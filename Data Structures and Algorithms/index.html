1. Introduction to DSA

Data Structures and Algorithms are fundamental concepts used to store, organize and process data efficiently.

Data structures define how data is stored, while algorithms define the steps used to solve a problem.

3. Arrays

An array stores multiple values in a single collection using indexes.

4. Searching

Linear Search

Linear search checks every element one by one.

Time Complexity: O(n)

Binary Search

Binary search repeatedly divides a sorted array into two parts.

Time Complexity: O(log n)

6. Linked List

A linked list consists of nodes. Each node stores data and a reference to another node.

7. Stack

Stack follows the LIFO principle: Last In, First Out.

8. Queue

Queue follows the FIFO principle: First In, First Out.

9. Trees

A tree is a hierarchical data structure consisting of nodes connected by edges.

  • Binary Tree
  • Binary Search Tree
  • AVL Tree
  • Heap
  • Trie

10. Graph

A graph consists of vertices and edges.

  • Graph Representation
  • Adjacency Matrix
  • Adjacency List
  • BFS
  • DFS
  • Dijkstra Algorithm

11. Recursion

Recursion is a technique where a function calls itself to solve smaller versions of the same problem.

12. Dynamic Programming

Dynamic Programming solves complex problems by breaking them into smaller overlapping subproblems and storing previously calculated results.

  • Fibonacci
  • 0/1 Knapsack
  • Longest Common Subsequence
  • Longest Increasing Subsequence

13. Greedy Algorithms

Greedy algorithms make the best available choice at each step.

  • Activity Selection
  • Fractional Knapsack
  • Huffman Coding
  • Prim's Algorithm
  • Kruskal's Algorithm

14. Backtracking

Backtracking explores possible solutions and goes back when a selected path cannot produce a solution.

  • N-Queens
  • Rat in a Maze
  • Sudoku Solver
  • Subset Problems
