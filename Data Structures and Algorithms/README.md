# Algorithms

## 1. Searching Algorithms

Searching algorithms are used to find elements in a collection.

### Linear Search

Checks elements one by one.

Time Complexity:

`O(n)`

### Binary Search

Works on sorted data and repeatedly divides the search space.

Time Complexity:

`O(log n)`

---

# 2. Sorting Algorithms

Sorting arranges data in a particular order.

Algorithms covered:

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

---

## Bubble Sort

Repeatedly compares adjacent elements and swaps them when required.

Time Complexity:

- Best: `O(n)`
- Average: `O(n²)`
- Worst: `O(n²)`

---

## Selection Sort

Selects the smallest element and places it at the correct position.

Time Complexity:

`O(n²)`

---

## Insertion Sort

Builds the sorted part of the array one element at a time.

Time Complexity:

`O(n²)`

---

## Merge Sort

Uses the divide-and-conquer technique.

Time Complexity:

`O(n log n)`

---

## Quick Sort

Selects a pivot and divides the array around the pivot.

Average Time Complexity:

`O(n log n)`

Worst Time Complexity:

`O(n²)`

---

## Heap Sort

Uses a heap data structure for sorting.

Time Complexity:

`O(n log n)`

# Divide and Conquer

Divide and conquer breaks a problem into smaller parts.

Examples:

- Merge Sort
- Quick Sort
- Binary Search

General steps:

1. Divide the problem.
2. Solve smaller problems.
3. Combine the results.

# Time Complexity

Time complexity describes how the running time of an algorithm grows with input size.

Common complexities:

| Complexity | Meaning |
|---|---|
| `O(1)` | Constant |
| `O(log n)` | Logarithmic |
| `O(n)` | Linear |
| `O(n log n)` | Linearithmic |
| `O(n²)` | Quadratic |
| `O(2ⁿ)` | Exponential |
| `O(n!)` | Factorial |

---

# Space Complexity

Space complexity describes the extra memory required by an algorithm.

Examples:

- `O(1)` — Constant Space
- `O(n)` — Linear Space
- `O(n²)` — Quadratic Space
