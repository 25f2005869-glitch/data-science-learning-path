## 📌 Introduction

SQLite is a lightweight relational database management system that stores the complete database in a single file.

In this day, we begin the database section of Modern Application Development and learn the fundamentals of SQLite, databases, tables, SQL, and basic database operations.

## 🎯 Learning Objectives

- Understand what SQLite is.
- Understand relational databases.
- Learn SQLite database structure.
- Understand databases, tables, rows, and columns.
- Learn basic SQL commands.
- Understand primary keys.
- Create an SQLite database.
- Connect Python with SQLite.
- Perform basic CRUD operations.
- Understand SQLite with Flask.
