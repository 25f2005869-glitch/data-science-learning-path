📌 What Is SQLite?

SQLite is a lightweight relational database management system. It is commonly stored as a single database file and does not require a separate database server.

💻 SQLite with Python

Python provides the built-in sqlite3 module for working with SQLite databases.

import sqlite3 connection = sqlite3.connect("students.db") cursor = connection.cursor()

🏗️ Create a Table

cursor.execute(""" CREATE TABLE IF NOT EXISTS students ( id INTEGER PRIMARY KEY, name TEXT, course TEXT ) """) connection.commit()

➕ Insert Data

cursor.execute( "INSERT INTO students (name, course) VALUES (?, ?)", ("Saloni", "Python") ) connection.commit()

The question-mark placeholders are used for parameterized queries.

🔍 Select Data

cursor.execute( "SELECT * FROM students" ) students = cursor.fetchall()

fetchall() retrieves all available rows from the executed SELECT query.

✏️ Update Data

cursor.execute( "UPDATE students SET course = ? WHERE id = ?", ("Flask", 1) ) connection.commit()

🗑️ Delete Data

cursor.execute( "DELETE FROM students WHERE id = ?", (1,) ) connection.commit()
Important: Always be careful with DELETE and UPDATE queries. An incorrect WHERE condition can affect multiple records.

🔐 Parameterized Queries

cursor.execute( "SELECT * FROM students WHERE name = ?", (student_name,) )

Parameterized queries are preferred when working with user-provided values because they help prevent SQL injection.

⚖️ SQLite Advantages

  • Lightweight
  • Serverless
  • File-based
  • Easy to configure
  • Portable
  • Excellent for learning and small applications
  • Python provides the sqlite3 module

⚠️ SQLite Considerations

  • It is not ideal for every large multi-user workload.
  • Concurrency characteristics differ from server-based databases.
  • Larger applications may use databases such as PostgreSQL.
  • The database choice should depend on application requirements.

⭐ Key Takeaways

  • SQLite is a lightweight relational database.
  • sqlite3 allows Python to work with SQLite.
  • SQL is used to communicate with the database.
  • CRUD means Create, Read, Update, Delete.
  • Primary keys identify records uniquely.
  • Parameterized queries help protect against SQL injection.
  • commit() persists database changes.
