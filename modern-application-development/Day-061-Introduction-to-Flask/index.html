📌 What is Flask?

Flask is a lightweight web framework written in Python. It is used to build web applications, websites and APIs.

🐍 Python

Programming language used to write backend logic.

🌐 Flask

Python framework used to handle web requests.

🖥️ Browser

Client that sends HTTP requests and receives responses.

🎯 Why Learn Flask?

  • Simple and lightweight
  • Python-based
  • Easy routing
  • Flexible project structure
  • Useful for backend development
  • Useful for building APIs

🔗 Flask Request Flow

Browser → HTTP Request → Flask → Route → View Function → Response → Browser

🧩 Basic Flask Application

from flask import Flask app = Flask(__name__) @app.route("/") def home(): return "Hello, Flask!" if __name__ == "__main__": app.run()

🔀 Route and View Function

Concept Example Purpose
Route /about URL path
Decorator @app.route("/about") Maps URL to function
View Function def about() Handles the request
Response return "About Page" Data sent back to browser

📁 Basic Flask Structure

flask-project/ │ ├── app.py ├── templates/ ├── static/ └── README.md

The templates folder is commonly used for HTML templates, while static is commonly used for CSS, JavaScript and images.

🛠️ Important Commands

Command Purpose
pip install flask Install Flask
python --version Check Python version
python app.py Run Flask application
app.run(debug=True) Run development server with debug mode
