## 📌 Introduction

Flask is a lightweight Python web framework used to build web applications and APIs.

In this day, we learn the basic Flask architecture, installation, application creation, routes, views, and how to run a Flask development server.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What Flask is
- Why Flask is used
- Flask vs traditional Python programs
- Flask installation
- Creating a Flask application
- Flask application object
- Routes and URL mapping
- View functions
- `@app.route()`
- Running the Flask development server
- Debug mode
- Returning HTML responses
- Basic Flask project structure
