# Part B - MCQs

### 1.

Which tag defines an HTML5 document?

- [ ] A. `<html>`
- [ ] B. `<body>`
- [ ] C. `<!DOCTYPE html>`
- [ ] D. `<head>`

**Answer:** C

---

### 2.

Which tag contains visible webpage content?

- [ ] A. `<head>`
- [ ] B. `<body>`
- [ ] C. `<meta>`
- [ ] D. `<title>`

**Answer:** B

---

### 3.

Which tag sets the browser tab title?

- [ ] A. `<title>`
- [ ] B. `<meta>`
- [ ] C. `<html>`
- [ ] D. `<h1>`

**Answer:** A

---

### 4.

Which tag is used for comments?

- [ ] A. `//`
- [ ] B. `/* */`
- [ ] C. `<!-- -->`
- [ ] D. `#`

**Answer:** C
