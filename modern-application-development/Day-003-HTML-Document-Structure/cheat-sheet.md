# 📋 Day 003 - Cheat Sheet

## HTML Document Structure

```html
<!DOCTYPE html>

<html lang="en">

<head>

<meta charset="UTF-8">

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

<title>My Webpage</title>

</head>

<body>

Content

</body>

</html>
```

---

## Quick Revision

### <!DOCTYPE html>

- HTML5 Declaration
- First line of every HTML page

---

### html

Root element of HTML.

---

### head

Stores webpage information.

Not displayed on the webpage.

---

### meta

Provides webpage information.

Examples

- charset
- viewport

---

### title

Displayed on the browser tab.

---

### body

Contains everything visible on the webpage.

---

### HTML Comment

```html
<!-- Comment -->
```

Ignored by the browser.

---
