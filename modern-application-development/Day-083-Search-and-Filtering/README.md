## 📌 Introduction

Search and filtering allow users to find specific records from a larger collection of data.

In Flask applications, search and filtering are commonly implemented using:

- Query parameters
- `request.args`
- SQL `WHERE`
- SQLAlchemy `where()`
- `LIKE`
- Multiple filter conditions
- Sorting and pagination basics

These concepts are important for building practical database-driven applications.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What search and filtering mean
- How query parameters work
- How to receive search input in Flask
- How to filter database records
- How SQLAlchemy performs filtering

- How to combine multiple filters
- How to sort filtered results
