📌 What is Search?

Search allows users to find specific records from a larger collection of data using a keyword or value.

Example: /students?search=saloni

🎯 Search Workflow

User Input

🔗 Query Parameters

Query parameters send additional information through a URL. 

/students?search=saloni&course=data-science

search and course are query parameter names.

🐍 Flask: request.args

search = request.args.get("search", "").strip()

Flask uses request.args to access query parameters.

🗄️ SQL Filtering

SELECT * FROM students
WHERE marks >= 80;

The SQL WHERE clause selects records that satisfy a condition.

🔤 LIKE Search

SELECT * FROM students
WHERE name LIKE '%saloni%';

The pattern %saloni% searches for values containing "saloni".

⚙️ SQLAlchemy Filtering

statement = select(Student).where(
    Student.marks >= 80
)

SQLAlchemy's where() is used to add filtering conditions to a query.

🔐 Security

Important: Never directly concatenate untrusted user input into SQL. Use SQLAlchemy expressions or parameterized queries. 
Safe approach:

select(Student).where(
    Student.name.ilike("%keyword%")
)

📚 Search vs Filtering

Search

Usually finds records using a keyword.

Example: name contains "saloni"

Filtering

Selects records using one or more conditions.

Example: marks >= 80

Sorting

Arranges the returned records.

Example: marks DESC

🧠 Key Concepts

  • request.args — query parameters
  • select() — create SELECT queries
  • where() — filter records
  • like() — pattern matching
  • ilike() — case-insensitive pattern matching where supported
  • order_by() — sort results
  • asc() — ascending order
  • desc() — descending order
