# 🏆 Day 020 — HTML Master Challenge Practice

**Author:** Saloni Tiwari  
**Programme:** IIT Madras BS Degree — Diploma Level

---

# 🎯 Challenge

Build a complete webpage called:

**Student Learning & Portfolio Hub**

The challenge should be completed using HTML only.

Do not use CSS or JavaScript.

---

# 🧩 Part 1 — Document Structure

Create:

- HTML5 doctype
- `html`
- `head`
- `meta charset`
- viewport meta tag
- `title`
- `body`

---

# 🧩 Part 2 — Header

Create a header containing:

- Student name
- Programme
- Short introduction

Use:

- `header`
- `h1`
- `p`

---

# 🧩 Part 3 — Navigation

Create navigation links for:

- About
- Education
- Skills
- Projects
- Learning Journey
- Achievements
- Media
- Contact

Use anchor links with section IDs.

---

# 🧩 Part 4 — About Section

Create an About section containing:

- Profile image
- Short introduction
- Learning goal

Requirements:

- Use `section`.
- Use `figure`.
- Use `figcaption`.
- Add meaningful `alt` text.

---

# 🧩 Part 5 — Education Table

Create an education table with:

- Programme
- Institution
- Level
- Status

Requirements:

- Use `caption`.
- Use `thead`.
- Use `tbody`.
- Use `th`.
- Use `td`.
- Use `scope`.

---

# 🧩 Part 6 — Skills

Create an unordered list containing at least six skills.

Example categories:

- HTML
- CSS
- JavaScript
- Python
- SQL
- Git

---

# 🧩 Part 7 — Learning Journey

Create an ordered list showing your learning sequence.

Example:

1. HTML
2. CSS
3. JavaScript
4. Flask
5. Database
6. CRUD
7. Final Project

---

# 🧩 Part 8 — Projects

Create at least three project articles.

Each article should contain:

- Project title
- Description
- Project link

Use:

    <article>

---

# 🧩 Part 9 — Achievements

Create an achievements section.

Include:

- Completed HTML learning phase
- Completed practice projects
- Current programme
- Technical learning goals

Use an unordered list or description list.

---

# 🧩 Part 10 — Study Resources

Create an aside containing useful learning resources.

Include links to:

- HTML documentation
- GitHub
- Learning platform

External links should use:

    target="_blank"

and:

    rel="noopener noreferrer"

---

# 🧩 Part 11 — Multimedia

Add:

### Audio

Use:

- `audio`
- `source`
- `controls`

### Video

Use:

- `video`
- `source`
- `controls`

### iframe

Embed an external webpage or suitable content.

Add a meaningful iframe `title`.

---

# 🧩 Part 12 — Contact Form

Create a complete contact form.

Required fields:

- Full Name
- Email
- Phone
- Date
- Website
- Learning Topic
- Preferred Mode
- Skills
- Message
- Submit
- Reset

---

# 🧩 Part 13 — Form Input Types

Use appropriate input types:

- text
- email
- tel
- date
- url
- radio
- checkbox

---

# 🧩 Part 14 — Validation

Apply validation using:

- `required`
- `minlength`
- `maxlength`
- `pattern`
- `min`
- `max`
- appropriate input types

Example phone validation:

    pattern="[0-9]{10}"

---

# 🧩 Part 15 — Accessibility

Check that:

- Every meaningful image has `alt`.
- Every form input has a label.
- Label `for` matches input `id`.
- Tables have headers.
- Tables use `scope`.
- Navigation is understandable.
- iframe has a title.
- Headings follow a logical order.
- Links have meaningful text.

---

# 🧩 Part 16 — Semantic HTML

Your final webpage should contain:

    header
    nav
    main
    section
    article
    aside
    footer
    figure
    figcaption

---

# 🧩 Part 17 — Debugging

Before completing the challenge, check for:

- Missing closing tags
- Incorrect nesting
- Duplicate IDs
- Missing `alt`
- Missing labels
- Incorrect form attributes
- Incorrect table structure
- Broken links
- Invalid input attributes

- Reset button
