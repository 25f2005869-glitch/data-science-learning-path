## 📖 Introduction

Day 020 is the final HTML master challenge of the Modern Application Development learning journey.

This challenge combines the important HTML concepts learned from Day 001 to Day 019 into one complete, structured, accessible, and practical webpage.

The project is intentionally built using HTML only.

No CSS or JavaScript is required for this challenge.

---

## 🎯 Challenge Objective

The main objective is to demonstrate that the HTML fundamentals learned during the previous days can be combined to create a complete webpage from scratch.

By completing this challenge, you should be able to:

- Create a valid HTML5 document.
- Build a semantic webpage structure.
- Organize content using headings and paragraphs.
- Create navigation links.
- Display images.
- Create ordered, unordered, and description lists.
- Create accessible tables.
- Build forms.
- Use multiple input types.
- Apply HTML form validation.
- Embed multimedia.
- Use semantic HTML elements.
- Follow accessibility and HTML best practices.

## 🚫 Challenge Rules

For this master challenge:

- Use HTML5 only.
- Do not use CSS.
- Do not use JavaScript.
- Use semantic HTML.
- Use meaningful attributes.
- Use proper indentation.
- Use accessible labels.
- Use alternative text for images.
- Use tables only for tabular information.
- Use appropriate input types.
- Add basic form validation.
- Keep the HTML logically structured.
