## 📌 Introduction

Loops allow JavaScript to execute a block of code repeatedly while a condition is true or for a specific number of iterations.

## 🎯 Learning Objectives

- Understand why loops are used.
- Learn `for`, `while`, and `do...while` loops.
- Understand loop initialization, condition, and update.
- Learn `break` and `continue`.
- Understand nested loops.
- Iterate through arrays and strings.
- Avoid infinite loops.
- Choose the appropriate loop for a problem.
