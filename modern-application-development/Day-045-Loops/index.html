📚 What Are Loops?

Loops allow JavaScript to execute the same block of code repeatedly while a condition is satisfied.


🔁 for Loop

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Best when the iteration structure is predictable.

🔁 while Loop

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

The condition is checked before each iteration.

🔁 do...while

let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

The body executes at least once.


⛔ break and continue

Keyword Purpose
break Stops the complete loop.
continue Skips the current iteration.

📦 Array Iteration

const subjects = ["DBMS", "PDSA", "MLF"];

for (let i = 0; i < subjects.length; i++) {
    console.log(subjects[i]);
}

The loop uses the array index to access every element.
