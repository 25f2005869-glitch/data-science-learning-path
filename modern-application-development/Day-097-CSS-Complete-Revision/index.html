🎯 CSS Fundamentals

Selectors

Universal, element, class, ID, grouping, descendant, child, sibling, and attribute selectors.

Colors

CSS supports named colors, HEX, RGB, RGBA, HSL, HSLA, and gradients.

Typography

Font family, size, weight, style, line height, alignment, spacing, and decoration.

Specificity

Specificity helps determine which CSS rule takes priority when multiple rules match.

Units

Common units include px, %, em, rem, vw, vh, vmin, vmax, and ch.

Overflow

Control overflowing content using overflow, overflow-x, and overflow-y.

📦 CSS Box Model

The CSS box model consists of:

Content → Padding → Border → Margin

Content Area

+ Border

A common project-wide rule is: box-sizing: border-box;

📱 Responsive Design

Mobile First

Start with the smaller-screen layout and progressively enhance it for larger screens.

Media Queries

Apply styles according to viewport and other supported conditions.

Responsive Images

Avoid images overflowing their containers. A common pattern is max-width: 100%.

✨ Transitions and Animations

Transitions smoothly change properties between states. Animations can define multiple stages using keyframes.
