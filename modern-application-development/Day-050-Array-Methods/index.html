📚 What Are Array Methods?

Array methods are built-in JavaScript functions used to process, transform, search, filter, and calculate array data. 

const numbers = [1, 2, 3];

const squares = numbers.map(
    number => number * number
);

🔁 forEach()

numbers.forEach(number => {
    console.log(number);
});

Performs an action for every element.

🔄 map()

const doubled = numbers.map(
    number => number * 2
);

Creates a new transformed array.

🔍 filter()

const even = numbers.filter(
    number => number % 2 === 0
);

Creates a new array containing matching elements.


🎯 find()

numbers.find(
    number => number > 10
);

Returns the first matching element.

🔎 findIndex()

numbers.findIndex(
    number => number > 10
);

Returns the index of the first match.

❓ some() / every()

numbers.some(
    number => number > 10
);

numbers.every(
    number => number > 0
);

Check whether any or all elements satisfy a condition.


📊 reduce()

const total = numbers.reduce(
    (sum, number) => sum + number,
    0
);

reduce() combines array elements into one final value.


🧰 Array Methods Comparison

Method Purpose Result
forEach() Perform an action undefined
map() Transform New array
filter() Select elements New array
find() Find first match Element
findIndex() Find first matching index Number
some() Check any Boolean
every() Check all Boolean
reduce() Combine values Single value
