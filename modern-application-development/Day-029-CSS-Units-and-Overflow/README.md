## 📖 Introduction

CSS units are used to define sizes such as width, height, spacing, and font sizes.

CSS overflow controls what happens when content becomes larger than the available space.

---

## 🎯 Learning Objectives

By the end of Day 029, you will be able to:

- Understand absolute and relative CSS units.
- Use `px`, `%`, `em`, `rem`, `vw`, and `vh`.
- Understand `em` vs `rem`.
- Choose suitable units for responsive layouts.
- Understand CSS overflow.
- Use `overflow`, `overflow-x`, and `overflow-y`.
- Use `visible`, `hidden`, `scroll`, and `auto`.
- Handle overflowing text.
- Create scrollable containers.
