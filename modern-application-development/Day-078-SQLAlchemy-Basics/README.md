## 📌 Introduction

SQLAlchemy is a Python library used to work with relational databases.

It provides an **Object Relational Mapper (ORM)** that allows Python classes and objects to represent database tables and records.

SQLAlchemy is especially useful in Flask applications because it reduces the need to write raw SQL for every database operation.
