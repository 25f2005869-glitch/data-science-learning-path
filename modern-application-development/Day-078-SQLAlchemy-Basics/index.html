📌 What is SQLAlchemy?

SQLAlchemy is a Python library used to work with relational databases. It provides SQL tools and an Object Relational Mapper (ORM).

With ORM, Python classes can represent database tables and Python objects can represent database records.

🧠 Core Concepts

Engine

Connects the Python application with the database.

Model

A Python class that represents a database table.

Column

Represents a field in a database table.

Session

Manages database operations and transactions.

Primary Key

Uniquely identifies a record in a table.

ORM

Maps programming objects to relational database data.

🔄 SQLAlchemy Flow

Python Model → SQLAlchemy → Engine → Database

🐍 Basic Model Example

from sqlalchemy import String
from sqlalchemy.orm import DeclarativeBase
from sqlalchemy.orm import Mapped, mapped_column

class Base(DeclarativeBase):
    pass

class Student(Base):
    __tablename__ = "students"

    id: Mapped[int] = mapped_column(
        primary_key=True
    )

    name: Mapped[str] = mapped_column(
        String(100)
    )

    email: Mapped[str] = mapped_column(
        String(120),
        unique=True
    )

⚙️ Database Engine

An SQLAlchemy Engine provides the connection interface between the application and database. 

from sqlalchemy import create_engine

engine = create_engine(
    "sqlite:///students.db"
)

💾 Basic CRUD Mapping

SQL Operations and SQLAlchemy Concepts

➕ Adding a Record

student = Student(
    name="Saloni",
    email="saloni@example.com"
)

session.add(student)
session.commit()

🔍 Querying Records

from sqlalchemy import select

statement = select(Student)

students = session.scalars(
    statement
).all()

✏️ Updating a Record

student = session.get(Student, 1)

student.name = "Saloni Tiwari"

session.commit()

🗑️ Deleting a Record

student = session.get(Student, 1)

session.delete(student)

session.commit()

🔁 Commit and Rollback

Commit

session.commit() saves the current transaction.

Rollback

session.rollback() cancels uncommitted changes after an error.

🌐 Flask-SQLAlchemy

Flask applications can use Flask-SQLAlchemy to integrate SQLAlchemy with Flask. 

from flask import Flask
from flask_sqlalchemy import SQLAlchemy

app = Flask(__name__)

app.config[
    "SQLALCHEMY_DATABASE_URI"
] = "sqlite:///students.db"

db = SQLAlchemy(app)
