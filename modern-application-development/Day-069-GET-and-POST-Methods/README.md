## 📖 Introduction

GET and POST are two important HTTP request methods used by web applications.

GET is commonly used to retrieve information, while POST is commonly used to submit data to the server.

Understanding these methods is essential for building Flask applications that communicate correctly with browsers.

## 🎯 Learning Objectives

- Understand HTTP request methods.
- Understand GET requests.
- Understand POST requests.
- Learn how Flask handles GET and POST.
- Understand query parameters.
- Understand request body data.
- Use `request.args`.
- Use `request.form`.
- Use `request.method`.
- Understand Post/Redirect/Get.
