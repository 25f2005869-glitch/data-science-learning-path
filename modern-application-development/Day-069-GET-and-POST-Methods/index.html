Day 069 — GET and POST Methods

Understanding HTTP methods and Flask request handling

GET POST Comparison Workflow

📡 What Is an HTTP Method?

An HTTP method tells the server what type of operation the client is requesting.

🔎 GET

Commonly used to retrieve information.

📤 POST

Commonly used to submit or process information.

1. GET Method

GET is commonly used when the client wants to retrieve information from the server.

GET /courses

Query Parameters

GET requests can contain query parameters in the URL.

/search?q=python&page=2

Flask reads query parameters using:

request.args.get("q")

2. GET Form Example

If the user searches for Python, the URL can become:

/search?q=Python

3. POST Method

POST is commonly used to submit data to the server.

POST /register

Normal form fields submitted through POST are commonly available in Flask through:

request.form

4. POST Form Example

5. Flask GET Example

from flask import Flask, request

app = Flask(__name__)

@app.route("/search", methods=["GET"])
def search():
    query = request.args.get("q", "")
    return f"Searching for: {query}"

6. Flask POST Example

from flask import Flask, request

app = Flask(__name__)

@app.route("/register", methods=["POST"])
def register():
    name = request.form.get("name", "")
    return f"Registered: {name}"

7. One Route for GET and POST

@app.route("/student", methods=["GET", "POST"])
def student():

    if request.method == "POST":
        name = request.form.get("name", "")
        return f"Submitted: {name}"

    return "Show Student Form"

11. Post/Redirect/Get

POST ↓ Process ↓ Redirect ↓ GET

Flask can perform a redirect using:

return redirect(url_for("home"))

This pattern helps prevent accidental duplicate submissions after refreshing a successful POST result.

12. Important Rules

  • GET is commonly used for retrieval and search.
  • POST is commonly used for submitting or changing data.
  • Use request.args for query parameters.
  • Use request.form for normal submitted form fields.
  • Use request.method to identify the HTTP method.
  • Always validate important data on the server.
  • Do not put passwords in GET query parameters.
  • POST does not provide encryption by itself.
  • Use HTTPS for sensitive data transmission.
