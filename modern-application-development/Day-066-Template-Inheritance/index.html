Day 066 — Template Inheritance

Learning reusable layouts with Flask and Jinja2

Concept Syntax Structure Workflow

What is Template Inheritance?

Jinja2 Template Inheritance allows multiple Flask pages to share a common layout.

A base template contains common elements such as the header, navigation, footer, and content areas. Child templates reuse this structure and provide page-specific content.

Important Jinja2 Syntax

extends

{% extends "base.html" %}

Inherits the structure of a parent template.

block

{% block content %} ... {% endblock %}

Creates a replaceable section in a template.

super()

{{ super() }}

Keeps the parent block content while adding child content.

Typical Flask Template Structure

project/
├── app.py
├── templates/
│   ├── base.html
│   ├── home.html
│   ├── about.html
│   └── contact.html
└── static/

The base template provides the common website structure. The child templates extend the base template.

Base Template Concept

<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}Website{% endblock %}</title>
</head>

<body>

    <header>Common Header</header>

    <nav>Common Navigation</nav>

    <main>
        {% block content %}
        {% endblock %}
    </main>

    <footer>Common Footer</footer>

</body>
</html>

Child Template Concept

{% extends "base.html" %}

{% block title %}
    Home
{% endblock %}

{% block content %}
    <h1>Welcome to the Home Page</h1>
    <p>This content belongs to the child template.</p>
{% endblock %}

Template Inheritance Workflow

Step Process
1 Browser sends a request to Flask.
2 Flask executes the appropriate route.
3 Flask calls render_template().
4 Jinja2 loads the child template.
5 The child extends the base template.
6 Jinja2 inserts child content into blocks.
7 Final HTML is returned to the browser.

Why Use Template Inheritance?

♻️ Reusability

Write common HTML once and reuse it across pages.

🧹 Less Duplication

Follow the DRY principle and avoid repeated markup.

🔧 Easy Maintenance

Update the common layout in one base template.

📁 Better Organization

Keep common and page-specific content separate.
