## 📖 Introduction

Jinja2 Template Inheritance allows multiple Flask pages to share a common layout.

Instead of repeating the same navbar, header, footer, and other HTML on every page, we create a **base template** and extend it in child templates.

## 🎯 Learning Objectives

- Understand template inheritance.
- Learn the purpose of a base template.
- Use `{% extends %}`.
- Use `{% block %}` and `{% endblock %}`.
- Create reusable layouts.
- Understand parent and child templates.
- Use `{{ super() }}`.
- Build clean Flask template structures.
