🐍 Flask Revision

Flask

Python web framework used to build web applications and APIs.

Routing

Connects URLs to Python view functions.

Request

Contains information sent by the browser to the Flask server.

Response

Data returned by Flask to the browser.

Browser ↓ HTTP Request ↓ Flask Route ↓ View Function ↓ Response ↓ Browser

🎨 Jinja2 Revision

Variables

Jinja2 uses double braces to display dynamic values.

{{ student.name }}

Conditions

Use conditions to display different content.

{% if marks >= 50 %} Passed {% else %} Failed {% endif %}

Loops

Use loops to display collections of data.

{% for student in students %} {{ student.name }} {% endfor %}

Inheritance

Base templates provide reusable page layouts.

{% extends "base.html" %} {% block content %} Dashboard {% endblock %}

🔐 Authentication & Sessions

Authentication

Determines who the user is.

Authorization

Determines what the user is allowed to do.

Password Hashing

Passwords should be stored as secure hashes, not plain text.

Session

Helps maintain login state between requests.

Register ↓ Hash Password ↓ Store User ↓ Login ↓ Verify Password ↓ Create Session ↓ Protected Dashboard ↓ Logout

🔍 Search, Filtering & Validation

Search

Use GET query parameters and database filtering.

Filtering

Filter records by course, marks, status, or other fields.

Validation

Check user input before processing or storing it.

Flash Messages

Provide temporary success, error, warning, or info feedback.

🛡️ Security Revision

  • Hash passwords securely.
  • Use HTTPS in production.
  • Keep secret keys outside source code.
  • Validate data on the server.
  • Use parameterized SQL or ORM queries.
  • Protect state-changing forms against CSRF.
  • Check authorization for protected operations.
  • Do not expose sensitive error details.
  • Never log passwords or secret keys.
  • Use secure cookie settings.
