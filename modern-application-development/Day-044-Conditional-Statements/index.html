Conditional Statements

Day 044 — JavaScript Decision Making

1. What Are Conditional Statements?

Conditional statements allow JavaScript to make decisions based on whether a condition is true or false.

if (age >= 18) {
    console.log("Adult");
}

2. if, else if and else

if

One Condition

Runs when the condition is truthy.

else if

Multiple Conditions

Checks another condition when previous conditions were false.

else

Default Path

Runs when no preceding condition is true.

3. Conditions with Logical Operators

&&

AND

Both conditions must be truthy.

||

OR

At least one condition must be truthy.

!

NOT

Reverses the truthiness of a value.

if (age >= 18 && hasID) {
    console.log("Allowed");
}

4. switch Statement

A switch is useful when one value needs to be compared with multiple known alternatives.

switch (role) {
    case "student":
        console.log("Student");
        break;

    default:
        console.log("Unknown");
}

5. Truthy and Falsy Values

Truthy

true, non-empty strings, non-zero numbers, objects and arrays.

Falsy

false, 0, "", null, undefined and NaN.

7. Ternary Operator

const status =
age >= 18 ? "Adult" : "Minor";

Ternary operators are useful for simple two-way decisions.
