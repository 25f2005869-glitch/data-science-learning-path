## 📌 Overview

Day 044 introduces conditional statements in JavaScript.

Conditional statements allow a program to make decisions based on whether a condition is true or false.

## 🎯 Learning Objectives

- Understand decision-making in JavaScript.
- Learn `if` statements.
- Learn `if...else`.
- Learn `else if`.
- Understand nested conditions.
- Learn `switch`.
- Understand truthy and falsy values.
- Use logical and comparison operators in conditions.
- Use the ternary operator for simple decisions.
