## 🔹 Semantic Elements

| Element | Purpose |
|---|---|
| `<header>` | Introductory/header content |
| `<nav>` | Navigation links |
| `<main>` | Primary page content |
| `<section>` | Meaningful section |
| `<article>` | Independent content |
| `<aside>` | Related/supporting content |
| `<footer>` | Footer information |
| `<figure>` | Self-contained figure/content |
| `<figcaption>` | Caption for a figure |

---

## 🔹 Generic Elements

| Element | Purpose |
|---|---|
| `<div>` | Generic block container |
| `<span>` | Generic inline container |

---

## 🔹 Basic Page Structure

    <header>
        Header
    </header>

    <nav>
        Navigation
    </nav>

    <main>

        <section>
            Section
        </section>

        <article>
            Article
        </article>

        <aside>
            Related Content
        </aside>

    </main>

    <footer>
        Footer
    </footer>

## 🔹 Semantic vs Non-Semantic

Semantic:

    <header>
    <nav>
    <main>
    <section>
    <article>
    <aside>
    <footer>

Non-semantic:

    <div>
    <span>

---

## 🔹 Remember

`header` → Introduction

`nav` → Navigation

`main` → Main content

`section` → Related section

`article` → Independent content

`aside` → Related content

`footer` → Footer

`figure` → Figure

`figcaption` → Figure caption

`div` → Generic block container

`span` → Generic inline container

---

## 🔹 Accessibility

Semantic HTML helps assistive technologies understand webpage structure.

Good practice:

- Use meaningful headings
- Use semantic elements
- Use labels for forms
- Use useful `alt` text for informative images

---

## ⭐ Quick Revision

Semantic HTML = HTML elements that describe the meaning and purpose of content.

Main elements:

`header → nav → main → section/article → aside → footer`
