# Part 2 — Multiple Choice Questions

### Q1. Which element represents the main content of a webpage?

A. `<content>`

B. `<main>`

C. `<body-content>`

D. `<primary>`

**Answer:** B

---

### Q2. Which element is used for navigation links?

A. `<links>`

B. `<navigation>`

C. `<nav>`

D. `<menu-links>`

**Answer:** C

---

### Q3. Which element represents independent content?

A. `<article>`

B. `<independent>`

C. `<content>`

D. `<post>`

**Answer:** A

---

### Q4. Which element represents related or supplementary content?

A. `<side>`

B. `<aside>`

C. `<extra>`

D. `<related>`

**Answer:** B

---

### Q5. Which element represents footer content?

A. `<bottom>`

B. `<end>`

C. `<footer>`

D. `<last>`

**Answer:** C

---

### Q6. Which element provides a caption for a figure?

A. `<caption>`

B. `<figcaption>`

C. `<figure-caption>`

D. `<description>`

**Answer:** B

---

### Q7. Which is a non-semantic element?

A. `<article>`

B. `<section>`

C. `<div>`

D. `<nav>`

**Answer:** C

---

### Q8. Which element is normally used for the primary content of a document?

A. `<main>`

B. `<aside>`

C. `<footer>`

D. `<nav>`

**Answer:** A

---

### Q9. Which element is best suited for a blog post?

A. `<article>`

B. `<nav>`

C. `<footer>`

D. `<span>`

**Answer:** A

---

### Q10. Semantic HTML primarily provides:

A. Programming logic

B. Meaningful document structure

C. Database storage

D. CSS animations

**Answer:** B

# Part 6 — Debugging Practice

Identify which elements should replace the generic `<div>` elements.

    <div>
        <h1>My Portfolio</h1>
    </div>

    <div>
        <a href="#">Home</a>
        <a href="#">About</a>
    </div>

    <div>
        <h2>About Me</h2>
        <p>I am learning web development.</p>
    </div>

    <div>
        <p>© 2026 My Portfolio</p>
    </div>

Try replacing the generic containers with appropriate semantic elements.
