## 📖 Introduction

Semantic HTML means using HTML elements according to the meaning and purpose of their content.

Instead of using generic elements everywhere, semantic elements clearly describe different parts of a webpage.

For example:

- `<header>` represents introductory content.
- `<nav>` represents navigation links.
- `<main>` represents the main content.
- `<section>` represents a meaningful section.
- `<article>` represents independent content.
- `<aside>` represents related or supplementary content.
- `<footer>` represents footer information.

Semantic HTML makes webpages easier to understand, maintain, navigate, and access.
