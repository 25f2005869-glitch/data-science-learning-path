📚 What Is a Function?

A function is a reusable block of JavaScript code that performs a specific task. 

function greet() {
    console.log("Hello!");
}

greet();

📥 Parameters

function greet(name) {
    console.log("Hello " + name);
}

greet("Saloni");

name is the parameter and "Saloni" is the argument.

↩️ return

function add(a, b) {
    return a + b;
}

const result = add(10, 20);

The function returns a reusable value.

➡️ Arrow Function

const square = x => x * x;

console.log(square(5));

Arrow functions provide concise syntax.


📊 Function Types

Type Example
Function Declaration function add(a, b) { ... }
Function Expression const add = function(a, b) { ... }
Arrow Function const add = (a, b) => a + b
