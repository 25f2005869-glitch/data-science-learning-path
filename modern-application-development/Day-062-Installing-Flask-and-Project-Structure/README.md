## 📌 Introduction

Before developing Flask applications, it is important to install Flask correctly and understand how a Flask project is organized.

This day focuses on Flask installation, virtual environments, dependencies, the application entry point, templates, static files, and a clean project structure.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- How to check Python and pip
- How to create a virtual environment
- How to activate a virtual environment
- How to install Flask
- How to verify Flask installation
- Why `requirements.txt` is used
- Flask project structure
- `app.py`
- `templates/`
- `static/`
- Basic application configuration
- How to run a Flask project
