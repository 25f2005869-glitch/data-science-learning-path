📌 Day 062 Overview

Before building Flask applications, we need a proper Python environment and a clean project structure.

🐍 Python

Required to run Flask applications.

🌱 Virtual Environment

Keeps project dependencies isolated.

📦 Flask

Python web framework used for backend development.

🔧 Installation Workflow

python --version python -m pip --version python -m venv .venv .venv\Scripts\activate python -m pip install flask python -m pip freeze > requirements.txt

📁 Recommended Project Structure

flask-project/ │ ├── .venv/ ├── app.py ├── requirements.txt ├── .gitignore │ ├── templates/ │ └── index.html │ └── static/ ├── css/ │ └── style.css ├── js/ │ └── script.js └── images/

📚 Project Components

Component Purpose
.venv/ Isolated Python environment
app.py Main Flask application
templates/ HTML templates
static/ CSS, JavaScript and images
requirements.txt Project dependencies
.gitignore Files ignored by Git

🐍 Basic Flask Application

from flask import Flask app = Flask(__name__) @app.route("/") def home(): return "Hello, Flask!" if __name__ == "__main__": app.run(debug=True)

🌐 Templates and Static Files

📄 templates/

Used for HTML templates that Flask can render.

🎨 static/css/

Used for CSS files.

⚙️ static/js/

Used for JavaScript files.

🖼️ static/images/

Used for images and other static assets.

📋 Dependency Management

A Flask project can record its Python dependencies in requirements.txt.

python -m pip freeze > requirements.txt python -m pip install -r requirements.txt
