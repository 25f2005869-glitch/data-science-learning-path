## 📖 Introduction

Day 021 marks the beginning of the CSS section of the Modern Application Development learning journey.

HTML is used to create the structure of a webpage, while CSS is used to control its presentation and visual appearance.

In this day, we learn the fundamentals of CSS and how CSS works together with HTML.

---

## 🎯 Learning Objectives

By the end of Day 021, you should be able to:

- Understand what CSS is.
- Understand why CSS is required.
- Understand the relationship between HTML and CSS.
- Understand CSS syntax.
- Identify selectors, properties, and values.
- Apply CSS to HTML elements.
- Understand inline CSS.
- Understand internal CSS.
- Understand external CSS.
- Understand comments in CSS.
- Understand basic CSS colors.
- Understand the difference between HTML structure and CSS presentation.
