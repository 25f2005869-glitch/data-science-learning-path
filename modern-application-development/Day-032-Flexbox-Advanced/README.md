## 📌 Introduction

Day 032 goes deeper into Flexbox and focuses on flex item properties used to control sizing, growth, shrinking, ordering and individual alignment.

## 🎯 Learning Objectives

- Understand advanced Flexbox properties.
- Control individual flex items.
- Use `flex-grow`, `flex-shrink` and `flex-basis`.
- Understand the `flex` shorthand.
- Use `order`.
- Use `align-self`.
- Understand `flex: 1`.
- Build responsive card layouts.

## 📚 Topics Covered
