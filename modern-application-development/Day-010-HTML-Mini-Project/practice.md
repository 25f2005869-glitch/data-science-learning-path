# 🎯 Section 2 — MCQs

### Q1. Which element contains the main content?

A. `<footer>`

B. `<main>`

C. `<aside>`

D. `<nav>`

**Answer:** B

---

### Q2. Which element is used for navigation?

A. `<navigate>`

B. `<links>`

C. `<nav>`

D. `<navigation>`

**Answer:** C

---

### Q3. Which attribute provides alternative text for an image?

A. `title`

B. `src`

C. `alt`

D. `href`

**Answer:** C

---

### Q4. Which element represents a table row?

A. `<td>`

B. `<tr>`

C. `<th>`

D. `<row>`

**Answer:** B

---

### Q5. Which element is used to submit a form?

A. `<submit>`

B. `<input>`

C. `<button>`

D. `<send>`

**Answer:** C
