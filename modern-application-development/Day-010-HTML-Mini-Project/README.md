## 📖 Introduction

Welcome to **Day 010** of my **Modern Application Development (MAD 1)** learning journey.

In the previous days, I learned the fundamentals of HTML including:

- HTML Document Structure
- Elements and Attributes
- Headings and Paragraphs
- Links and Images
- Lists and Tables
- HTML Forms

In this mini project, I am combining these concepts to build a simple **Student Portfolio Website using HTML5**.

The project is intentionally created using **HTML only** so that the focus remains on understanding HTML structure and semantics.
