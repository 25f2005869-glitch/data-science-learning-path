## 📌 Introduction

Day 034 goes deeper into CSS Grid and focuses on controlling the placement, size and alignment of individual grid items.

## 🎯 Learning Objectives

- Understand Grid lines and tracks.
- Position items using `grid-column` and `grid-row`.
- Make items span multiple columns or rows.
- Use `grid-area`.
- Understand `minmax()`, `auto-fit` and `auto-fill`.
- Use `justify-items`, `align-items` and `place-items`.
- Build practical dashboard layouts.
