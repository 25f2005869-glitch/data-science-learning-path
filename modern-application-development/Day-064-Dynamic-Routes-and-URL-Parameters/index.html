📌 What is a Dynamic Route?

A dynamic route contains a variable part of the URL. The same route can handle many different values.

/student/101 → /student/102 → /student/103

🧩 Basic Dynamic Route

@app.route("/student/<name>") def student(name): return f"Student: {name}"

Example: /student/Saloni

🔢 Integer Parameter

@app.route("/student/<int:student_id>") def student(student_id): return f"Student ID: {student_id}"

Valid example: /student/101

A value such as /student/abc does not match the integer converter.

📚 Route Converters

Converter Example Purpose
string <name> Text without a slash
int <int:id> Integer
float <float:price> Decimal value
path <path:file> Path containing slashes
uuid <uuid:id> UUID value

🔀 Multiple URL Parameters

@app.route("/student/<int:id>/course/<course>") def student_course(id, course): return f"Student {id} - Course: {course}"

Example URL: /student/101/course/DBMS

📁 Path Parameter

@app.route("/files/<path:filename>") def files(filename): return filename

A path parameter can contain slash-separated content.

Example: /files/docs/mad1/notes.pdf

🔗 Using `url_for()`

Flask can generate URLs for dynamic routes using url_for().

url_for("student", student_id=101)

This generates the URL corresponding to the student route with the supplied parameter.

📊 URL Parameter vs Query Parameter

Type Example Location
URL Parameter /student/101 Path
Query Parameter /students?page=2 Query string

🎓 Practical Student Routes

/student/101

Represents student 101.

/course/DBMS

Represents a DBMS course page.

/project/5

Represents project 5.

/post/10

Represents blog post 10.

🔄 Dynamic Route Flow

Dynamic URL → Parameter → Flask Route → View Function → Response

🧠 Day 064 Key Points

  • Dynamic routes contain variable URL values.
  • URL parameters are received by Flask view functions.
  • Route converters can restrict parameter types.
  • Multiple parameters can be used in one route.
  • url_for() can generate dynamic URLs.
  • URL parameters and query parameters are different.
  • Meaningful URL design improves application structure.
