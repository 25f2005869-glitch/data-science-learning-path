## 📌 Introduction

Dynamic routes allow Flask applications to receive changing values directly from a URL.

For example, instead of creating separate routes for every student, one route can handle:

    /student/101
    /student/102
    /student/103

This day focuses on URL parameters, dynamic routes, route converters, multiple parameters, and practical URL design.
