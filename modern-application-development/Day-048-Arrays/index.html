📚 What Is an Array?

An array stores multiple values inside a single variable. 

const subjects = ["DBMS", "PDSA", "MLF"];

console.log(subjects[0]);

Array indexes start from 0.


➕ Add Elements

subjects.push("MAD1");

subjects.unshift("Statistics");

push() adds to the end. unshift() adds to the beginning.

➖ Remove Elements

subjects.pop();

subjects.shift();

pop() removes from the end. shift() removes from the beginning.

✂️ slice()

const result = numbers.slice(1, 4);

Extracts a portion without modifying the original array.


🧰 Array Methods

Method Purpose
push() Add at the end
pop() Remove from the end
unshift() Add at the beginning
shift() Remove from the beginning
includes() Check whether a value exists
indexOf() Find an element's index
join() Combine elements into a string
slice() Extract without modifying original
splice() Add, remove, or replace elements
