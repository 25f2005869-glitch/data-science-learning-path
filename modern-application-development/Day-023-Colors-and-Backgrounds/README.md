## 📖 Introduction

Day 023 focuses on CSS Colors and Backgrounds.

Colors and backgrounds are fundamental parts of webpage design. CSS provides several ways to define colors and many properties for controlling backgrounds.

In this day, we learn how to apply text colors, background colors, gradients, background images, and basic background positioning and sizing.

---

## 🎯 Learning Objectives

By the end of Day 023, you should be able to:

- Understand CSS color values.
- Use named colors.
- Use hexadecimal colors.
- Use RGB and RGBA colors.
- Use HSL and HSLA colors.
- Apply the `color` property.
- Apply `background-color`.
- Apply `background-image`.
- Control background repetition.
- Control background position.
- Control background size.
- Understand `background-attachment`.
- Use CSS gradients.
- Understand transparency.
- Combine multiple background properties.
