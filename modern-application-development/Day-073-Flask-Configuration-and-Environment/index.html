📌 What Is Configuration?

Configuration contains settings that control how a Flask application behaves.

Debug

Controls development debugging behavior.

Database

Stores database connection configuration.

Security

Contains security-related settings such as secret keys.

Application

Contains application-specific settings.

🧩 Flask Configuration Object

Flask provides the app.config object for storing application configuration.

from flask import Flask app = Flask(__name__) app.config["DEBUG"] = True app.config["APP_NAME"] = "Student Portal"

📦 from_mapping()

Multiple configuration values can be loaded using from_mapping().

app.config.from_mapping( DEBUG=True, APP_NAME="Student Portal", MAX_STUDENTS=100 )

🏗️ Configuration Classes

class Config: APP_NAME = "Student Portal" DEBUG = False app.config.from_object(Config)

Configuration classes help keep settings organized and separate from application logic.

🌱 Environment Variables

Environment variables allow deployment-specific values to be supplied outside the application source code.

import os secret_key = os.environ.get("SECRET_KEY") database_url = os.environ.get("DATABASE_URL")

📄 .env File

A local development environment can use a .env file to define environment variables.

SECRET_KEY=development-secret DATABASE_URL=sqlite:///students.db APP_NAME=Student Portal
Security: Never commit real secrets to a public repository. Add sensitive .env files to .gitignore.

🔐 SECRET_KEY

Flask uses SECRET_KEY for security-related features such as signing session data.

app.config["SECRET_KEY"] = os.environ.get( "SECRET_KEY" )
  • Keep the secret private.
  • Use a strong unpredictable value.
  • Do not publish it on GitHub.
  • Use appropriate values for different environments.

🖥️ Development vs Production

Development Production
Debugging may be enabled Debugging disabled
Local database Production database
Development configuration Secure deployment configuration
Detailed debugging Safe error responses

🧪 Application Factory

Larger Flask applications can use an application factory to create applications with different configurations.

def create_app(): app = Flask(__name__) app.config.from_object(Config) return app

🛡️ Configuration Best Practices

  • Keep configuration separate from application logic.
  • Use environment variables for sensitive values.
  • Keep .env files out of version control.
  • Use strong secret keys.
  • Disable debug mode in production.
  • Separate development, testing, and production settings.
  • Never expose secrets in responses or logs.

⭐ Key Takeaways

  • app.config stores Flask configuration.
  • from_mapping() loads multiple configuration values.
  • from_object() loads values from an object or class.
  • Environment variables keep deployment-specific values outside source code.
  • .env is useful for local development.
  • SECRET_KEY must be protected.
  • Production should use secure configuration.
