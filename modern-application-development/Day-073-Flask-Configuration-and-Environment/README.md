## 📌 Introduction

Flask applications need configuration settings to control their behavior.

In this day, we learn how Flask configuration works, how to store settings, how to use environment variables, and how to separate development and production configuration safely.

## 🎯 Learning Objectives

- Understand Flask configuration.
- Use `app.config`.
- Create configuration variables.
- Load configuration from Python objects.
- Understand environment variables.
- Use `.env` files safely.
- Understand development and production environments.
- Protect secrets and credentials.
- Understand `SECRET_KEY`.
- Use configuration in routes and templates.

## 📚 Topics Covered

- Flask Configuration
- `app.config`
- Configuration Keys
- `app.config.from_object()`
- `app.config.from_mapping()`
- Environment Variables
- `.env` Files
- `python-dotenv`
- `SECRET_KEY`
- Development Configuration
- Production Configuration
- Configuration Best Practices
- Security
