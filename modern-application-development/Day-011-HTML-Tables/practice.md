# 🎯 Section 2 — MCQs

## Q1. Which element creates a table row?

A. `<td>`

B. `<row>`

C. `<tr>`

D. `<table-row>`

**Answer:** C

---

## Q2. Which element creates a table header?

A. `<header>`

B. `<th>`

C. `<thead>`

D. `<heading>`

**Answer:** B

---

## Q3. Which element contains normal table data?

A. `<data>`

B. `<td>`

C. `<tr>`

D. `<cell>`

**Answer:** B

---

## Q4. Which element provides a table title?

A. `<title>`

B. `<caption>`

C. `<heading>`

D. `<label>`

**Answer:** B

---

## Q5. Which attribute allows a cell to span multiple columns?

A. `rowspan`

B. `merge`

C. `colspan`

D. `columnspan`

**Answer:** C

---

## Q6. Which attribute allows a cell to span multiple rows?

A. `rowspan`

B. `colspan`

C. `rows`

D. `merge-row`

**Answer:** A

---

## Q7. Which element contains the main table data?

A. `<tbody>`

B. `<main>`

C. `<data>`

D. `<content>`

**Answer:** A

---

## Q8. Which attribute describes whether a header applies to a row or column?

A. `header`

B. `scope`

C. `type`

D. `direction`

**Answer:** B
