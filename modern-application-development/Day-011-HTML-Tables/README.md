## 📊 What is an HTML Table?

An HTML table is used to display structured data in rows and columns.

Example:

```text
Name       Course       Status
--------------------------------
Saloni     MAD          Learning
Rahul      PDSA         Learning

HTML tables are useful for structured data such as:

Student records
Course information
Exam schedules
Marks
Product data
Employee records
Timetables
🧱 Basic Table Structure
<table>

    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Saloni</td>
        <td>MAD</td>
    </tr>

</table>
