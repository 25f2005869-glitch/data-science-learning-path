## 📖 Introduction

Form validation ensures that users enter valid and complete information before a form is processed.

JavaScript can be used to create custom validation rules and provide immediate feedback to users.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What form validation is
- Client-side validation
- HTML5 validation
- JavaScript validation
- `required`
- `minlength` and `maxlength`
- `min` and `max`
- `pattern`
- Input types
- `checkValidity()`
- `reportValidity()`
- `setCustomValidity()`
- Form submission validation
- Custom error messages
- Preventing invalid submission
- Validation best practices
