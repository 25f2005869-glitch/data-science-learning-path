6. Position Types

Position Normal Flow Main Use
static Yes Default layout
relative Yes Offset or positioning context
absolute No Badges and overlays
fixed No Floating viewport elements
sticky Yes Sticky headers/navigation

7. Positioning Properties

  • position — Defines positioning behavior
  • top — Controls top offset
  • right — Controls right offset
  • bottom — Controls bottom offset
  • left — Controls left offset
  • z-index — Controls stacking order
  • transform — Useful for positioning adjustments

8. Key Pattern

Important

Parent + Child Positioning

Parent: position: relative

Child: position: absolute

This is a common pattern for badges, icons, labels and overlays.
