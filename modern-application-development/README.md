## 📌 About This Repository

This repository contains my complete **100-day Modern Application Development learning journey**.

The learning path is designed to build a strong foundation in modern web application development, starting from HTML and CSS and progressing through JavaScript, Flask, SQLite, SQLAlchemy, CRUD, authentication, testing, deployment, and portfolio development.

The complete journey follows:

**HTML → CSS → JavaScript → Flask → SQLite → SQLAlchemy → Full-Stack Development → Project → Revision → Portfolio**

---

# 🎯 Learning Objectives

By completing this 100-day learning path, the objectives are to:

- Understand the fundamentals of web development.
- Build structured webpages using HTML.
- Design responsive interfaces using CSS.
- Add interactivity using JavaScript.
- Understand client-side DOM manipulation.
- Work with browser storage and events.
- Build backend applications using Flask.
- Work with Jinja2 templates.
- Handle forms and HTTP requests.
- Understand SQLite databases.
- Use SQLAlchemy ORM.
- Implement CRUD operations.
- Build authentication systems.
- Work with sessions and cookies.
- Implement search and filtering.
- Validate user input.
- Handle errors and debugging.
- Test web applications.
- Understand deployment.
- Optimize applications.
- Build a complete MAD 1 project.
- Prepare professional GitHub repositories and portfolio projects.

# 🔐 Security Principles

Important security practices learned throughout the course:

- Never store plain-text passwords.
- Hash passwords securely.
- Validate input on the server.
- Use safe database queries.
- Use ORM or parameterized SQL.
- Protect state-changing forms against CSRF.
- Implement authorization.
- Use HTTPS in production.
- Protect secret keys.
- Use environment variables.
- Do not commit `.env` files containing secrets.
- Do not expose production debug information.
- Use secure cookie settings.
- Avoid logging passwords or sensitive information.
