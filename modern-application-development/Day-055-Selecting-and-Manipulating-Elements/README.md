## 📖 Introduction

JavaScript can select HTML elements from the DOM and manipulate their content, styles, classes, attributes, and structure.

This day focuses on practical DOM selection and manipulation techniques used to build interactive webpages.

---

## 🎯 Learning Objectives

By the end of this day, you will understand:

- How to select HTML elements
- How to select multiple elements
- How to change text and HTML
- How to modify CSS classes and styles
- How to manipulate attributes
- How to create and insert elements
- How to remove and replace elements
- How to traverse basic DOM relationships
