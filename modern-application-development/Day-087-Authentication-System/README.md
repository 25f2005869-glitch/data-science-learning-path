## 📌 Introduction

Authentication verifies the identity of a user.

In a Flask application, an authentication system commonly includes:

- Registration
- Login
- Logout
- Password hashing
- Session management
- Protected routes
- Authorization

This day focuses on designing these components as part of the MAD 1 project.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- Authentication vs authorization
- User registration
- Password hashing
- Password verification
- Login workflow
- Logout workflow
- Flask sessions

- `SECRET_KEY`
- Role-based access
- Authentication security
