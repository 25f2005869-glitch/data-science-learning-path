# Part 9 — Contact Form

Create a form containing:

- Full Name
- Email
- Phone
- Subject
- Message
- Submit button
- Reset button

Apply suitable validation.

Requirements:

Name:

- Required
- Minimum 3 characters

Email:

- Required
- `type="email"`

Phone:

- `type="tel"`
- Exactly 10 digits

Subject:

- Required

Message:

- Required

# Part 11 — Accessibility Check

Verify:

- Every form input has a label.
- Navigation links are descriptive.
