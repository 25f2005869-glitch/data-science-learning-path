## 📖 Project Overview

Day 018 is an HTML-only mini project focused on building a Personal Portfolio Website.

The purpose of this project is to combine the HTML concepts learned during the previous days into one complete webpage.

This project focuses on structure, semantics, accessibility, forms, links, tables, images, and clean HTML practices.

No CSS or JavaScript is used in this project.

---

## 🎯 Project Objectives

The main objectives are:

- Build a complete personal portfolio webpage
- Apply semantic HTML
- Create a logical page structure
- Add personal information
- Display education details
- Display technical skills
- Showcase projects
- Add useful links
- Create a contact form
- Apply basic form validation
- Practice accessible HTML
- Follow HTML best practices
