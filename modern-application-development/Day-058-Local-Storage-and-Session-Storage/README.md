## 📖 Introduction

Web Storage allows JavaScript to store small amounts of data in the user's browser.

The two main Web Storage mechanisms are:

- `localStorage`
- `sessionStorage`

`localStorage` keeps data across browser sessions, while `sessionStorage` is associated with the current browser tab/session.
