## 📌 Introduction

Day 035 focuses on building websites that automatically adapt to different screen sizes such as mobile, tablet and desktop.

## 🎯 Learning Objectives

- Understand responsive web design.
- Understand viewport and media queries.
- Build mobile-friendly layouts.
- Use flexible units.
- Use responsive images.
- Use Flexbox and Grid responsively.
- Apply mobile-first design.

## 📚 Topics Covered

- Responsive Web Design

- Responsive Flexbox
