## 📌 Introduction

User authentication is the process of verifying the identity of a user.

A typical authentication system allows users to:

- Register
- Log in
- Access protected pages
- Log out

In Flask applications, authentication is commonly connected with forms, databases, sessions, password hashing and authorization.
