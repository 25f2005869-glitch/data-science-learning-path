📌 What is Authentication?

Authentication is the process of verifying the identity of a user.

Authentication

Answers: Who are you?

Authorization

Answers: What can you access?

🔄 Authentication Flow

Register → Hash Password → Save User → Login → Verify → Session

👤 Registration

Registration creates a new user account. The password should be hashed before being stored. 

password_hash = generate_password_hash(
    password
)

user = User(
    email=email,
    password_hash=password_hash
)

db.session.add(user)
db.session.commit()

🔒 Password Hashing

Passwords should never be stored as plain text. A password hash is stored instead. 

from werkzeug.security import generate_password_hash

password_hash = generate_password_hash(
    password
)

✅ Password Verification

from werkzeug.security import check_password_hash

valid = check_password_hash(
    stored_hash,
    entered_password
)

The verification function checks whether the entered password matches the stored password hash.

🔑 Login

user = find_user_by_email(email)

if user and check_password_hash(
    user.password_hash,
    password
):
    login_user(user)

🧠 Flask Session

Flask sessions can maintain login-related state between requests. 

from flask import session

session["user_id"] = user.id

user_id = session.get("user_id")

session.pop("user_id", None)

🚪 Protected Routes

@app.route("/dashboard")
@login_required
def dashboard():
    return "Student Dashboard"

A protected route should only be accessible to an authenticated user.

👤 Flask-Login

Common Flask-Login Components
Component Purpose
LoginManager Manages authentication configuration
UserMixin Provides common user functionality
login_user() Logs a user in
logout_user() Logs a user out
login_required Protects routes
current_user Represents the current user

🛡️ Security Best Practices

Password Hashing

Never store plain-text passwords.

HTTPS

Use HTTPS for production authentication traffic.

Secret Key

Keep production secret keys secure.

Input Validation

Validate user-controlled data on the server.

Protected Routes

Restrict private resources to authenticated users.

Rate Limiting

Help reduce automated brute-force login attempts.

📊 Authentication vs Authorization

Identity and Permission
Concept Example
Authentication Email + password verifies identity
Authorization Student role allows student dashboard access
Admin Authorization Admin role allows admin dashboard access

⭐ Key Takeaways

  • Authentication verifies user identity.
  • Authorization controls access permissions.

  • generate_password_hash() creates password hashes.
  • check_password_hash() verifies passwords.
  • Flask sessions can maintain login state.
  • Flask-Login simplifies authentication management.
  • login_required protects routes.
  • current_user represents the authenticated user.
