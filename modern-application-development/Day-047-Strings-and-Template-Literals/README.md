## 📌 Introduction

Strings are used to represent text in JavaScript. Template literals provide a convenient way to create strings with variables, expressions, and multiple lines.

## 🎯 Learning Objectives

- Understand JavaScript strings.
- Learn different ways to create strings.
- Access characters using indexes.
- Use common string methods.
- Understand string length.
- Learn template literals.
- Use `${}` for interpolation.
- Create multiline strings.
- Apply strings in practical programs.

## 📚 Topics Covered

- String basics

- `toLowerCase()`
- `trim()`
- `includes()`

- `endsWith()`
- `indexOf()`

- String interpolation
- Expressions inside template literals
- Multiline strings
