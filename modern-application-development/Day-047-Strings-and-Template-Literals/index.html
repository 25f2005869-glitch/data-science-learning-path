📚 What Is a String?

A string is a sequence of characters used to represent text in JavaScript. 

const name = "Saloni";

console.log(name);

🔢 String Indexing

const word = "Hello";

console.log(word[0]);
console.log(word[4]);

Indexing starts from 0.

📏 length

const word = "JavaScript";

console.log(word.length);

The length property gives the number of characters.

✂️ slice()

const text = "JavaScript";

console.log(text.slice(0, 4));

Extracts a part of a string.


🧰 Common String Methods

Method Purpose
toUpperCase() Converts text to uppercase.
toLowerCase() Converts text to lowercase.
trim() Removes outer whitespace.
includes() Checks whether text exists.
indexOf() Finds the position of text.
replace() Replaces matching text.
split() Converts a string into an array.

🧩 Template Literals

const name = "Saloni";
const course = "MAD 1";

const message = `Hello ${name}.
You are learning ${course}.`;

console.log(message);

Template literals use backticks and allow variables and expressions inside ${}.
