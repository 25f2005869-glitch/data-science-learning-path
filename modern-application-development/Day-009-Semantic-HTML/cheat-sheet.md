# 📋 Day 009 - Semantic HTML Cheat Sheet

## Main Semantic Elements

```html
<header>
```

Page or section header.

```html
<nav>
```

Navigation links.

```html
<main>
```

Main content of the page.

```html
<section>
```

Thematic section of content.

```html
<article>
```

Independent/self-contained content.

```html
<aside>
```

Related or secondary content.

```html
<footer>
```

Footer of page or section.

---

## Figure

```html
<figure>

    <img src="image.jpg" alt="Example">

    <figcaption>
        Image Caption
    </figcaption>

</figure>
```

```text
<header>
     ↓

     ↓
<article>
     ↓
<aside>
     ↓

```

# Semantic vs Non-Semantic

### Semantic

```html
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

### Non-Semantic

```html
<div>
<span>
```

# 🧠 Remember

| Element | Meaning |
|---|---|
| `<header>` | Header |
| `<nav>` | Navigation |
| `<main>` | Main Content |
| `<section>` | Section |
| `<article>` | Independent Content |
| `<aside>` | Related Content |
| `<footer>` | Footer |
| `<figure>` | Figure/Media |
| `<figcaption>` | Figure Caption |

## 🔥 One-Line Revision

**Semantic HTML = HTML elements that describe the meaning of their content.**
