# Part B - MCQs

### 1. Which element represents the main content?

- [ ] A. `<header>`
- [ ] B. `<main>`
- [ ] C. `<footer>`
- [ ] D. `<aside>`

**Answer:** B

---

### 2. Which element is used for navigation?

- [ ] A. `<navigate>`
- [ ] B. `<links>`
- [ ] C. `<nav>`
- [ ] D. `<navigation>`

**Answer:** C

---

### 3. Which element represents independent content?

- [ ] A. `<article>`
- [ ] B. `<section>`
- [ ] C. `<div>`
- [ ] D. `<main>`

**Answer:** A

---

### 4. Which element represents secondary content?

- [ ] A. `<side>`
- [ ] B. `<aside>`
- [ ] C. `<secondary>`
- [ ] D. `<sidebar>`

**Answer:** B

---

### 5. Which element is used for the bottom section of a webpage?

- [ ] A. `<bottom>`
- [ ] B. `<end>`
- [ ] C. `<footer>`
- [ ] D. `<last>`

**Answer:** C
