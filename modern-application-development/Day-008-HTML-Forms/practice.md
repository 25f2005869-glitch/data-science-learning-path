# Part B - MCQs

### 1. Which tag creates an HTML form?

- [ ] A. `<input>`
- [ ] B. `<form>`
- [ ] C. `<label>`
- [ ] D. `<button>`

**Answer:** B

---

### 2. Which input type is used for passwords?

- [ ] A. text
- [ ] B. email
- [ ] C. password
- [ ] D. secret

**Answer:** C

---

### 3. Which input type is suitable for email?

- [ ] A. email
- [ ] B. mail
- [ ] C. text-email
- [ ] D. address

**Answer:** A

---

### 4. Which element creates a dropdown?

- [ ] A. `<dropdown>`
- [ ] B. `<select>`
- [ ] C. `<option>`
- [ ] D. `<list>`

**Answer:** B

---

### 5. Which element is used inside `<select>`?

- [ ] A. `<item>`
- [ ] B. `<choice>`
- [ ] C. `<option>`
- [ ] D. `<select-item>`

**Answer:** C

---

### 6. Which attribute makes an input mandatory?

- [ ] A. important
- [ ] B. required
- [ ] C. mandatory
- [ ] D. validate

**Answer:** B
