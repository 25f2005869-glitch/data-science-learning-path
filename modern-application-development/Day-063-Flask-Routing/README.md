## 📌 Introduction

Routing is one of the most important concepts in Flask.

A route connects a URL to a Python view function. Flask uses routes to decide which function should handle an incoming request.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What Flask routing means
- `@app.route()`
- URL paths
- View functions
- Multiple routes
- Dynamic routes
- URL variables
- `<int:variable>`
- `<float:variable>`
- `<path:variable>`
- Route converters
- HTTP methods
- `url_for()`
- Route naming
- Trailing slashes
- 404 errors
