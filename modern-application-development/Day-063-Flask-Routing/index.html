📌 What is Routing?

Routing connects a URL to a Python view function. Flask uses the route to decide which function should handle an incoming request.

URL → Route → View Function → Response

🏠 Basic Route

@app.route("/") def home(): return "Home Page"

📚 Multiple Routes

/

Home page route

/about

About page route

/projects

Projects page route

/contact

Contact page route

🎯 Dynamic Routes

Dynamic routes allow values to be received directly from the URL.

@app.route("/student/<name>") def student(name): return f"Student: {name}"

Example URL: /student/Saloni

🔢 Route Converters

Converter Example Purpose
string <name> Text
int <int:id> Integer
float <float:price> Decimal number
path <path:file> Path containing slashes
uuid <uuid:id> UUID value

🔢 Integer Route Example

@app.route("/student/<int:student_id>") def student(student_id): return f"Student ID: {student_id}"

Valid example: /student/101

A non-integer value such as /student/abc does not match this route.

🌐 HTTP Methods

Method Common Purpose
GET Retrieve data
POST Submit or create data
PUT Replace data
PATCH Partially update data
DELETE Delete data
@app.route("/login", methods=["GET", "POST"]) def login(): return "Login"

🔗 `url_for()`

Flask provides url_for() to generate URLs using endpoint or view function names.

from flask import url_for url_for("home") url_for("about")

❌ 404 Not Found

If Flask cannot find a route matching the requested URL, it returns a 404 Not Found response.

Browser Request ↓ /unknown ↓ No Matching Route ↓ 404 Not Found

🔄 Routing Flow

Browser → HTTP Request → Flask → Route Matching → View Function → Response → Browser

🧠 Day 063 Key Points

  • A route maps a URL to a Python function.
  • @app.route() defines a route.
  • Dynamic routes receive values from URLs.
  • Route converters restrict the type of URL values.
  • HTTP methods control the types of requests accepted.
  • url_for() generates URLs from endpoints.
  • An unmatched URL generally produces a 404 response.
