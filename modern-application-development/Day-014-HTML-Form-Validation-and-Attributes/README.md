## 📖 Introduction

HTML forms collect information from users. Form validation helps ensure that the information entered by the user follows the required rules.

In Day 014, we learn how to validate form data using built-in HTML attributes without writing JavaScript.

---

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What form validation means
- Why form validation is important
- The `required` attribute
- `minlength` and `maxlength`
- `min` and `max`
- `pattern`
- `type`-based validation
- `placeholder`
- `disabled`
- `readonly`
- `checked`

- `multiple`

## 📚 Topics Covered

### 1. Form Validation
Understanding how browsers check user input before submission.

### 2. Required Fields
Using `required` to make a field compulsory.

### 3. Text Validation
Using `minlength` and `maxlength`.

### 4. Number Validation
Using `min` and `max`.

### 5. Pattern Validation
Using regular expressions with the `pattern` attribute.

### 6. Input Type Validation
Using input types such as:

- `email`
- `url`
- `number`
- `date`
- `tel`

### 7. Other Form Attributes

- `placeholder`
- `disabled`
- `readonly`
- `checked`
- `selected`
- `multiple`
- `autocomplete`

### 8. Form Validation Control

Understanding the `novalidate` attribute.
