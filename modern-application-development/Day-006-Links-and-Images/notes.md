# 📘 Day 006 - Links and Images

## What is a Hyperlink?

A hyperlink connects one webpage to another webpage or website.

HTML uses the `<a>` (Anchor) tag to create hyperlinks.

Example

```html
<a href="https://www.google.com">
Google
</a>
```

---

# href Attribute

The `href` attribute specifies the destination URL.

Example

```html
<a href="https://www.github.com">
GitHub
</a>
```

---

# target Attribute

The `target` attribute specifies where the link opens.

Open in same tab

```html
<a href="https://google.com">
Google
</a>
```

Open in new tab

```html
<a href="https://google.com" target="_blank">
Google
</a>
```

---

# Absolute URL

Links to another website.

Example

```html
<a href="https://www.youtube.com">
YouTube
</a>
```

---

# Relative URL

Links to another page in the same project.

Example

```html
<a href="about.html">
About
</a>
```

---

# Image Tag

Images are displayed using the `<img>` tag.

Example

```html
<img src="image.jpg">
```

---

# src Attribute

Specifies the image location.

Example

```html
<img src="images/html.png">
```

---

# alt Attribute

Alternative text shown if the image cannot load.

Example

```html
<img src="logo.png"
alt="HTML Logo">
```

---

# width Attribute

Sets image width.

```html
<img src="logo.png"
width="300">
```

---

# height Attribute

Sets image height.

```html
<img src="logo.png"
height="200">
```

---

# Best Practices

- Always use alt.
- Use meaningful link text.
- Use target="_blank" for external websites.
- Optimize image size.
