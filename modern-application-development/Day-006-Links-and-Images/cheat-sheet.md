# 📋 Day 006 - Cheat Sheet

## Hyperlink

```html
<a href="https://google.com">
Google
</a>
```

---

## New Tab

```html
<a href="https://google.com"
target="_blank">
Google
</a>
```

---

## Image

```html
<img
src="image.png"
alt="Image"
width="300">
```

---

## Common Attributes

| Attribute | Purpose |
|-----------|---------|
| href | Link Destination |
| target | Open Location |
| src | Image Source |
| alt | Alternative Text |
| width | Image Width |
| height | Image Height |

---

## Remember

Anchor → `<a>`

Image → `<img>`

Link → href

Image Location → src

Alternative Text → alt
