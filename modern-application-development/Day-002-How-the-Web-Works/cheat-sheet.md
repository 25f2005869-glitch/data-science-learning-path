# 📋 Day 002 - Cheat Sheet

## 🌍 Internet

- Network of Networks
- Connects millions of devices worldwide

---

## 🌐 World Wide Web (WWW)

- Collection of websites
- Uses the Internet

---

## 💻 Browser

Software used to access websites.

Examples:

- Chrome
- Firefox
- Edge
- Safari
- Opera

---

## 🖥 Server

Stores website files and sends them to users.

---

## 👥 Client

The user's browser or device requesting data.

---

## 🔄 Client-Server Flow

```
User
   ↓
Browser
   ↓
DNS
   ↓
Server
   ↓
HTTP Response
   ↓
Browser
```

---

## 📨 HTTP

- HyperText Transfer Protocol
- Transfers web data
- Not encrypted

---

## 🔒 HTTPS

- HyperText Transfer Protocol Secure
- Encrypted
- Secure

---

## 🌍 URL

Address of a webpage.

Example:

```
https://www.example.com
```

---

## 🌐 Domain Name

Human-readable website name.

Examples:

- google.com
- github.com

---

## 🧮 IP Address

Unique address of a device on the Internet.

Example:

```
142.250.xxx.xxx
```

---

## 🔎 DNS

Converts a Domain Name into an IP Address.

---

## 🚀 Webpage Loading Steps

1. Enter URL
2. DNS Lookup
3. Find Server
4. Send HTTP Request
5. Server Processes Request
6. HTTP Response
7. Browser Displays Webpage

---
