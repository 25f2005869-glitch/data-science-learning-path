## 📖 Introduction

Responsive UI means designing a web interface that adapts to different screen sizes and devices.

A Flask application should provide a usable interface on desktops, tablets, and mobile devices.

## 🎯 Learning Objectives

- Understand responsive UI.
- Build mobile-friendly layouts.
- Use CSS Grid and Flexbox.
- Apply media queries.
- Create responsive navigation.
- Make tables and forms responsive.
- Use responsive images.
- Improve accessibility and usability.
