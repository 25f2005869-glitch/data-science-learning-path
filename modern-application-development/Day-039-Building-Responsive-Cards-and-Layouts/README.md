## 📌 Introduction

Day 039 focuses on creating responsive card components and page layouts that adapt smoothly to mobile, tablet and desktop screens.

- Build reusable card components.
- Create responsive card grids.
- Combine Flexbox and Grid.
- Use `minmax()`, `auto-fit` and `auto-fill`.
- Control card sizing and spacing.
- Create responsive page layouts.
