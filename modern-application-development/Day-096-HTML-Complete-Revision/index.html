🧱 HTML Fundamentals

Document Structure

HTML5 documents use a doctype, root element, head, metadata, title, and body.

Elements

Elements define the structure and meaning of webpage content.

Attributes

Attributes provide additional information such as id, class, href, and src.

Links

The <a> element creates hyperlinks.

Images

The <img> element displays images. Meaningful images should have useful alternative text.

Lists

HTML supports ordered, unordered, and description lists.
