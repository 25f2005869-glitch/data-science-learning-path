12. Key Properties

  • width — Controls horizontal size
  • height — Controls vertical size
  • min-width — Sets minimum width
  • max-width — Sets maximum width
  • min-height — Sets minimum height
  • max-height — Sets maximum height
  • display: block — Block layout
  • display: inline — Inline layout
  • display: inline-block — Inline layout with controllable dimensions
  • display: none — Hides and removes layout space
  • visibility: hidden — Hides but preserves layout space
  • box-sizing: border-box — Includes padding and border in dimensions
