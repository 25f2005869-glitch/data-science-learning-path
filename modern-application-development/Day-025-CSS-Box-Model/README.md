## 📖 Introduction

The CSS Box Model is one of the most important concepts in CSS.

Every HTML element displayed on a webpage can be understood as a rectangular box. The Box Model defines how the size of an element and the space around it are calculated.

The CSS Box Model consists of four main components:

- Content
- Padding
- Border
- Margin

Understanding these components is essential for controlling spacing, sizing, and creating well-structured web layouts.

## 📚 Topics Covered

### 1. CSS Box Model

The four main components are:

- Content
- Padding
- Border
- Margin

---

### 2. Content

The content is the actual area of an element.

It may contain:

- Text
- Images
- Links
- Other HTML elements

---

### 3. Padding

Padding is the space between the content and the border.

Important properties:

- `padding`
- `padding-top`
- `padding-right`
- `padding-bottom`
- `padding-left`

---

### 4. Border

A border surrounds the content and padding.

Important properties:

- `border`
- `border-width`
- `border-style`
- `border-color`
- `border-radius`

---

### 5. Margin

Margin creates space outside the border.

Important properties:

- `margin`
- `margin-top`
- `margin-right`
- `margin-bottom`
- `margin-left`

---

### 6. Width and Height

CSS provides properties for controlling element dimensions:

- `width`
- `height`
- `min-width`
- `max-width`
- `min-height`
- `max-height`

---

### 7. Box Sizing

The `box-sizing` property controls how the width and height of an element are calculated.

Main values:

- `content-box`
- `border-box`

---

### 8. Content Box

With `content-box`, the declared width applies to the content area.

Padding and border are added outside the declared width.

---

### 9. Border Box

With `border-box`, the declared width includes:

- Content
- Padding
- Border

This makes element sizing easier to manage.

---

### 10. Padding and Margin Shorthand

CSS allows multiple values to be written using shorthand notation.

The four-value order is:

**Top → Right → Bottom → Left**

This applies to both padding and margin.

---

### 11. Auto Margin

A fixed-width block element can commonly be centered horizontally using automatic margins.

Example concept:

`margin: 0 auto`

---

### 12. Margin Collapsing

Vertical margins of block-level elements can sometimes collapse instead of adding together.

Understanding margin collapsing helps explain unexpected vertical spacing.
