1. JavaScript Variables

Variables allow us to store and work with values in a JavaScript program.

let studentName = "Saloni";
const age = 17;
let score = 90;

5. typeof Operator

The typeof operator tells us the type of a value.

typeof "Saloni" → "string"
typeof 17 → "number"
typeof true → "boolean"
typeof undefined → "undefined"
typeof null → "object"

6. Dynamic Typing

JavaScript is dynamically typed. A variable can hold values of different types at different times.

let value = 100;
value = "Hello";
value = true;
