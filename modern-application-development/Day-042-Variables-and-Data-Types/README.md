## 📌 Overview

Day 042 focuses on JavaScript variables and data types.

Variables are used to store and work with data. Data types describe the kind of value stored in a variable.

## 🎯 Learning Objectives

- Understand variables.
- Learn `var`, `let` and `const`.
- Understand variable declaration and initialization.
- Learn JavaScript primitive data types.
- Understand `typeof`.
- Learn `null` and `undefined`.
- Understand dynamic typing.
- Practice type conversion basics.
