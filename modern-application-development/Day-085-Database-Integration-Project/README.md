## 📌 Introduction

Database integration connects a Flask application with a database so that the application can store, retrieve, update, delete, search, and filter persistent data.

This project combines the database concepts learned throughout Days 076–084.

## 🏗️ Project Idea

### Student Management System

The application manages student records.

Each student can have:

- ID
- Name
- Email
- Age
- Course
- Marks

The application can:

1. Add students
2. Display students
3. Search students
4. Filter students
5. Update students
6. Delete students
7. Validate input
8. Show success/error messages
