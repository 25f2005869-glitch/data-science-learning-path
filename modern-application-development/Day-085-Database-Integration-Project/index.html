Day 085 — Flask + SQLAlchemy + SQLite

Author: Saloni Tiwari

🎯 Project Goal

Build a database-driven Student Management System that combines Flask, SQLAlchemy, SQLite, CRUD, search, filtering, validation, and flash messages.

🏗️ Application Architecture

Browser User interface
Flask Routes and logic
SQLAlchemy ORM layer
SQLite Persistent database

🔄 Request-to-Database Flow

Browser → Flask Route → Validation → SQLAlchemy → SQLite → Response

👩‍🎓 Student Model

Column Purpose
id Primary key
name Student name
email Unique email address
age Student age
course Enrolled course
marks Student marks

♻️ CRUD Operations

CREATE

Add a new student.

db.session.add()

READ

Retrieve student records.

select()

UPDATE

Modify an existing student.

db.session.commit()

DELETE

Remove a student.

db.session.delete()

🔎 Search and Filtering

A database application can search and filter records using query parameters and SQLAlchemy conditions.

✅ Validation

Name Required and length checked
Email Format and uniqueness checked
Age Numeric and range checked
Course Allowed choices checked
Marks Must be between 0 and 100

💬 Flash Messages

Success: Student added successfully.
Error: Invalid student information.
Warning: Please check the submitted values.

🛡️ Database Safety

Important:
  • Validate all user input.
  • Use SQLAlchemy expressions or parameterized queries.
  • Do not expose database credentials.
  • Do not store plaintext passwords.
  • Protect state-changing forms with CSRF protection.
  • Do not expose internal database errors to users.
