## 📖 Project Overview

This mini project combines the JavaScript concepts learned from Day 041 to Day 058 into one interactive application.

### 🎓 Project: Student Learning Tracker

The application allows a student to:

- Enter personal information
- Select a course
- Enter marks
- Calculate a result and grade
- Track learning progress
- Add and remove courses
- Validate form input
- Save data using `localStorage`
- Store temporary session information
- Interact with buttons and form events
- Dynamically update the DOM
