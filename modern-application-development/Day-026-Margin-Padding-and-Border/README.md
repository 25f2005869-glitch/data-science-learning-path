## 📖 Introduction

Margin, Padding, and Border are three important parts of the CSS Box Model.

They are used to control:

- Internal spacing
- External spacing
- Element boundaries
- Element appearance
- Layout spacing
- Card and container design

In this day, we focus specifically on understanding and practicing `margin`, `padding`, and `border` in detail.

## 📚 Topics Covered

### 1. CSS Margin

Margin creates space outside an element's border.

Properties:

- `margin`
- `margin-top`
- `margin-right`
- `margin-bottom`
- `margin-left`

---

### 2. CSS Padding

Padding creates space between the content and the border.

Properties:

- `padding`
- `padding-top`
- `padding-right`
- `padding-bottom`
- `padding-left`

---

### 3. CSS Border

Border creates a visible boundary around an element.

Properties:

- `border`
- `border-width`
- `border-style`
- `border-color`
- `border-top`
- `border-right`
- `border-bottom`
- `border-left`

---

### 4. Border Styles

Common border styles:

- `solid`
- `dashed`
- `dotted`
- `double`
- `groove`
- `ridge`
- `inset`
- `outset`
- `none`

---

### 5. Border Radius

`border-radius` creates rounded corners.

Example:

`border-radius: 10px;`

---

### 6. Shorthand Properties

Margin and padding support one, two, three, and four-value shorthand syntax.

The four-value order is:

**Top → Right → Bottom → Left**

---

### 7. Auto Margin

`margin: 0 auto` is commonly used to center a fixed-width block element horizontally.

---

### 8. Negative Margin

Margins can use negative values.

Example:

`margin-top: -10px;`

Negative margins should be used carefully because they can change the normal spacing and positioning of elements.

---

### 9. Margin Collapsing

Vertical margins between some block-level elements can collapse.

Understanding this behavior helps explain unexpected vertical spacing.

---

### 10. Margin vs Padding

The key difference:

- Margin = space outside the border
- Padding = space inside the border
