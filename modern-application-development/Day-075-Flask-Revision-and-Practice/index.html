🛣️ Routing

from flask import Flask app = Flask(__name__) @app.route("/") def home(): return "Welcome to Flask" @app.route("/student/<student_name>") def student(student_name): return f"Student: {student_name}"

Routes connect URLs to Python view functions. Dynamic routes allow values to be captured from the URL.

📄 Jinja2 Templates

from flask import render_template @app.route("/student") def student(): return render_template( "student.html", name="Saloni", marks=85 )
<h1>Welcome, {{ name }}</h1> {% if marks >= 50 %} <p>Passed</p> {% else %} <p>Failed</p> {% endif %}

📝 Forms and Request Data

from flask import request @app.route("/register", methods=["GET", "POST"]) def register(): if request.method == "POST": name = request.form.get("name") email = request.form.get("email") return "Registration successful" return "Registration Form"
Flask Object Purpose
request.form Read submitted form data
request.args Read query parameters
request.method Read HTTP method

🔄 Redirects and url_for()

from flask import redirect, url_for return redirect(url_for("success"))

url_for() generates a URL from an endpoint name and makes navigation easier to maintain.

🧩 Blueprints

from flask import Blueprint student_bp = Blueprint( "students", __name__, url_prefix="/students" ) @student_bp.route("/profile") def profile(): return "Student Profile" app.register_blueprint(student_bp)

Blueprints help divide larger Flask applications into logical modules.

⚠️ Error Handling

@app.errorhandler(404) def not_found(error): return "Page not found", 404
from flask import abort abort(404)
Production rule: Do not expose detailed Flask debug tracebacks to users in production.

⚙️ Configuration and Environment

class Config: DEBUG = False TESTING = False APP_NAME = "Student Portal" app.config.from_object(Config)
import os app.config["SECRET_KEY"] = os.environ.get( "SECRET_KEY" )

🔐 Security Checklist

  • Validate user input on the server.
  • Keep secrets outside source code.
  • Do not commit real .env secrets.
  • Disable debug mode in production.
  • Do not expose detailed tracebacks.
  • Use HTTPS in production.
  • Use appropriate HTTP status codes.
