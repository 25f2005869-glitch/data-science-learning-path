## 🟨 JavaScript

JavaScript adds behavior and interactivity to web pages.

    HTML → Structure
    CSS → Style
    JavaScript → Behavior

---

## 📌 Uses

JavaScript can handle:

    Events
    Forms
    Calculations
    DOM
    Dynamic content
    APIs
    Browser storage
    Web applications

---

## 🌐 Client-Side JavaScript

JavaScript running in the browser is client-side JavaScript.

---

## 🧠 JavaScript Engines

    Chrome  → V8
    Firefox → SpiderMonkey
    Safari  → JavaScriptCore

---

## 🔗 Internal JavaScript

    <script>
        console.log("Hello");
    </script>

---

## 📁 External JavaScript

    <script src="script.js" defer></script>

---

## ⚡ Inline JavaScript

    <button onclick="alert('Hello')">
        Click
    </button>

Useful for demonstrations, but generally avoid it in larger projects.
