What is JavaScript?

JavaScript is a programming language used to add behavior, logic and interactivity to web pages.

console.log("Hello, JavaScript!");

HTML vs CSS vs JavaScript

HTML

Provides the structure and content of a webpage.

CSS

Controls appearance, layout and visual styling.

JavaScript

Adds behavior, logic and interactivity.
