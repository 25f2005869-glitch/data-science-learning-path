## 📖 Introduction

JavaScript events allow web pages to respond to user actions and browser activities.

Examples include:
- Clicking a button
- Typing in an input
- Submitting a form
- Moving the mouse
- Focusing an input
- Loading a page
- Pressing a keyboard key

Event listeners are used to detect these events and execute JavaScript code.
