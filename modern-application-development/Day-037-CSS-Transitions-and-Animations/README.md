## 📌 Introduction

Day 037 introduces CSS Transitions and Animations for creating smooth visual effects and interactive interfaces without JavaScript.

## 🎯 Learning Objectives

- Understand CSS transitions.
- Use `transition-property`.
- Use `transition-duration`.
- Use `transition-timing-function`.
- Use `transition-delay`.
- Understand `transform`.
- Create CSS animations with `@keyframes`.
- Use animation properties.
- Apply hover and focus effects.
