## 📖 Introduction

Writing HTML is not only about making a webpage work.

Good HTML should also be:

- Clean
- Readable
- Structured
- Accessible
- Maintainable
- Meaningful
- Valid
- Easy to debug

In Day 017, we learn important HTML best practices that help us write professional and maintainable webpages.

## 📚 Topics Covered

### 1. Clean HTML Structure

Writing HTML using proper indentation and organization.

### 2. Semantic HTML

Using meaningful elements such as:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

### 3. Heading Hierarchy

Using headings logically from `<h1>` to `<h6>`.

### 4. Attributes

Using meaningful and appropriate attributes.

### 5. Accessibility

Making webpages easier to use with assistive technologies.

### 6. Images

Using meaningful `alt` text.

### 7. Forms

Using labels and appropriate input types.

### 8. Links

Using descriptive link text.

### 9. Tables

Using tables only for tabular data and providing meaningful headers.

### 10. Deprecated HTML

Avoiding outdated presentation elements and attributes.

### 11. Validation

Checking HTML for errors and invalid markup.
