📌 CRUD Overview

C — Create

Add a new record to the database.

R — Read

Retrieve existing records.

U — Update

Modify an existing record.

D — Delete

Remove an existing record.

Day 079 covered Create and Read. Day 080 focuses on Update and Delete.

✏️ Update Flow

Find Record → Modify Object → Commit → Database Updated

✏️ Updating a Record

student = session.get(Student, 1)

if student:
    student.name = "Saloni Tiwari"
    student.course = "Data Science"

    session.commit()

🔑 Finding a Record

student = session.get(Student, 1)

if student is None:
    print("Student not found")
else:
    print(student.name)

Checking for None prevents the program from trying to modify a record that does not exist.

🗑️ Delete Flow

Find Record → session.delete() → Commit → Record Removed

🗑️ Deleting a Record

student = session.get(Student, 1)

if student:
    session.delete(student)
    session.commit()
else:
    print("Student not found")

🔎 Update Using a Condition

statement = select(Student).where(
    Student.email == "saloni@example.com"
)

student = session.scalars(
    statement
).one_or_none()

if student:
    student.course = "Data Science"
    session.commit()

🔄 Update vs Delete

SQLAlchemy Update and Delete Comparison
Operation Action Save
Update Modify object attributes session.commit()
Delete session.delete() session.commit()

↩️ Rollback

try:
    student.course = "Data Science"
    session.commit()

except Exception:
    session.rollback()
    raise

Rollback cancels uncommitted changes after a transaction failure.

⭐ Key Takeaways

  • Update modifies an existing database record.
  • Delete removes an existing database record.
  • Find the object before updating or deleting it.
  • Modify attributes to perform an update.
  • Use session.delete() to mark an object for deletion.
  • Use session.commit() to save the transaction.
  • Use session.rollback() after transaction failures.
  • Always handle records that may not exist.
