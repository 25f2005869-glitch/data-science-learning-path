## 📌 Introduction

CRUD represents the four fundamental database operations:

- **Create** — Add records
- **Read** — Retrieve records
- **Update** — Modify records
- **Delete** — Remove records

Day 079 covered Create and Read.

Day 080 focuses on **Update and Delete** using SQLAlchemy ORM.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- Update operations
- Delete operations
- Finding records before modification
- Changing model attributes
- `session.commit()`
- `session.delete()`
- `session.get()`
- `where()`
- Rollback
- Handling missing records
- Complete CRUD workflow
