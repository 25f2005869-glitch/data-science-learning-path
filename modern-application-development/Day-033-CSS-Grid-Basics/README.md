## 📌 Introduction

Day 033 introduces CSS Grid, a two-dimensional layout system used to create layouts with rows and columns.

## 🎯 Learning Objectives

- Understand CSS Grid.
- Create grid containers and grid items.
- Define rows and columns.
- Use `grid-template-columns`.
- Use `grid-template-rows`.
- Understand `fr`, `repeat()` and `gap`.
- Create basic responsive grids.
