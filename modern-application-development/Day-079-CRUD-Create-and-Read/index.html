📌 What is CRUD?

C — Create

Adds new records to the database.

R — Read

Retrieves records from the database.

U — Update

Modifies existing records.

D — Delete

Removes records from the database.

Day 079 focuses on the first two operations: Create and Read.

🔄 Create Flow

Python Object → session.add() → commit() → Database

➕ Creating a Record

student = Student(
    name="Saloni",
    email="saloni@example.com",
    age=17
)

session.add(student)
session.commit()

add() places the object into the session. commit() saves the transaction.

➕ Adding Multiple Records

session.add_all([
    Student(
        name="Saloni",
        email="saloni@example.com"
    ),
    Student(
        name="Rahul",
        email="rahul@example.com"
    ),
    Student(
        name="Anita",
        email="anita@example.com"
    )
])

session.commit()

🔍 Read Flow

select(Model) → scalars() → all() → Python Objects

📖 Reading All Records

from sqlalchemy import select

statement = select(Student)

students = session.scalars(
    statement
).all()

for student in students:
    print(student.name)

🎯 Read Methods

Common SQLAlchemy Reading Methods
Method Purpose
all() Returns all matching records
first() Returns the first matching record
one_or_none() Returns one record or None
get() Finds a record by primary key

🔎 Filtering Records

statement = select(Student).where(
    Student.age >= 18
)

students = session.scalars(
    statement
).all()

The where() method allows us to retrieve records that satisfy a condition.

🔑 Reading by Primary Key

student = session.get(Student, 1)

if student is None:
    print("Student not found")
else:
    print(student.name)

⭐ Key Takeaways

  • Create adds new database records.
  • Read retrieves existing records.
  • session.add() adds one object.
  • session.add_all() adds multiple objects.
  • session.commit() saves changes.
  • select() builds a SELECT query.
  • scalars() retrieves ORM objects.
  • all() retrieves all matching results.
  • first() retrieves the first result.
  • session.get() is useful for primary-key lookup.
