## 📌 Introduction

CRUD stands for:

- **C — Create**
- **R — Read**
- **U — Update**
- **D — Delete**

This day focuses specifically on the first two operations:

**Create** — inserting new records into a database.

**Read** — retrieving records from a database.

SQLAlchemy allows these operations to be performed using Python models and objects.
