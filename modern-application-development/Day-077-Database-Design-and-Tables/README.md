## 📌 Introduction

Database design is the process of organizing data into tables and defining relationships between them.

In this day, we learn how to design tables, choose columns and data types, identify primary keys, use constraints, and create well-structured SQLite databases.

## 🎯 Learning Objectives

- Understand database design.
- Identify entities and attributes.
- Design relational tables.
- Choose appropriate data types.
- Understand primary keys.
- Learn common SQL constraints.
- Create tables using SQLite.
- Understand relationships between tables.
- Avoid unnecessary data duplication.
- Design tables for Flask applications.
