## 📖 Introduction

CRUD stands for Create, Read, Update, and Delete.

A CRUD module allows a Flask application to create new records, display existing records, modify records, and remove records from a database.

## 🎯 Learning Objectives

- Understand the complete CRUD lifecycle.
- Connect Flask routes with database operations.
- Use SQLAlchemy for CRUD operations.
- Create forms for adding and editing records.
- Display database records with Jinja2.
- Validate user input.
- Use redirects and flash messages.
- Handle database errors safely.
