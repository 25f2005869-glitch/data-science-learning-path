Day 070 — Redirects and url_for()

Flask navigation, URL generation and Post/Redirect/Get

Redirect url_for() Dynamic URLs PRG

🔀 Core Concepts

redirect()

Tells the browser to navigate to another URL.

redirect("/home")

url_for()

Generates a URL for a Flask endpoint.

url_for("home")

1. Flask Redirect

A redirect tells the browser to make another request to a different URL. 

from flask import redirect

@app.route("/old")
def old():
    return redirect("/new")

The browser receives a redirect response and then requests the new location.

2. url_for()

url_for() generates a URL from a Flask endpoint name. 

@app.route("/")
def home():
    return "Home"

url_for("home")

If the endpoint is home, Flask generates the URL associated with that endpoint.

3. Redirect + url_for()

return redirect(url_for("home"))

This is one of the most commonly used Flask navigation patterns.

url_for() → Generates the URL

↓

redirect() → Tells the browser to navigate

4. Endpoint

@app.route("/about")
def about():
    return "About"

The endpoint is normally:

about

Therefore:

url_for("about")

5. Dynamic URL

@app.route("/student/<int:student_id>")
def student(student_id):
    return f"Student {student_id}"

Generate the URL using:

url_for("student", student_id=101)

Result:

/student/101

6. Query Parameters

Extra keyword arguments can be used to generate query parameters when they are not route variables.

url_for("search", q="python", page=2)

Result:

/search?q=python&page=2

7. Jinja2 Template Usage

<a href="{{ url_for('home') }}">
    Home
</a>

<a href="{{ url_for('student', student_id=101) }}">
    Student
</a>

Using url_for() in templates avoids hard-coding internal application URLs.

This pattern is commonly used after successful form submissions.

9. Flask PRG Example

@app.route("/register", methods=["GET", "POST"])
def register():

    if request.method == "POST":
        name = request.form.get("name", "").strip()

        if not name:
            return "Name is required", 400

        return redirect(url_for("success"))

    return "Registration Form"

10. Redirect Status Codes

Status Code Meaning
301 Permanent Redirect
302 Found
303 See Other
307 Temporary Redirect
308 Permanent Redirect

Flask's redirect() uses a temporary redirect by default. A specific status code can be supplied when needed.

11. redirect() vs url_for()

Function Purpose Example
redirect() Redirect browser redirect("/home")
url_for() Generate URL url_for("home")
Both Generate and redirect redirect(url_for("home"))

12. Common Mistakes

  • Passing /home directly to url_for().
  • Forgetting the endpoint name.
  • Using the wrong endpoint name.
  • Forgetting required dynamic route parameters.
  • Using POST without allowing POST on the route.
  • Hard-coding internal URLs unnecessarily.

13. Mental Model

url_for() asks Flask: "What URL belongs to this endpoint?"

redirect() tells the browser: "Go to this URL."

Therefore:

redirect(url_for("home"))
