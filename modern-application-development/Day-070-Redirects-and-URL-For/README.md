## 📖 Introduction

Flask provides `redirect()` and `url_for()` to control navigation between routes.

`redirect()` tells the browser to make another request to a different URL.

`url_for()` generates a URL for a Flask endpoint instead of manually writing the URL.

These tools are especially important when handling forms and implementing the Post/Redirect/Get pattern.
