# 📘 Day 004 - HTML Elements and Attributes

## What is an HTML Element?

An HTML Element is the basic building block of an HTML webpage.

Example:

```html
<h1>Hello World</h1>
```

This complete line is called an **HTML Element**.

---

## Structure of an HTML Element

```html
<tagname>Content</tagname>
```

Example

```html
<p>This is a paragraph.</p>
```

---

## Opening Tag

Marks the beginning of an element.

```html
<h1>
```

---

## Closing Tag

Marks the end of an element.

```html
</h1>
```

---

## Content

Everything written between the opening and closing tags.

```html
<h1>Hello</h1>
```

Content = **Hello**

---

## Nested Elements

One HTML element can contain another.

Example

```html
<p>
    Welcome to <strong>HTML</strong>.
</p>
```

---

## Empty Elements

Some HTML elements do not have closing tags.

Examples

```html
<hr>

<br>

<img>
```

---

# What is an HTML Attribute?

An attribute provides additional information about an element.

Syntax

```html
<tag attribute="value">
```

Example

```html
<a href="https://google.com">
```

---

# Common HTML Attributes

## id

Gives a unique identifier.

```html
<p id="intro">
```

---

## class

Groups similar elements.

```html
<p class="text">
```

---

## title

Displays a tooltip.

```html
<p title="This is a tooltip">
```

---

## href

Specifies the destination of a link.

```html
<a href="https://google.com">
```

---

## src

Specifies the source of an image.

```html
<img src="image.png">
```

---

## alt

Alternative text for an image.

```html
<img src="image.png" alt="HTML Logo">
```

---

## width

Specifies image width.

```html
<img width="300">
```

---

## height

Specifies image height.

```html
<img height="200">
```
