# Part B - MCQs

### 1.

- [ ] A. `<h1>Hello</h1>`
- [ ] B. `href`
- [ ] C. `src`
- [ ] D. `id`

**Answer:** A

---

### 2.

Which attribute is used for hyperlinks?

- [ ] A. src
- [ ] B. href
- [ ] C. alt
- [ ] D. class

**Answer:** B

---

### 3.

Which attribute specifies an image source?

- [ ] A. src
- [ ] B. href
- [ ] C. title
- [ ] D. id

**Answer:** A

---

### 4.

Which attribute displays tooltip text?

- [ ] A. width
- [ ] B. title
- [ ] C. alt
- [ ] D. class

**Answer:** B
