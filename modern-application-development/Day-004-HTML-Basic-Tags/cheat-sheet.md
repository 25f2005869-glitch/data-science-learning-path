# 📋 Day 004 - Cheat Sheet

## HTML Element

```html
<tag>Content</tag>
```

Example

```html
<h1>Hello</h1>
```

---

## Opening Tag

```html
<h1>
```

---

## Closing Tag

```html
</h1>
```

---

## Empty Elements

```html
<hr>

<br>

<img>
```

---

## HTML Attribute

```html
<tag attribute="value">
```

---

## Common Attributes

| Attribute | Purpose |
|-----------|---------|
| id | Unique Identifier |
| class | Group Elements |
| title | Tooltip |
| href | Link Destination |
| src | Image Source |
| alt | Image Description |
| width | Width |
| height | Height |

---

## Remember

```
Element

↓

Opening Tag

↓

Content

↓

Closing Tag

↓

Attributes
```
