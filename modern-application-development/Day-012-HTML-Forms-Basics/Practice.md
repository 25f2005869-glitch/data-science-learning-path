# 🎯 Section 2 — MCQs

## Q1. Which element is used to create a form?

A. `<input>`

B. `<form>`

C. `<fieldset>`

D. `<data>`

**Answer:** B

---

## Q2. Which element is used to create a label?

A. `<label>`

B. `<text>`

C. `<caption>`

D. `<name>`

**Answer:** A

---

## Q3. Which input type is suitable for an email address?

A. `text`

B. `mail`

C. `email`

D. `address`

**Answer:** C

---

## Q4. Which input type hides entered characters?

A. `hidden`

B. `password`

C. `private`

D. `secure`

**Answer:** B

---

## Q5. Which attribute makes a field mandatory?

A. `important`

B. `required`

C. `mandatory`

D. `must`

**Answer:** B

---

## Q6. Which attribute connects a label to an input?

A. `connect`

B. `for`

C. `target`

D. `link`

**Answer:** B

---

## Q7. Which attribute should normally identify a submitted form field?

A. `name`

B. `title`

C. `class`

D. `style`

**Answer:** A

---

## Q8. Which button type submits a form?

A. `send`

B. `submit`

C. `form`

D. `enter`

**Answer:** B

---

## Q9. Which button type resets the form?

A. `clear`

B. `reset`

C. `remove`

D. `restart`

**Answer:** B

---

## Q10. Which attribute specifies where form data is sent?

A. `target`

B. `destination`

C. `action`

D. `sendto`

**Answer:** C
