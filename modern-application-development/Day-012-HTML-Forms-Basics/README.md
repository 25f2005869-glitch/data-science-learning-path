## 📝 What is an HTML Form?

An HTML form is a section of a webpage that allows users to enter and submit information.

For example:

```text
Name:     [____________]
Email:    [____________]
Password: [____________]

          [ Submit ]

A basic form can be created using:

<form>

    <label for="name">Name:</label>

    <input
        type="text"
        id="name"
        name="name">

    <button type="submit">
        Submit
    </button>
