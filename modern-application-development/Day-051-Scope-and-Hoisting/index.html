Day 051 — Scope and Hoisting

Understanding JavaScript variable visibility and declaration behavior

📖 What is Scope?

Scope determines where a variable, function, or identifier can be accessed in JavaScript.

Global Scope Available from the global scope.
Function Scope Created by functions, especially for var.
Block Scope Created by blocks for let and const.
Lexical Scope Determined by where code is written.

🔗 Scope Chain

JavaScript searches for variables from the current scope and then moves outward through the scope chain. 

Current Scope
     ↓
Outer Scope
     ↓
Global Scope

👤 Variable Shadowing

Shadowing occurs when an inner scope declares a variable with the same name as a variable in an outer scope. 

let course = "HTML";

function learn() {
    let course = "JavaScript";
    console.log(course);
}

learn();

⬆️ Hoisting

Hoisting describes how JavaScript processes declarations before executing the code.

var

console.log(score);
var score = 90;

// Output:
// undefined

let

console.log(score);
let score = 90;

// Result:
// ReferenceError

const

console.log(course);
const course = "MAD 1";

// Result:
// ReferenceError

⏳ Temporal Dead Zone

The Temporal Dead Zone is the period between entering a scope and the initialization of a let or const variable. 

console.log(name);

let name = "Saloni";

// ReferenceError

⚡ Function Hoisting

Function declarations can be called before their declaration. 

greet();

function greet() {
    console.log("Hello!");
}

🎓 Student Scope Example

let student = "Saloni";

function studentDetails() {
    let score = 92;

    if (score >= 90) {
        const grade = "A";
        console.log(student);
        console.log(score);
        console.log(grade);
    }
}

studentDetails();

The function can access the global student, its local score, and the block-scoped grade.

🧠 Key Takeaways

  • Scope controls variable accessibility.
  • var is function-scoped.
  • let and const are block-scoped.
  • JavaScript uses a scope chain to find variables.
  • Inner scopes can access suitable outer variables.
  • Variable shadowing occurs when inner and outer variables share a name.
  • var is initialized as undefined during hoisting.
  • let and const remain in the Temporal Dead Zone until initialization.
  • Function declarations are hoisted.
  • In modern JavaScript, prefer const and let.
