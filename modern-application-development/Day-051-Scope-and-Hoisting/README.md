## 📖 Introduction

Scope defines where a variable or function can be accessed in JavaScript.

Hoisting describes how JavaScript processes declarations before executing code.

Understanding scope and hoisting is important for writing predictable and maintainable JavaScript programs.

---

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What scope means in JavaScript
- Global, function, and block scope
- Scope chain
- Lexical scope
- `var`, `let`, and `const` scope
- What hoisting means
- Hoisting behavior of variables
- Hoisting of function declarations
- Temporal Dead Zone (TDZ)
- Common scope and hoisting mistakes
