🧩 What Is a Blueprint?

A Flask Blueprint is a modular component used to organize related routes and application functionality.

👨‍🎓 Student

Handles student-related routes and functionality.

📚 Course

Handles course-related routes and functionality.

🔐 Authentication

Handles login, logout and authentication routes.

1. Why Use Blueprints?

A small Flask application can keep its routes in app.py. As the application grows, this can become difficult to maintain.

Blueprints allow related routes to be separated into independent modules.

2. Creating a Blueprint

from flask import Blueprint

student_bp = Blueprint(
    "student",
    __name__
)

The first argument is the Blueprint name. The second argument is normally __name__.

3. Blueprint Route

@student_bp.route("/students")
def students():
    return "Students"

Routes are attached to the Blueprint instead of directly to the Flask application object.

4. Registering a Blueprint

from flask import Flask

app = Flask(__name__)

app.register_blueprint(student_bp)

A Blueprint must be registered with the Flask application before its routes become available.

6. URL Prefix

student_bp = Blueprint(
    "student",
    __name__,
    url_prefix="/students"
)

@student_bp.route("/")
def list_students():
    return "Student List"

The route becomes:

/students/

7. Blueprint Endpoints

student_bp = Blueprint("student", __name__)

@student_bp.route("/profile")
def profile():
    return "Profile"

The endpoint is generally:

student.profile

Generate its URL using:

url_for("student.profile")

11. Flask App vs Blueprint

Flask Application Blueprint
Main application object Modular application component
Created with Flask() Created with Blueprint()
Runs the application Does not run independently
Registers Blueprints Gets registered with the application
app.route() blueprint.route()

12. Common Mistakes

  • Creating a Blueprint but forgetting to register it.
  • Using app.route() instead of the Blueprint route.
  • Using the wrong Blueprint endpoint in url_for().
  • Forgetting required dynamic route parameters.
  • Accidentally repeating a URL prefix.
