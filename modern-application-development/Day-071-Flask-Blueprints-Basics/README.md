## 📖 Introduction

Flask Blueprints provide a way to organize a larger Flask application into smaller, reusable components.

Instead of keeping every route inside one large `app.py` file, related routes can be grouped into separate modules.

## 🎯 Learning Objectives

- Understand Flask Blueprints.
- Learn why Blueprints are useful.
- Create a Blueprint.
- Register a Blueprint with an application.
- Organize routes into modules.
- Understand Blueprint URL prefixes.
- Understand Blueprint endpoints.
