# 📋 Day 005 - Cheat Sheet

## Headings

```html
<h1>Main Heading</h1>
<h2>Heading</h2>
<h3>Heading</h3>
<h4>Heading</h4>
<h5>Heading</h5>
<h6>Heading</h6>
```

---

## Paragraph

```html
<p>This is a paragraph.</p>
```

---

## Line Break

```html
<br>
```

Moves content to the next line.

---

## Horizontal Rule

```html
<hr>
```

Creates a horizontal line.

---

## Best Practices

✅ One `<h1>` per page

✅ Use headings in order

✅ Use paragraphs for text

✅ Use `<br>` for line breaks

✅ Use `<hr>` to separate sections

---
