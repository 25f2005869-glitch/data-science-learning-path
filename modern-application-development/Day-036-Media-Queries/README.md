## 📌 Introduction

Day 036 focuses on CSS Media Queries, which allow different CSS rules to be applied according to conditions such as viewport width, height, orientation and media type.

## 🎯 Learning Objectives

- Understand Media Queries.
- Write `@media` rules.
- Create responsive breakpoints.
- Use `min-width` and `max-width`.
- Understand mobile-first design.
- Combine Media Queries with Flexbox and Grid.
- Handle different screen sizes.
