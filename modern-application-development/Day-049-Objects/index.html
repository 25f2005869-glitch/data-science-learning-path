📚 What Is an Object?

An object stores related information as key-value pairs. 

const student = {
    name: "Saloni",
    age: 17,
    course: "MAD1"
};

🔑 Dot Notation

student.name
student.age
student.course

Used when the property name is known directly.

🔑 Bracket Notation

student["name"]

const key = "course";
student[key]

Useful when the property name is dynamic.

🔧 Object Method

const student = {
    name: "Saloni",

    greet() {
        return `Hello ${this.name}`;
    }
};

🧰 Object Operations

Operation Example
Access student.name
Add student.email = "example@email.com"
Update student.age = 18
Delete delete student.email
Keys Object.keys(student)
Values Object.values(student)
Entries Object.entries(student)

📚 Array of Objects

An array can contain multiple objects representing similar entities. 

const students = [
    { name: "Asha", marks: 85 },
    { name: "Riya", marks: 92 },
    { name: "Neha", marks: 78 }
];
