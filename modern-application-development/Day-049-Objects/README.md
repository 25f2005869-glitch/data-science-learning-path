## 📌 Introduction

Objects are JavaScript data structures used to store related information as key-value pairs.

## 🎯 Learning Objectives

- Understand JavaScript objects.
- Create and access object properties.
- Add, update, and delete properties.
- Use dot and bracket notation.
- Create methods inside objects.
- Understand nested objects.
- Work with arrays of objects.
- Use objects with loops and functions.
