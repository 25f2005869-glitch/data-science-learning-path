## 📖 Introduction

HTML forms allow users to enter and submit data to a web application.

In Flask, submitted form data can be received through the request object.

This day focuses on connecting HTML forms with Flask request methods, especially **GET** and **POST**.

## 🎯 Learning Objectives

- Understand HTML forms in Flask.
- Understand GET and POST requests.
- Learn the `request` object.
- Read form data using `request.args`.
- Read submitted form data using `request.form`.
- Understand form `action` and `method`.
- Understand query parameters.
- Understand form submission flow.
