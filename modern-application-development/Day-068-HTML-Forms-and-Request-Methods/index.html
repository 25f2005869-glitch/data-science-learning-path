Day 068 — HTML Forms and Request Methods

Connecting HTML forms with Flask request handling

Form GET vs POST Flask Workflow

1. HTML Form

An HTML form collects information from the user and sends it to a server.

<form action="/register" method="POST">
  <input type="text" name="name">
  <button type="submit">Register</button>
</form>

2. GET and POST

🔎 GET

GET is commonly used for retrieving data.

<form action="/search" method="GET">

Flask reads query parameters using:

request.args.get("q")

📤 POST

POST is commonly used for submitting or changing data.

<form action="/register" method="POST">

Flask reads form data using:

request.form.get("name")

3. GET vs POST Comparison

Feature GET POST
Common purpose Retrieve data Submit/process data
Data location URL query string Request body
Visible in URL Yes Normally no
Search Common choice Usually unnecessary
Registration Usually inappropriate Common choice

4. Flask Request Handling

Import the request object:

from flask import Flask, request

For GET query parameters:

query = request.args.get("q", "")

For POST form data:

name = request.form.get("name", "")

To check the request method:

if request.method == "POST":

5. Route Supporting GET and POST

@app.route("/register", methods=["GET", "POST"])
def register():

    if request.method == "POST":
        name = request.form.get("name")
        return f"Registered: {name}"

    return "Show registration form"

8. Form Submission Workflow

1. User opens the form.

2. User enters information.

3. User submits the form.

4. Browser creates an HTTP request.

5. Request is sent to the form action.

6. Flask receives the request.

7. Flask checks request.method.

8. Flask reads request.args or request.form.

9. Server validates and processes the data.

10. Flask sends a response.

9. Important Rules

  • Use GET commonly for retrieval and search.
  • Use POST commonly for data submission or state changes.
  • Use request.args for query parameters.
  • Use request.form for POST form fields.
  • Use meaningful name attributes.
  • Always perform important validation on the server.
  • POST does not itself encrypt data.
  • Use HTTPS when transmitting sensitive information.
