## 📖 Introduction

CSS provides powerful properties for controlling the appearance, readability, and presentation of text on a webpage.

On Day 024, we learn how to style fonts and text using CSS.

We will learn how to control:

- Font family
- Font size
- Font weight
- Font style
- Font variant
- Line height
- Text alignment
- Text decoration
- Text transformation
- Text indentation
- Letter spacing
- Word spacing
- Text shadow
- Font shorthand
- Web-safe fonts
- Font stacks
- Readability and accessibility

---

## 🎯 Learning Objectives

By the end of this day, you should be able to:

- Understand CSS font properties.
- Use different font families.
- Set appropriate font sizes.
- Control font weight and style.
- Understand serif, sans-serif, monospace, cursive, and fantasy fonts.
- Use font stacks and fallback fonts.
- Control line spacing with `line-height`.
- Align text using `text-align`.
- Add and remove text decoration.
- Transform text using `text-transform`.
- Control letter and word spacing.
- Add indentation using `text-indent`.
- Create text shadows.
- Use the `font` shorthand property.
- Apply readable and accessible typography.
