## 🎨 Font Properties

| Property | Purpose | Example |
|---|---|---|
| `font-family` | Select font | `font-family: Arial, sans-serif;` |
| `font-size` | Set text size | `font-size: 18px;` |
| `font-weight` | Set thickness | `font-weight: 700;` |
| `font-style` | Normal/italic/oblique | `font-style: italic;` |
| `font-variant` | Small capitals | `font-variant: small-caps;` |
| `line-height` | Vertical line spacing | `line-height: 1.6;` |

---

## 📝 Text Properties

| Property | Purpose | Example |
|---|---|---|
| `text-align` | Horizontal alignment | `text-align: center;` |
| `text-decoration` | Decoration | `text-decoration: underline;` |
| `text-transform` | Change capitalization | `text-transform: uppercase;` |
| `text-indent` | First-line indentation | `text-indent: 30px;` |
| `letter-spacing` | Character spacing | `letter-spacing: 2px;` |
| `word-spacing` | Word spacing | `word-spacing: 8px;` |
| `text-shadow` | Add text shadow | `text-shadow: 2px 2px 4px gray;` |

## 🌑 Text Shadow Syntax

    text-shadow: x-offset y-offset blur color;

Example:

    text-shadow: 2px 2px 4px gray;

---

## 🚀 Font Shorthand

    font: style weight size/line-height family;

Example:

    font: italic 700 20px/1.5 Arial, sans-serif;

## 🧠 Quick Memory

    FAMILY  → Which font?
    SIZE    → How big?
    WEIGHT  → How thick?
    STYLE   → Italic or normal?
    HEIGHT  → Line spacing?
    ALIGN   → Where?
    DECOR   → Underline?
    TRANSFORM → Uppercase/lowercase?
    SPACING → Letters/words?
    SHADOW  → Visual effect?

## 📌 Important

Good typography should prioritize:

- Readability
- Accessibility
- Consistency
- Proper hierarchy
- Sufficient contrast
- Appropriate spacing
