## 🧱 Basic Syntax

The basic syntax is:

```html
<input type="text">

The value of the type attribute determines the kind of input control.

For example:

text      → Text field
email     → Email field
password  → Password field
number    → Number field
date      → Date field
checkbox  → Checkbox
radio     → Radio button
