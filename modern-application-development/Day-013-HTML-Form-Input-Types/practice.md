# 🎯 Section 2 — MCQs

## Q1. Which input type is designed for email addresses?

A. `text`

B. `mail`

C. `email`

D. `address`

**Answer:** C

---

## Q2. Which input type hides entered characters?

A. `hidden`

B. `password`

C. `private`

D. `secure`

**Answer:** B

---

## Q3. Which input type is appropriate for a phone number?

A. `number`

B. `phone`

C. `tel`

D. `telephone`

**Answer:** C

---

## Q4. Which input type allows a user to select a date?

A. `calendar`

B. `date`

C. `day`

D. `datetime`

**Answer:** B

---

## Q5. Which input type is normally used when one option should be selected from a group?

A. `checkbox`

B. `radio`

C. `select`

D. `choice`

**Answer:** B

---

## Q6. Which input type allows multiple independent choices?

A. `radio`

B. `checkbox`

C. `multiple`

D. `options`

**Answer:** B

---

## Q7. Which input type is used to select a file?

A. `upload`

B. `document`

C. `file`

D. `attachment`

**Answer:** C

---

## Q8. Which input type creates a slider?

A. `slider`

B. `range`

C. `scale`

D. `progress`

**Answer:** B

---

## Q9. Which input type is intended for website addresses?

A. `website`

B. `link`

C. `url`

D. `web`

**Answer:** C

---

## Q10. Which input type is used for search queries?

A. `find`

B. `search`

C. `query`

D. `lookup`

**Answer:** B
