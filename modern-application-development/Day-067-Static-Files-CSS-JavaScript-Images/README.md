## 📖 Introduction

Flask applications commonly use static files such as CSS, JavaScript, images, fonts, and other assets.

Flask normally serves these files from a `static/` directory.

Jinja2 provides the `url_for()` function to generate correct URLs for static files.

## 🎯 Learning Objectives

- Understand Flask static files.
- Learn the purpose of the `static/` folder.
- Serve CSS files with Flask.
- Serve JavaScript files with Flask.
- Display images from the static folder.
- Use `url_for('static', filename=...)`.
- Organize static assets correctly.
