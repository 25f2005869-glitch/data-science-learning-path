Day 067 — Flask Static Files

CSS, JavaScript, Images and Static Asset Management

Concept Structure url_for() Workflow

What Are Static Files?

Static files are assets that are served to the browser, such as CSS, JavaScript, images, fonts and icons.

🎨 CSS

Controls the visual appearance of the application.

static/css/style.css

⚙️ JavaScript

Adds browser-side interaction and behavior.

static/js/script.js

🖼️ Images

Provides visual assets for the application.

static/images/logo.png

Flask Project Structure

project/
├── app.py
├── templates/
│   ├── base.html
│   └── home.html
└── static/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    └── images/
        └── logo.png

The templates directory contains Jinja2 templates, while the static directory contains frontend assets.

Using url_for()

Flask provides url_for() to generate URLs for static files.

CSS

{{ url_for('static', filename='css/style.css') }}

JavaScript

{{ url_for('static', filename='js/script.js') }}

Image

{{ url_for('static', filename='images/logo.png') }}

CSS Example

<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">

The stylesheet can be stored separately inside static/css/.

JavaScript Example

<script src="{{ url_for('static', filename='js/script.js') }}"> </script>

JavaScript files can be organized inside static/js/.

Image Example

<img src="{{ url_for('static', filename='images/logo.png') }}" alt="Website Logo">

Images can be stored inside static/images/.

Static Files vs Templates

Directory Purpose Examples
templates/ Jinja2 templates base.html, home.html
static/css/ Stylesheets style.css
static/js/ JavaScript script.js
static/images/ Images logo.png, profile.jpg

Static File Request Workflow

1. Browser requests a Flask page.

2. Flask renders the Jinja2 template.

3. The generated HTML contains static URLs.

4. Browser requests CSS, JavaScript and images.

5. Flask serves the corresponding static assets.

6. Browser uses the assets to render the page.

Best Practices

  • Keep CSS inside static/css/.
  • Keep JavaScript inside static/js/.
  • Keep images inside static/images/.
  • Use url_for() for static URLs.
  • Use meaningful filenames.
  • Do not store passwords or API keys in static files.
  • Keep templates and static assets separate.
