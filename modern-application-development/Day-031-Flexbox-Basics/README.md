## 📌 Introduction

Day 031 introduces CSS Flexbox, a powerful one-dimensional layout system used to arrange, align and distribute elements inside a container.

## 🎯 Learning Objectives

- Understand Flexbox.
- Create a flex container.
- Understand main axis and cross axis.
- Use `flex-direction`.
- Use `justify-content`.
- Use `align-items`.
- Use `flex-wrap`.
- Use `gap`.
- Understand flex items.
- Build simple responsive layouts.
