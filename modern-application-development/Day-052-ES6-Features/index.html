Day 052 — ES6 Features

Modern JavaScript syntax and features

🚀 What is ES6?

ES6, also known as ECMAScript 2015, introduced many features that made JavaScript more modern, concise, and maintainable.

let / const Modern block-scoped declarations.
Arrow Functions Concise function syntax.
Destructuring Extract values from arrays and objects.
Spread / Rest Expand or collect values.

🔤 Template Literals

const name = "Saloni";
const course = "MAD 1";

const message = `Student: ${name}, Course: ${course}`;

⚡ Arrow Functions

const add = (a, b) => a + b;

const square = x => x * x;

📦 Destructuring

Array Destructuring

const marks = [90, 85, 95];

const [first, second, third] = marks;

Object Destructuring

const student = {
    name: "Saloni",
    course: "MAD 1",
    score: 95
};

const { name, course, score } = student;

📋 Spread and Rest

Spread

const frontend = ["HTML", "CSS"];
const programming = ["JavaScript", "Python"];

const skills = [...frontend, ...programming];

Rest

function total(...numbers) {
    return numbers.reduce((sum, number) => sum + number, 0);
}

🔁 for...of

const courses = ["HTML", "CSS", "JavaScript"];

for (const course of courses) {
    console.log(course);
}

🛡️ Optional Chaining

const student = {
    profile: {
        name: "Saloni"
    }
};

console.log(student.profile?.name);
console.log(student.address?.city);

❓ Nullish Coalescing

const score = null;

const finalScore = score ?? 0;

console.log(finalScore);

🏗️ Enhanced Object Literals

const name = "Saloni";
const course = "MAD 1";

const student = {
    name,
    course,

    greet() {
        return `Hello, ${this.name}`;
    }
};

🎓 Student ES6 Example

const student = {
    name: "Saloni",
    course: "MAD 1",
    score: 95,
    skills: ["HTML", "CSS", "JavaScript"]
};

const { name, course, score, skills } = student;

const message = `
Student: ${name}
Course: ${course}
Score: ${score}
Skills: ${skills.join(", ")}
`;

📊 ES6 Feature Summary

Feature Purpose
let / const Modern variable declarations
Arrow Function Concise function syntax
Template Literal String interpolation
Destructuring Extract values
Spread Expand values
Rest Collect values
for...of Iterate over values
Optional Chaining Safe property access
Nullish Coalescing Handle null or undefined
