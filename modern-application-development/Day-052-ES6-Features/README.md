## 📖 Introduction

ES6, also called ECMAScript 2015, introduced many important features that made JavaScript cleaner, safer, and easier to write.

This day focuses on the most useful ES6 features for modern JavaScript development.

---

## 🎯 Learning Objectives

By the end of this day, you will understand:

- `let` and `const`
- Arrow functions
- Template literals
- Default parameters
- Destructuring
- Spread operator
- Rest parameters
- Enhanced object literals
- `for...of`
- Modules basics
- Optional chaining
- Nullish coalescing
