📌 What Are Flash Messages?

Flash messages provide temporary feedback to users after an operation.

Success

Student created successfully.

Error

Invalid email address.

Warning

Please check your information.

Info

Your profile was updated.

🐍 Flask Flash Message

from flask import flash

flash("Registration successful.", "success")
flash("Invalid email address.", "error")

Categories allow the application to style or process different types of messages.

🧩 Displaying Flash Messages

{% with messages = get_flashed_messages(with_categories=true) %}
    {% for category, message in messages %}
        <div class="{{ category }}">
            {{ message }}
        </div>
    {% endfor %}
{% endwith %}

✅ Validation

Validation checks whether user input satisfies the application's requirements.

  • Required fields
  • Correct data types
  • Minimum and maximum length
  • Numeric ranges
  • Allowed choices
  • Business rules

🌐 Client-Side vs Server-Side Validation

Client-Side

Runs in the browser and provides fast feedback. It can be bypassed.

Server-Side

Runs on the server and must always validate submitted data before processing it.

📝 Validation Demo

🔐 Server-Side Validation Example

name = request.form.get("name", "").strip()

if not name:
    flash("Name is required.", "error")
    return redirect(url_for("register"))

The server should validate the submitted value even when the browser already performs HTML validation.

🛡️ Important Security Rule

Never trust user input.

Validate form data, query parameters, URL parameters and other externally supplied values on the server.

Validation is one security layer. It does not replace authentication, authorization, CSRF protection, output escaping or parameterized database queries.
