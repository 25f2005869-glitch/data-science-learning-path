## 📌 Introduction

Flash messages provide temporary feedback to users after an action.

Examples:

- Registration successful
- Login failed
- Record deleted
- Invalid input
- Access denied

Validation checks whether user-provided data satisfies the application's requirements.

Together, flash messages and validation help create reliable and user-friendly Flask applications.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What flash messages are

- The importance of `SECRET_KEY`
