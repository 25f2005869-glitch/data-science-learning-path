## 📖 Introduction

Day 022 focuses on CSS Selectors.

CSS selectors are used to select HTML elements that need to be styled.

Selectors are one of the most important foundations of CSS because they determine exactly which HTML elements receive a particular style.

---

```text
HTML Element
     ↓
CSS Selector
     ↓
Select Element
     ↓
Apply CSS Rule

    color: blue;
}

Here:

p → selector
color → property
blue → value
