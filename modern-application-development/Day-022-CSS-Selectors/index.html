Day 022 — Learning how CSS selects HTML elements.

What is a CSS Selector?

A CSS selector identifies the HTML elements that should receive a particular CSS rule.

Selectors are one of the most important foundations of CSS.

Basic Selectors

Element Selector

The element selector targets HTML elements such as paragraphs, headings, and lists.

Class Selector

The class selector can be reused on multiple elements.

ID Selector

The ID selector targets an element with a specific ID.
