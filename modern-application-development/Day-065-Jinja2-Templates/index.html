📌 What is Jinja2?

Jinja2 is a template engine commonly used with Flask to create dynamic HTML pages.

Python Data → Flask → Jinja2 → HTML → Browser

🎯 Why Use Templates?

📄 Separate HTML

HTML can be stored separately from Python code.

🔄 Dynamic Data

Python variables can be displayed dynamically.

♻️ Reusable Layouts

Template inheritance reduces repeated HTML.

📁 Template Structure

flask-project/ │ ├── app.py │ └── templates/ ├── index.html ├── about.html └── student.html

🖥️ `render_template()`

from flask import Flask, render_template app = Flask(__name__) @app.route("/") def home(): return render_template("index.html")

📤 Passing Variables

@app.route("/") def home(): name = "Saloni" course = "MAD 1" score = 95 return render_template( "index.html", name=name, course=course, score=score )

The template can display these values using {{ name }}, {{ course }}, and {{ score }}.

🔀 Jinja2 Conditions

{% if score >= 50 %} <p>Pass</p> {% else %} <p>Fail</p> {% endif %}

🔁 Jinja2 Loops

{% for course in courses %} <p>{{ course }}</p> {% endfor %}

A loop can generate HTML for every item in a Python list.

🎨 Jinja2 Filters

Filter Example Purpose
upper {{ name | upper }} Uppercase text
lower {{ name | lower }} Lowercase text
title {{ name | title }} Title case
length {{ courses | length }} Length of a value
trim {{ name | trim }} Remove surrounding whitespace

💬 Jinja2 Syntax

Expression

{{ variable }}

Statement

{% statement %}

Comment

{# comment #}

🧬 Template Inheritance

{% extends "base.html" %} {% block content %} <h1>Home Page</h1> {% endblock %}

A base template can contain common elements such as the header, navigation, and footer.

🔗 Dynamic Route + Template

@app.route("/student/<int:student_id>") def student(student_id): return render_template( "student.html", student_id=student_id )

The same template can display different student IDs, such as 101, 102, and 103.

🔄 Jinja2 Flow

Python Data → Flask → render_template() → Jinja2 → HTML

🧠 Day 065 Key Points

  • Jinja2 is used for dynamic HTML templates.
  • Flask uses render_template() to render templates.
  • Python data can be passed to templates.
  • {{ }} is used for expressions.
  • {% %} is used for statements.
  • {# #} is used for Jinja2 comments.
  • Conditions and loops make templates dynamic.
  • Filters modify or format values.
  • Template inheritance allows reusable layouts.
