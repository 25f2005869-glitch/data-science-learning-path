## 📌 Introduction

Project planning is the process of deciding what to build, how to build it, what technologies are required, and how the work will be divided into manageable tasks.

This day prepares the foundation for the final MAD 1 project.

## 🎯 Learning Objectives

By the end of this day, you will understand:

- How to select a project idea
- How to define project requirements
- Functional and non-functional requirements
- User roles
- Features and modules
- Database planning
- Route planning
- Project architecture
- UI planning
- Development phases
- Testing and deployment planning
