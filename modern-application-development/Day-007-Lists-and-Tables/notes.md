# 📘 Day 007 - Lists and Tables

## What is a List?

A list is used to display multiple related items.

HTML provides three types of lists.

- Ordered List
- Unordered List
- Description List

---

# Ordered List

Displays items in numbered order.

Syntax

```html
<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>
```

Output

1. HTML
2. CSS
3. JavaScript

---

# Unordered List

Displays items using bullets.

```html
<ul>
    <li>Apple</li>
    <li>Mango</li>
    <li>Orange</li>
</ul>
```

---

# Description List

Used for terms and descriptions.

```html
<dl>

<dt>HTML</dt>

<dd>Markup Language</dd>

<dt>CSS</dt>

<dd>Styles Webpages</dd>

</dl>
```

---

# HTML Table

A table organizes data into rows and columns.

---

## Table Structure

```html
<table>

<tr>

<th>Name</th>

<th>Age</th>

</tr>

<tr>

<td>Saloni</td>

<td>18</td>

</tr>

</table>
```

---

# Table Tags

| Tag | Purpose |
|------|---------|
| table | Creates a table |
| tr | Table Row |
| th | Table Header |
| td | Table Data |

---

# colspan

Merge columns.

```html
<td colspan="2">
```

---

# rowspan

Merge rows.

```html
<td rowspan="2">
```

---

# Best Practices

- Use tables only for tabular data.
- Use headers for readability.
- Keep tables simple.
