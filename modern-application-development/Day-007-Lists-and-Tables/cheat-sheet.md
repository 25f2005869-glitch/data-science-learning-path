# 📋 Day 007 - Cheat Sheet

## Ordered List

```html
<ol>
<li>Item</li>
</ol>
```

---

## Unordered List

```html
<ul>
<li>Item</li>
</ul>
```

---

## Description List

```html
<dl>
<dt>Term</dt>
<dd>Description</dd>
</dl>
```

---

## Table

```html
<table>

<tr>

<th>Name</th>

<th>Age</th>

</tr>

<tr>

<td>Saloni</td>

<td>18</td>

</tr>

</table>
```

---

## Table Tags

table → Table

tr → Row

th → Header

td → Data

---

## Remember

```
Lists

↓

Ordered

↓

Unordered

↓

Description

↓

Tables

↓

Rows

↓

Columns
```
