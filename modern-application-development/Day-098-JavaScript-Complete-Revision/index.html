🧠 JavaScript Fundamentals

Variables

Use const by default and let when reassignment is needed.

Conditions

Use if, else, switch, and ternary expressions for conditional logic.

Loops

Use for, while, and do...while to repeat operations.

Functions

Functions package reusable logic using parameters, arguments, and return values.

Scope

Scope determines where variables can be accessed. Block and function scope are important concepts.

Errors

Use try, catch, finally, and throw when appropriate.

Strings

JavaScript strings are immutable.

Arrays

Array methods include map(), filter(), find(), and reduce().

Objects

Objects store related data as key-value pairs and can also contain methods.
