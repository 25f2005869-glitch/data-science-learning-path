## Part B — Multiple Choice Questions

### Q11. Which technique can reduce the number of records displayed at once?

A. Pagination  
B. Duplication  
C. Recursion  
D. Inheritance

**Answer:** A

---

### Q12. Which is usually better for filtering database records?

A. Retrieve everything and filter a huge list in Python  
B. Filter at the database level  
C. Ignore filtering  
D. Reload the database

**Answer:** B

---

### Q13. Which resource can strongly affect page loading speed?

A. Large images  
B. HTML comments  
C. Variable names  
D. Indentation

**Answer:** A

---

### Q14. Which practice is unsafe?

A. Password hashing  
B. HTTPS  
C. Logging passwords  
D. Input validation

**Answer:** C

---

### Q15. What should normally happen before optimization?

A. Delete the project  
B. Measure performance
