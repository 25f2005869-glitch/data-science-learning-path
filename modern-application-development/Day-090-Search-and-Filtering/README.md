## 📖 Introduction

Search and filtering allow users to find specific records from a large collection of data.

In a Flask application, search and filtering commonly use GET query parameters, SQLAlchemy queries, Jinja2 templates, and database filtering.

## 🎯 Learning Objectives

- Understand search and filtering.
- Use URL query parameters.
- Read query parameters with Flask.
- Filter database records using SQLAlchemy.
- Combine multiple filter conditions.
- Implement sorting.
- Handle empty searches.
- Build user-friendly search interfaces.
