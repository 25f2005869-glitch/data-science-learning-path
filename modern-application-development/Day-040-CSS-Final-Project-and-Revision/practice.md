# Part C — Debugging Practice

### 31. Find the problem

    .card {
        width: 100%;
        padding: 30px;
        border: 10px solid black;
    }

Explain why this can cause sizing problems and how `box-sizing` can help.

### 32. Find the problem

    .container {
        display: flex;
        justify-content: center;
    }

The user expects vertical centering too.

What property is missing?

### 33. Find the problem

    img {
        width: 800px;
    }

Why can this create problems on mobile screens?

### 34. Find the problem

    .child {
        position: absolute;
    }

The child is positioned relative to an unexpected ancestor.

What should usually be added to the intended parent?

### 35. Find the problem

    .box {
        transition: all 5s;
    }

Why can `transition: all` be undesirable?
