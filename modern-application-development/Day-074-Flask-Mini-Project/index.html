🚀 Student Learning Portal

Day 074 — Flask Mini Project

IIT Madras BS Degree — Diploma Level

📌 Project Overview

The Student Learning Portal combines the major Flask concepts learned from Day 061 to Day 073 into one practical application.

🎯 Project Features

🏠 Home Application landing page.
👩‍🎓 Student Profile Displays student information.
📚 Courses Displays available courses.
📝 Registration Processes student registration.
⚠️ Error Pages Custom 404 and 500 responses.
⚙️ Configuration Environment-based application settings.

🛣️ Example Routes

URL Purpose
/ Home page
/student Student profile
/courses Course list
/course/<course_name> Dynamic course page
/register Student registration
/success Registration success

🔗 Flask Routing

from flask import Flask app = Flask(__name__) @app.route("/") def home(): return "Student Learning Portal" @app.route("/course/<course_name>") def course(course_name): return f"Course: {course_name}"

📄 Jinja2 Templates

Flask uses Jinja2 to generate dynamic HTML pages.

from flask import render_template @app.route("/") def home(): return render_template( "index.html", student_name="Saloni" )

A template can display the value dynamically.

<h1>Welcome, {{ student_name }}!</h1>

📝 Form Processing

from flask import request @app.route("/register", methods=["GET", "POST"]) def register(): if request.method == "POST": name = request.form.get("name") email = request.form.get("email") return "Registration successful" return "Registration Form"

🔄 Redirect and url_for()

from flask import redirect, url_for return redirect(url_for("success"))

Using url_for() allows Flask to generate a URL from the endpoint name instead of hard-coding the URL.

🧩 Blueprint

from flask import Blueprint student_bp = Blueprint( "students", __name__, url_prefix="/students" ) @student_bp.route("/profile") def profile(): return "Student Profile"

⚠️ Error Handling

@app.errorhandler(404) def not_found(error): return "Page not found", 404

Custom error handlers provide a better user experience and keep technical information away from normal users.

⛔ abort()

from flask import abort if course_not_found: abort(404)

⚙️ Configuration

class Config: APP_NAME = "Student Learning Portal" DEBUG = False app.config.from_object(Config)

🌱 Environment Variables

import os secret_key = os.environ.get("SECRET_KEY") app.config["SECRET_KEY"] = secret_key
Security Rule: Never commit real passwords, API keys, or secret keys to a public repository.

🛡️ Security Checklist

  • Validate user input on the server.
  • Keep secrets outside source code.
  • Keep .env files out of Git.
  • Disable debug mode in production.
  • Use HTTPS in production.
  • Do not expose detailed tracebacks to users.
  • Do not trust client-side validation alone.
