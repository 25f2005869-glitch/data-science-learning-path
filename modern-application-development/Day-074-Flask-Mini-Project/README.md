## 📌 Introduction

This mini project combines the major Flask concepts learned from Day 061 to Day 073.

The project is a **Student Learning Portal** that demonstrates routing, dynamic URLs, Jinja2 templates, forms, GET/POST requests, redirects, `url_for()`, Blueprints, error handling, configuration, and environment variables.

## 🎯 Learning Objectives

- Build a small Flask application.
- Combine multiple Flask concepts.
- Create routes and dynamic routes.
- Work with GET and POST requests.
- Process form data.
- Use Jinja2 templates.
- Use redirects and `url_for()`.
- Organize routes with Blueprints.
- Handle 404 and 500 errors.
- Use Flask configuration.
- Understand environment-based settings.
