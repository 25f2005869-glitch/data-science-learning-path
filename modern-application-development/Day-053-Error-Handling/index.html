Day 053 — Error Handling

Detecting, handling, and debugging JavaScript errors

⚠️ What is an Error?

An error is a problem that occurs while JavaScript is being parsed or executed.

Syntax Error Invalid JavaScript syntax.
Runtime Error Problem occurring during execution.
Logical Error Program runs but produces an incorrect result.

🛡️ try...catch

The try...catch structure allows certain runtime exceptions to be handled. 

try {
    riskyOperation();
} catch (error) {
    console.error(error);
}

🧹 finally

try {
    console.log("Trying...");
} catch (error) {
    console.log("Error handled");
} finally {
    console.log("Cleanup");
}

🚨 throw

function checkMarks(marks) {
    if (marks < 0 || marks > 100) {
        throw new Error("Marks must be between 0 and 100");
    }

    return "Valid marks";
}

🔎 Error Object

Property Purpose
name Identifies the error type
message Describes the error
stack Provides debugging information

📚 Common Error Types

Error Typical Cause
ReferenceError Unknown variable or binding
TypeError Invalid operation for a value's type
RangeError Value outside an allowed range
SyntaxError Invalid syntax or invalid JSON parsing
URIError Invalid URI operation

📄 JSON Error Handling

try {
    const data = JSON.parse('{"name":"Saloni"}');
    console.log(data.name);
} catch (error) {
    console.error("Invalid JSON");
}

💡 Best Practices

  • Validate input before processing it.
  • Use meaningful error messages.
  • Use try...catch for expected exceptions.
  • Use finally for cleanup.
  • Do not silently ignore important errors.
  • Use console.error() for debugging.
  • Do not expose sensitive technical details to users.
  • Fix the underlying cause of an error.
