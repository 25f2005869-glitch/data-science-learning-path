## 📖 Introduction

Errors are a normal part of programming. JavaScript provides error-handling mechanisms that allow programs to detect, handle, and recover from runtime problems.

This day focuses on `try`, `catch`, `finally`, `throw`, and common JavaScript error types.

---

## 🎯 Learning Objectives

By the end of this day, you will understand:

- What JavaScript errors are
- Syntax, runtime, and logical errors
- `try...catch`
- `finally`
- `throw`
- `Error` objects
- Common error types
- Custom error messages
- Error handling best practices
