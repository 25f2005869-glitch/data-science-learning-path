## 📖 Introduction

HTML5 provides built-in elements for adding multimedia content to webpages.

In Day 016, we learn how to embed audio, video, and external webpages or content using iFrames.

The main elements covered are:

- `<audio>`
- `<video>`
- `<source>`
- `<track>`
- `<iframe>`

---

## 🎯 Learning Objectives

By the end of this day, you will understand:

- How to add audio to a webpage
- How to add video to a webpage
- The `controls` attribute

## 📚 Topics Covered

### 1. HTML Audio

Using the `<audio>` element to embed sound.

### 2. Audio Controls

Understanding:

- `controls`
- `autoplay`
- `muted`
- `loop`
- `preload`

### 3. HTML Video

Using the `<video>` element to embed videos.

### 4. Video Sources

Using `<source>` to provide media files.

### 5. Video Captions

Using `<track>` for subtitles and captions.

### 6. iFrames

Using `<iframe>` to embed another webpage or external content.

### 7. Accessibility

Understanding captions, controls, and alternative content.
