# Part 2 — Multiple Choice Questions

### Q1. Which HTML element is used for audio?

A. `<sound>`

B. `<music>`

C. `<audio>`

D. `<media>`

**Answer:** C

---

### Q2. Which HTML element is used for video?

A. `<movie>`

B. `<video>`

C. `<media>`

D. `<film>`

**Answer:** B

---

### Q3. Which attribute displays media controls?

A. `buttons`

B. `controls`

C. `player`

D. `control-panel`

**Answer:** B

---

### Q4. Which attribute repeats media after it finishes?

A. `repeat`

B. `again`

C. `loop`

D. `replay`

**Answer:** C

---

### Q5. Which attribute starts media without sound?

A. `silent`

B. `nosound`

C. `muted`

D. `quiet`

**Answer:** C

---

### Q6. Which element specifies a media source?

A. `<media-source>`

B. `<source>`

C. `<src>`

D. `<file>`

**Answer:** B

---

### Q7. Which element provides captions or other timed text?

A. `<caption>`

B. `<subtitle>`

C. `<track>`

D. `<text>`

**Answer:** C

---

### Q8. Which element embeds another browsing context?

A. `<embed-page>`

B. `<iframe>`

C. `<frame-page>`

D. `<window>`

**Answer:** B

---

### Q9. Which iframe attribute is important for accessibility?

A. `description`

B. `label`

C. `title`

D. `name`

**Answer:** C

---

### Q10. Which iframe attribute can restrict capabilities?

A. `restrict`

B. `secure`

C. `sandbox`

D. `protect`

**Answer:** C
