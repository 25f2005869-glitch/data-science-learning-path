# ML Paradigms

## 1. What is an ML Paradigm?

A Machine Learning paradigm describes **how a machine learns from data, examples, or feedback**.

Different paradigms are used depending on the type of information available during learning.

---

## 2. Main ML Paradigms

The major Machine Learning paradigms are:

1. Supervised Learning
2. Unsupervised Learning
3. Reinforcement Learning

---

## 3. Supervised Learning

In supervised learning, the model learns from **labelled data**.

The training data contains:

- Input features
- Expected output or label

The model learns a relationship between input and output.

### Example

Suppose we have information about houses:

- Area
- Number of rooms
- Location
- Price

The model learns from existing houses where the price is already known.

It can then predict the price of a new house.

### Common Tasks

- Classification
- Regression

### Examples

- Spam email detection
- House price prediction
- Disease classification
- Student performance prediction

---

## 4. Unsupervised Learning

In unsupervised learning, the data does **not have predefined labels**.

The model tries to discover useful patterns or structures in the data.

### Example

A company has customer data but does not know the customer groups.

A clustering algorithm can group customers based on similarities.

### Common Tasks

- Clustering
- Dimensionality Reduction
- Representation Learning

### Examples

- Customer segmentation
- Document grouping
- Image grouping
- Data compression

---

## 5. Reinforcement Learning

In reinforcement learning, an **agent learns by interacting with an environment**.

The agent:

1. Observes the environment
2. Takes an action
3. Receives a reward or penalty
4. Learns from the result

The goal is to learn actions that produce better long-term rewards.

### Example

A game-playing agent:

- Takes a move
- Receives a reward for a good move
- Receives a penalty for a bad move
- Improves its strategy over time

---

## 6. Comparison

| Paradigm | Data/Feedback | Main Goal |
|---|---|---|
| Supervised Learning | Labelled data | Predict output |
| Unsupervised Learning | Unlabelled data | Find patterns |
| Reinforcement Learning | Rewards/penalties | Learn good actions |

---

## 7. Supervised vs Unsupervised

### Supervised Learning

- Uses labelled data
- Has a known target
- Learns input-output relationships
- Used for prediction

### Unsupervised Learning

- Uses unlabelled data
- No predefined target
- Finds hidden patterns
- Used for discovering structure

---

## 8. Important Terms

**Label:**  
The known output associated with a training example.

**Feature:**  
An input variable used by the model.

**Training Data:**  
Data used to learn the model.

**Model:**  
A mathematical or computational representation learned from data.

**Prediction:**  
The output produced by a trained model.

**Reward:**  
Feedback received by an agent in reinforcement learning.

---

## 9. Key Points

- ML paradigms describe different ways of learning.
- Supervised learning uses labelled data.
- Unsupervised learning works with unlabelled data.
- Reinforcement learning uses rewards and penalties.
- Classification and regression are supervised learning tasks.
- Clustering is an unsupervised learning task.
- The choice of paradigm depends on the problem and available data.

---

## 10. Quick Revision

**Supervised → Labels → Prediction**

**Unsupervised → No Labels → Patterns**

**Reinforcement → Rewards → Actions**
