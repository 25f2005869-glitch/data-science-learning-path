# 📊 Day 080 — A/B Testing Introduction

## 🎯 Objective
- Understand the basic structure of an A/B test.
- Separate control and treatment variants.
- Calculate conversion and click rates.
- Calculate absolute and relative lift.
- Prepare a presentation-ready experiment analysis.

## 🧪 Experiment Setup
- Control is the reference variant.
- Treatment is the changed experience.
- Each observation is assigned to one variant.
- The dataset is synthetic and created for learning.

## 📈 Primary Outcome
- Purchased_Flag is the primary binary outcome.
- Conversion Rate = Purchases / Exposures × 100.
- Click Rate measures an earlier response stage.
- Order value provides a secondary monetary outcome.

## 🧮 Core Metrics
- Control conversion rate.
- Treatment conversion rate.
- Absolute lift.
- Relative lift.
- Click rate.
- Average order value.

## 📂 Workbook
- AB_Test_Data contains the source observations.
- Variant_Summary compares control and treatment.
- AB_Test_Metrics contains the main calculations.
- Segment_Analysis checks segment-level response.
- Region_Analysis checks regional response.
- Device_Analysis checks device-level response.
- Experiment_Framework defines A/B concepts.
- Presentation_Stages structures the presentation.
- Analysis_Questions contains practice questions.
- Business_Insights contains descriptive observations.
- Data_Dictionary documents fields.
- AB_Testing_KPIs contains headline metrics.
- AB_Testing_Dashboard contains prepared charts.

## 📊 Dashboard
- Conversion rate by variant.
- Click rate by variant.
- Conversion rate by customer segment.
- Order value versus click response.

## 🐍 Python
- Reads the Excel dataset.
- Calculates variant summaries.
- Calculates lift.
- Creates segment, region and device analysis.
- Exports CSV summaries.
- Generates PNG charts.

## ⚠️ Important Interpretation
- An observed difference is not automatically proof of causality.
- Random assignment is important for causal interpretation.
- Sample size affects precision.
- Synthetic results should not be generalised to real users.
