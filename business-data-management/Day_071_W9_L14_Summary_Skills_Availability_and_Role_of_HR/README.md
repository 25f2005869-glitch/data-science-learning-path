# 📊 Day 071 — Summary: Skills Availability and Role of HR

## 📌 Topic
This day summarises workforce skill availability and connects the analysis with the role of HR.

## 🎯 Objectives
1. Understand a skills inventory.
2. Measure skill availability.
3. Calculate skill gaps.
4. Compare departments.
5. Compare regions.
6. Compare roles.
7. Compare experience levels.
8. Connect skill data with training.
9. Understand HR's analytical role.
10. Present workforce capability insights.

## 🧩 Dataset
The workbook contains 30 illustrative employee records.
The dataset is synthetic and intended for learning.
It contains department, region, role and experience information.
Each record contains a primary skill.
A secondary skill is also included.
Skill scores are numerical practice measures.
Training hours provide a development dimension.
Performance scores provide additional context.

## 📏 Core Measures
Employee Count.
Skill Availability.
Availability Rate.
Average Skill Score.
Skill Gap Count.
Skill Gap Rate.
Training Need Count.
Training Need Rate.

## 🧮 Key Formulas
Availability Rate = Available Employees / Employees × 100.
Skill Gap Rate = Skill Gap Employees / Employees × 100.
Training Need Rate = Training Need Employees / Employees × 100.
Average Skill Score = Total Skill Score / Employees.

Results should be treated as descriptive practice analysis.
