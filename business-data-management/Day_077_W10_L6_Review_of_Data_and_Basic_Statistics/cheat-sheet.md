# ⚡ Day 077 Cheat Sheet — Basic Statistics

## 🔢 Core Statistics
- Count → number of observations.
- Sum → total value.
- Mean → average.
- Median → middle ordered value.
- Minimum → smallest value.
- Maximum → largest value.
- Range → maximum − minimum.
- Q1 → 25th percentile.
- Q3 → 75th percentile.
- IQR → Q3 − Q1.
- Standard deviation → measure of spread.

## 🧮 Formulas
- Mean = Σx / n.
- Range = Max − Min.
- IQR = Q3 − Q1.
- Transaction value per customer = transaction value × 100 / customers in lakh.
- Transactions per customer = transaction volume / active customers when units match.
- Engagement Index = digital adoption × satisfaction / 100.

## 📌 Excel Functions
- COUNT() → numeric observations.
- COUNTA() → non-empty cells.
- COUNTIF() → conditional count.
- SUM() → total.
- SUMIF() → conditional total.
- AVERAGE() → arithmetic mean.
- AVERAGEIF() → conditional average.
- MEDIAN() → middle value.
- MIN() → minimum.
- MAX() → maximum.
- STDEV.S() → sample standard deviation.
- QUARTILE.INC() → quartile.
- CORREL() → correlation.

## 🐼 Pandas
- df.shape → dimensions.
- df.info() → structure.
- df.describe() → descriptive statistics.
- df.isna().sum() → missing values.
- df.duplicated().sum() → duplicate rows.
- df.groupby() → grouped analysis.
- df.mean() → mean.
- df.median() → median.
- df.std() → sample standard deviation.
- df.quantile(.25) → Q1.
- df.quantile(.75) → Q3.
- df.corr() → correlation matrix.

## 🔍 Data Review
- Check IDs.
- Check duplicates.
- Check missing values.
- Check data types.
- Check category spelling.
- Check units.
- Check numeric ranges.

## 📊 Chart Choice
- Column → category comparison.
- Line → ordered trend or sequence.
- Scatter → two numeric variables.
- Bar → category frequency.
- Dashboard → multiple related views.

## ⚠️ Interpretation
- Mean ≠ median.
- Count ≠ market share.
- Transaction value ≠ profit.
- Correlation ≠ causation.
- Synthetic data ≠ real market evidence.
