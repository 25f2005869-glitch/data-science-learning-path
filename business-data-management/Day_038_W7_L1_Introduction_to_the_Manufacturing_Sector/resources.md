# 📚 Day 038 Resources — Introduction to the Manufacturing Sector

**Author:** Saloni Tiwari  
**Programme:** IIT Madras BS Degree — Diploma Level  
**Day:** 038  
**Topic:** Introduction to the Manufacturing Sector

## 🎓 Learning Context

This day introduces manufacturing-sector data through a business analytics workflow.

The workbook connects operations, sales, quality and financial measures.

## 📖 Workbook Resources

Manufacturing_Data contains the transaction-level sample.

Product_Master describes products.

Product_Summary provides product-level aggregation.

Region_Summary provides regional aggregation.

Customer_Summary provides customer-type aggregation.

Manufacturing_KPIs lists important metrics.

Case_Questions provides analytical questions.

Business_Insights contains learning observations.

Data_Dictionary explains fields.

Manufacturing_Dashboard provides visual summaries.

## 🧰 Excel Resources

Use SUMIF for grouped calculations.

Use Pivot Tables for interactive summaries.

Use charts for comparisons.

Use formulas for KPI calculations.

## 🐍 Python Resources

pandas is used for data manipulation.

groupby is used for aggregation.

matplotlib is used for visualization.
