## 📒 Ledger Learning

- A ledger is a detailed record of inventory movements.
- Date identifies when an event is recorded.
- Product identifies the inventory item.
- Transaction type identifies the movement.
- Purchases represent incoming units.
- Sales represent outgoing units.
- Closing stock represents the recorded stock position.

## 🏷️ Product Learning

- Product-level grouping makes comparison easier.
- Total purchases show incoming activity.
- Total sales units show outgoing activity.
- Average inventory summarizes recorded stock.
- Closing stock provides the latest recorded position.
- DSI can be compared by product.
- Turnover can be compared by product.

## 📅 Monthly Learning

- Monthly grouping reveals changes over time.
- Purchases can be compared across months.
- Sales units can be compared across months.
- Closing stock can be tracked over time.
- Monthly summaries support presentation.
- The same date definition should be used consistently.

## 📐 DSI Learning

- DSI means Days of Sales of Inventory.
- It connects average inventory with average daily sales.
- DSI is expressed in days.
- Average daily sales depend on the observation period.
- Higher DSI represents more inventory days relative to sales velocity.
- Lower DSI represents fewer inventory days relative to sales velocity.

## 🔄 Turnover Learning

- Inventory turnover connects sales volume with average inventory.
- The practical formula is Sales Units divided by Average Inventory.
- Turnover is a complementary measure.
- DSI and turnover should use compatible inputs.
- Product comparisons should use consistent methodology.

## 📊 Presentation Learning

- A presentation should focus on the business question.
- Raw data should support the analysis.
- Summaries should simplify the evidence.
- Charts should communicate clear comparisons.
- Units should be visible.
- Conclusions should remain connected to the dataset.

## 🔎 Data Quality Learning

- Check dates before analysis.
- Check product names.
- Check transaction types.
- Check numeric values.
- Check duplicates.
- Check missing values.
- Check the chronological order of records.

## 💼 Business Interpretation

- A purchase adds inventory.
- A sale reduces inventory.
- Closing stock records the stock position.
- High sales activity can affect stock availability.
- DSI describes inventory coverage relative to sales velocity.
- Turnover describes sales volume relative to average inventory.

## 🧠 What the Case Teaches

- Business data must first be understood.
- Detailed data should be summarized.
- Different views answer different questions.
- Inventory analysis needs both stock and sales information.
- Metrics should be defined before interpretation.
- Visuals should support the written explanation.
- Evidence should be separated from assumptions.

## 📗 Excel Learning

- Excel can store the source ledger.
- Pivot Tables can create grouped summaries.
- Formulas can calculate metrics.
- Charts can communicate patterns.
- Dashboards combine KPIs and visuals.
- Data dictionaries clarify field meanings.

## 🐍 Python Learning

- pandas can read the Excel workbook.

## ⚠️ Common Mistakes

- Confusing purchases with sales.
- Treating closing stock as a flow.
- Ignoring the observation period.
- Using inconsistent units.
- Interpreting DSI without sales velocity.
- Using charts without labels.
- Making unsupported causal claims.
