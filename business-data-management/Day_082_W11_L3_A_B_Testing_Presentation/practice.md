# 🧪 Day 082 Practice — A/B Testing Presentation

## Task 1 — Business Question
- Write one PayLater A/B testing question.
- Make the outcome measurable.
- Identify the experimental unit.

## Task 2 — Experiment Design
- Define Control.
- Define Treatment.
- Define eligibility.
- Define exposure.
- Define primary outcome.

## Task 3 — Dataset Review
- Count records.
- Count Control records.
- Count Treatment records.
- Check duplicate Experiment_ID values.

## Task 4 — Main Metric
- Calculate Control conversion.
- Calculate Treatment conversion.
- Verify the denominator.
- Record both counts and rates.

## Task 5 — Lift
- Calculate absolute lift.
- Express it in percentage points.
- Calculate relative lift.
- Explain the difference between both measures.

## Task 6 — Click Analysis
- Calculate Control click rate.
- Calculate Treatment click rate.
- Explain why click rate is secondary.

## Task 7 — Nudge Analysis
- Group by Nudge_Type.
- Calculate exposures.
- Calculate PayLater users.
- Calculate conversion.
- Compare with No Nudge.

## Task 8 — Segment Analysis
- Group by Customer_Segment and Variant.
- Calculate conversion.
- Record subgroup counts.
- Identify small groups.

## Task 9 — Region Analysis
- Group by Region and Variant.
- Calculate conversion.
- Compare descriptive patterns.
- Avoid unsupported causal explanations.

## Task 10 — Dashboard
- Review all four charts.
- Check titles.
- Check units.
- Check labels.
- Check that Control and Treatment are distinguishable.

## Task 11 — Slide Draft
Create eight slides:
1. Business Question
2. Experiment Design
3. Dataset
4. Main Result
5. Nudge Analysis
6. Segment and Region Analysis
7. Interpretation
8. Limitations

## Task 12 — Speaker Notes
- Write two sentences for each slide.
- Explain metrics before conclusions.
- Mention sample size.
- Mention synthetic-data limitation.

## Task 13 — Excel Recreation
- Recreate Variant_Summary.
- Use COUNTIFS.
- Calculate conversion.
- Calculate absolute lift.
- Format percentages.

## Task 14 — Python Recreation
- Read the workbook.
- Group by Variant.
- Group by Nudge_Type.
- Export CSV files.
- Generate charts.

## Task 15 — Statistical Extension
- Identify a two-proportion test.
- Explain confidence intervals.
- Explain statistical power.
- Explain practical significance.

## Task 16 — Final Presentation Audit
- Question is clear.
- Design is clear.
- Primary metric is clear.
- Denominators are visible.
- Lift is correctly labelled.
- Subgroups are contextual.
- Limitations are stated.
- Synthetic data is identified.

## Task 17 — One-Minute Explanation
- Explain the business question in one sentence.
- Explain Control in one sentence.
- Explain Treatment in one sentence.
- State the primary metric.
- State the main limitation.

## Task 18 — Chart Audit
- Check the y-axis unit.
- Check category labels.
- Check Control/Treatment order.
- Check chart title.
- Check whether subgroup counts are available.

## Task 19 — Final Review

- Verify lift manually.
- Compare Excel and Python.
