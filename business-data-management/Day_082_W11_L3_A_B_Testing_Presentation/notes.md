# 📝 Day 082 Notes — A/B Testing Presentation

## 1. From Analysis to Presentation
- A/B testing analysis must be converted into a clear business story.
- The presentation should answer one primary question.
- Supporting metrics should explain the main result.
- Limitations should remain visible.

## 2. Slide 1 — Business Question
- State the decision or question being studied.
- Keep the question measurable.
- Avoid vague statements.
- Define the PayLater outcome.

## 3. Slide 2 — Experiment Design
- Identify Control.
- Identify Treatment.
- Define eligibility.
- Define exposure.
- Define the experimental unit.
- Define the primary outcome.

## 4. Slide 3 — Dataset and Sample
- Report record count.
- Report exposure count.
- Report variant counts.
- State that the dataset is synthetic.
- Explain important variables.

## 5. Slide 4 — Main Result
- Show Control conversion.
- Show Treatment conversion.
- Show absolute lift.
- Show relative lift.
- Keep denominators visible.

## 6. Slide 5 — Nudge Analysis
- Compare No Nudge with treatment nudge categories.
- Use the same conversion definition.
- Show exposure counts.
- Avoid changing the primary metric.

## 7. Slide 6 — Segmentation
- Customer segments can reveal heterogeneous patterns.
- Region can provide descriptive context.
- Small subgroup counts need caution.
- Segment differences are not automatically treatment effects.

## 8. Slide 7 — Business Interpretation
- Separate observation from explanation.
- Explain what the metric measures.
- Avoid unsupported causal claims.
- State what additional evidence would be useful.

## 9. Slide 8 — Limitations
- Synthetic dataset.
- Limited sample size.
- No documented real-world randomisation process.
- Statistical uncertainty should be quantified in an extended analysis.

## 10. Presentation Metrics
- Conversion rate.
- Click rate.
- Absolute lift.
- Relative lift.
- Purchase value.
- Repayment rate.

## 11. Visual Hierarchy
- Lead with the primary metric.
- Keep charts simple.
- Use consistent labels.
- Put units on axes.
- Show counts with percentages.

## 12. Evidence Discipline
- Define the denominator.
- Define the outcome.
- Report sample size.
- Separate descriptive and causal language.
- Label synthetic data.

## 13. Speaker Notes
- Explain the experiment before the result.
- Explain the metric before the interpretation.
- Mention limitations after the main finding.
- Avoid reading every table value aloud.

## 14. Statistical Extension
- Add a two-proportion test.
- Add confidence intervals.
- Add statistical power.
- Estimate a minimum detectable effect.
- Consider subgroup power.

## 15. Learning Outcome
- Build an A/B testing presentation.
- Explain experimental design.
- Present conversion and lift.
- Present subgroup context.
- Communicate limitations.

## 16. Presentation Narrative
- Start with the business problem.
- Introduce the experiment.
- Explain the sample.
- Present the primary metric.
- Add supporting breakdowns.
- Explain limitations.
- End with analytical next steps.

## 17. Main Result Discipline
- Never present a percentage without its denominator.
- Use percentage points for absolute lift.
- Use percent for relative lift.
- Keep control and treatment labels consistent.

## 18. Dashboard Reading
- Read the primary comparison first.
- Then inspect nudge categories.
- Then inspect segments.
- Then inspect regions.
- Use subgroup counts before interpretation.
