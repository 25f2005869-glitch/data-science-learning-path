# ⚡ Day 082 Cheat Sheet — A/B Testing Presentation

## Presentation Order
- Question.
- Design.
- Data.
- Primary result.
- Nudge analysis.
- Segmentation.
- Interpretation.
- Limitations.

## Core Definitions
- Control → reference group.
- Treatment → changed experience.
- Exposure → nudge shown.
- Conversion → PayLater usage.
- Lift → difference from reference.

## Formulas
- Conversion % = Users / Exposures × 100.
- Click Rate % = Clicks / Exposures × 100.
- Repayment Rate % = Repayments / PayLater Users × 100.
- Absolute Lift = Treatment − Control.
- Relative Lift % = Absolute Lift / Control × 100.

## Reporting Units
- Conversion → percentage.
- Click rate → percentage.
- Absolute lift → percentage points.
- Relative lift → percent.
- Purchase value → rupees.

## Excel
- COUNTIF → simple count.
- COUNTIFS → conditional count.
- SUMIF → category sum.
- SUMIFS → conditional sum.
- AVERAGEIF → subgroup average.
- PivotTable → multi-dimensional comparison.

## Python
- read_excel() → input.
- groupby() → grouping.
- agg() → metrics.
- pivot() → chart preparation.
- to_csv() → exports.
- matplotlib → presentation charts.

## Chart Selection
- Control/Treatment → column chart.
- Nudge categories → column chart.
- Segment comparison → grouped column.
- Region comparison → line chart.

## Slide Checklist
- Business question present.
- Control defined.
- Treatment defined.
- Exposure defined.
- Primary outcome defined.
- Counts shown.
- Rates shown.
- Lift shown.
- Limitations shown.

## Interpretation Rules
- Click is not conversion.
- Conversion is not purchase value.
- Repayment is a later-stage outcome.
- Correlation is not causation.
- Statistical significance is not practical importance.

## Quality Checks
- Variant labels valid.
- Denominator correct.
- Binary fields valid.
- Totals reconciled.
- Units consistent.
- Synthetic data labelled.

## Presentation Language
- “Observed conversion rate” is descriptive.
- “Absolute lift” means percentage-point difference.
- “Relative lift” means proportional change.
- “Treatment effect” requires appropriate experimental assumptions.

## Final 30-Second Summary
- State the question.
- State the design.
- State the primary metric.
- State the control rate.
- State the treatment rate.
- State the lift.
- State the main limitation.
