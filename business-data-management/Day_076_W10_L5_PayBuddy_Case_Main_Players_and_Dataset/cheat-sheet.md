# ⚡ Day 076 Cheat Sheet — Main Players & Dataset

## 🔢 Core Fields

- Player_ID → unique identifier.
- Player_Type → ecosystem category.
- Industry → business domain.
- Region → geography.
- Primary_Product → main service.
- Customer_Segment → customer grouping.

## 📊 Measures

- Active_Customers_Lakh.
- Transactions_Lakh.
- Transaction_Value_Crore.
- Digital_Adoption_%.
- Satisfaction_Score.

## 🧮 Formulas

- Value per customer = transaction value × 100 / active customers in lakh.
- Transactions per customer = transaction volume / active customers when units match.
- Engagement Index = digital adoption × satisfaction / 100.
- Group average = sum of values / number of records.

## 💳 Player Types

- Bank → banking services.
- NBFC → non-bank finance.
- Insurance → risk protection.
- Capital Market → investment activity.
- FinTech → technology-led finance.

## 🏢 Industries

- Payments.
- Lending.

- Investment.
- Compliance.

## 📌 Analysis Dimensions

- Player type.

## 📈 Chart Selection

- Doughnut → composition.
- Column → category comparison.
- Line → ordered or sequential comparison.
- Scatter → relationship between numeric variables.

## 🐼 Pandas

- pd.read_excel() → read workbook.
- pd.to_numeric() → convert numeric values.
- df.groupby() → create groups.
- agg() → calculate multiple statistics.
- to_csv() → save summaries.

## 🔍 Validation

- Check units.
- Check denominators.
- Check missing values.
- Check duplicate IDs.
- Reconcile totals.
- Check category labels.

## ⚠️ Interpretation

- Synthetic data is not market evidence.
- Totals and averages are different measures.
- Correlation does not prove causation.
- Player count does not equal market share.
- Transaction value does not equal profit.
