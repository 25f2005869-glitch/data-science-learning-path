# 📊 Day 048 — Production Scheduling Data: Plans vs Actual

## 🎯 Day Objective

This day focuses on production scheduling data.

The main task is to compare planned production with actual production.

The analysis uses product, region and month dimensions.

## 📐 Key Metrics

Variance Units = Actual Production - Planned Production.

Variance % = Variance Units / Planned Production.

Plan Achievement % = Actual Production / Planned Production.

## 📈 Positive Variance

A positive variance means actual production is above planned production.

## 📉 Negative Variance

A negative variance means actual production is below planned production.

## 📅 Monthly Analysis

Monthly analysis shows how production performance changes over time.

## 🏭 Product Analysis

Product analysis compares Gears, Shafts and Bearings.

## 🌍 Regional Analysis

Regional analysis compares production across North, South and West.

## 🧠 Important Interpretation

Variance identifies a difference between plan and actual.

Variance alone does not prove the operational cause.

Additional information may be required for root-cause analysis.
