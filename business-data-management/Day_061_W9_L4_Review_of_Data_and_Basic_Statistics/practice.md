# 🧪 Day 061 Practice — Review of Data and Basic Statistics

## Practice Setup

Open the Day 061 workbook.
Start with Data_Review.
Do not begin with the dashboard.
Review the fields and their definitions.

## Task 1 — Data Review

Count all records.
Count missing values.
Check duplicate Request_ID values.
Count unique departments.
Count unique regions.
Count unique internal sources.

## Task 2 — Variable Classification

Identify categorical variables.
Identify numerical variables.
Identify identifier fields.
Identify derived fields.

## Task 3 — Central Tendency

Calculate mean internal cost.
Calculate median internal cost.
Calculate mean actual days.
Calculate median actual days.
Calculate mean satisfaction.
Calculate median satisfaction.

## Task 4 — Dispersion

Calculate minimum internal cost.
Calculate maximum internal cost.
Calculate cost range.
Calculate standard deviation of cost.
Calculate standard deviation of actual days.

## Task 5 — Quartiles

Calculate Q1 for internal cost.
Calculate Q3 for internal cost.
Calculate the IQR.
Explain what the middle 50 percent means.

## Task 6 — Department Analysis

Count requests by department.
Calculate mean cost by department.
Calculate median cost by department.
Calculate mean actual days by department.
Calculate mean satisfaction by department.

## Task 7 — Region Analysis

Count records by region.
Calculate total cost by region.
Calculate average cost by region.
Calculate average actual days by region.

## Task 8 — Source Analysis

Count requests by internal source.
Calculate total cost by source.
Calculate mean cost by source.
Calculate average actual days by source.

## Task 9 — Monthly Analysis

Calculate monthly request count.
Calculate monthly total cost.
Calculate monthly average actual days.
Calculate monthly average satisfaction.

## Task 10 — Excel Practice

Use AVERAGE.
Use MEDIAN.
Use MIN.
Use MAX.
Use STDEV.S.
Use QUARTILE.INC.
Create a PivotTable.

## Task 11 — Python Practice

Run the Day 061 Python script.
Open basic_statistics.csv.
Open department_basic_statistics.csv.
Open region_basic_statistics.csv.
Open source_basic_statistics.csv.
Open monthly_basic_statistics.csv.

## Task 12 — Interpretation

Compare mean and median cost.
Explain what standard deviation tells you.
Explain what IQR tells you.
Identify one limitation of using only the mean.
Explain why data quality matters.

## Mini Case

A manager sees a high average internal cost.
Write three questions before concluding that costs are high.
Choose two statistics that should be reviewed.
Choose one chart that could help explain the pattern.

## Final Review

Can you review raw data?
Can you calculate mean?
Can you calculate median?
Can you calculate standard deviation?
Can you calculate range?
Can you calculate IQR?
Can you create grouped summaries?
Can you interpret statistics without overstating causation?
