## 📌 Overview

Customer Analytics is the process of analysing customer data to understand customer behaviour, spending patterns, customer segments, product preferences, regional performance, and customer activity.

In this day, the focus is on working with customer transaction data using Excel and applying business data management techniques such as data cleaning, segmentation, aggregation, KPI analysis, Pivot-style analysis, and visualisation.

The analysis follows a complete business data workflow:

**Raw Customer Data → Inspect → Clean → Analyse → Segment → Calculate KPIs → Pivot Analysis → Visualise → Business Insights**

The customer dataset contains deliberate data-quality issues for practice.

The cleaning workflow is:

1. Inspect the raw data
2. Identify data-quality issues
3. Standardise text values
4. Convert dates into valid date values
5. Handle missing Age values
6. Handle missing Quantity values
7. Handle missing Unit Price values
8. Correct negative Quantity values
9. Handle missing Customer Satisfaction
10. Recalculate Revenue
11. Remove duplicate records
12. Validate the cleaned dataset
13. Analyse the cleaned data

## 📊 Key Customer Metrics

### Total Customers

Number of unique customers in the cleaned dataset.

### Total Orders

Number of customer transaction records.

### Total Revenue

Total revenue generated from customer transactions.

### Average Customer Spend

**Formula:**

Average Customer Spend = Total Revenue / Total Customers

### Average Order Value

**Formula:**

Average Order Value = Total Revenue / Total Orders

### Repeat Customers

Customers who have placed more than one order.

### Repeat Customer Rate

**Formula:**

Repeat Customer Rate = Repeat Customers / Total Customers
