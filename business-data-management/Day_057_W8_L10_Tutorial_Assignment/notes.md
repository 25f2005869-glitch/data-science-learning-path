# 📝 Day 057 Notes

## 1. Tutorial Assignment

The tutorial assignment is an opportunity to apply the inventory-analysis workflow to a complete dataset.

## 2. Start With the Data

Always inspect the raw dataset before calculating metrics.

Check:

- Columns
- Units
- Materials
- Regions
- Months
- Missing values
- Data consistency

## 3. Inventory Flow

The basic inventory relationship is:

Opening Inventory + Purchases − Usage = Closing Inventory

## 4. Purchase Analysis

Purchase analysis shows how much material enters the inventory system.

## 5. Usage Analysis

Usage analysis shows how much raw material is consumed.

## 6. Closing Inventory

Closing inventory shows the remaining material at the end of the period.

## 7. Inventory Value

Inventory value connects quantity with unit cost.

Formula:

Closing Inventory × Unit Cost

## 8. Average Daily Usage

For this tutorial:

Material Usage ÷ 30

## 9. Lead-Time Demand

Lead-time demand estimates expected consumption during lead time.

Formula:

Average Daily Usage × Lead Time

## 10. Safety Stock

Safety stock provides additional coverage beyond expected lead-time demand.

## 11. Reorder Point

Reorder point is calculated using:

Lead-Time Demand + Safety Stock

## 12. Inventory Gap

Inventory gap is:

Closing Inventory − Reorder Point

## 13. Status

Negative gap:

Below Reorder Point

Non-negative gap:

At/Above Reorder Point

## 14. Material Analysis

Group the data by raw material to compare:

- Purchases
- Usage
- Closing inventory
- Inventory value
- Reorder point

## 15. Monthly Analysis

Group by month to identify changes in:

- Purchases
- Usage
- Closing inventory
- Reorder requirements

## 16. Regional Analysis

Group by region to compare inventory conditions.

## 17. Business Insight

A business insight should connect an observation to its meaning.

Example structure:

Observation → Evidence → Business Meaning

## 18. Presentation

A short presentation should have a logical sequence.

Context

→ Data

→ Analysis

→ Risk

→ Insight

## 19. Dashboard

Use the dashboard to support the presentation.

Do not simply read chart values.

Explain what the chart means.

## 20. Assignment Strategy

Read every task carefully.

Identify the required metric.

Select the appropriate aggregation.

Check the result.

Write the business interpretation.
