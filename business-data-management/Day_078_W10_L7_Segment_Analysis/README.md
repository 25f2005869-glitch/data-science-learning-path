# 📘 Day 078 — Segment Analysis

## 🎯 Objective

- Analyse customers through meaningful business segments.
- Compare customer scale and transaction activity.
- Study digital adoption and satisfaction by segment.
- Connect segmentation with descriptive business analytics.

## 🧾 Case Context

- The dataset continues the synthetic PayBuddy-style financial ecosystem.
- Customer segments are Consumer, Retail, Business and Investor.
- The dataset contains 30 illustrative player records.
- The figures are created for learning and are not real market statistics.

## 👥 Customer Segments

- Consumer represents individual-oriented activity.
- Retail represents retail-oriented customers.
- Business represents business-oriented customers.
- Investor represents investment-oriented customers.

## 📊 Segment Measures

- Active customers.
- Transactions.
- Transaction value.
- Digital adoption.
- Satisfaction.
- Engagement index.

## 🧮 Derived Measures

- Transactions per customer.
- Transaction value per customer.
- Customer value index.
- Customer share.
- Transaction-value share.
- Activity level.

## 📂 Workbook

- Segment_Data contains the working dataset.
- Segment_Summary contains segment-level aggregates.
- Player_Segment_Analysis shows player type versus segment.
- Region_Segment_Analysis combines geography and segment.
- Industry_Segment_Analysis combines industry and segment.
- Product_Segment_Analysis combines product and segment.
- Activity_Level_Analysis classifies transaction activity.
- Segment_KPIs contains headline measures.
- Data_Review contains quality checks.
- Segment_Questions contains business questions.
- Business_Insights contains descriptive observations.
- Data_Dictionary defines fields.
- Instructions provides the workflow.
- Segment_Analysis_Dashboard contains charts.

## 📈 Dashboard

- Active customers by segment.
- Transaction value by segment.
- Digital adoption by segment.
- Transaction value versus active customers.

## 🐍 Python

- Reads the Excel dataset.
- Converts numeric fields.
- Creates customer-level derived metrics.
- Groups data by customer segment.
- Creates cross-tabulations.
- Exports CSV summaries.
- Generates PNG charts.

## 🔎 Analysis Approach

- Define the segment.
- Measure segment size.
- Measure activity.
- Compare engagement.
- Compare customer experience.
- Examine regional and player-type composition.
- State limitations.

## ⚠️ Interpretation

- Segment size is not the same as profitability.
- Transaction value is not profit.
- A segment average can hide individual variation.
- Correlation does not establish causation.
- Synthetic data should not be treated as real market evidence.
