# 🧪 Day 078 Practice — Segment Analysis

## Task 1 — Identify Segments

- List every customer segment.
- Count records in each segment.
- Check whether segment labels are consistent.
- Confirm the total record count.

## Task 2 — Data Quality

- Check duplicate Player_ID values.
- Check missing Customer_Segment values.
- Check missing customer values.
- Check missing transaction values.
- Verify numeric data types.

## Task 3 — Segment Size

- Calculate active customers by segment.
- Calculate customer share percentage.
- Compare record count with customer count.
- Explain why these measures differ.

## Task 4 — Transaction Activity

- Calculate transaction volume by segment.
- Calculate transaction value by segment.
- Calculate transactions per customer.
- Compare volume with customer scale.

## Task 5 — Digital Adoption

- Calculate average digital adoption by segment.
- Compare adoption values.
- Create a column chart.
- Write two descriptive observations.

## Task 6 — Satisfaction

- Calculate average satisfaction by segment.
- Compare satisfaction with digital adoption.
- Check whether high adoption automatically means high satisfaction.
- Explain why the dataset cannot establish causality.

## Task 7 — Normalisation

- Calculate transaction value per customer.
- Calculate transactions per customer.
- Compare raw and normalised measures.
- Explain why denominators matter.

## Task 8 — Activity Bands

- Create Low Activity records.
- Create Medium Activity records.
- Create High Activity records.
- Count records in each band.
- Compare transaction value across bands.

## Task 9 — Player-Type Cross-Tab

- Visualise the cross-tabulation.

## Task 10 — Region Cross-Tab

## Task 11 — Industry Cross-Tab

## Task 12 — Product Cross-Tab

- Calculate active customers.
- Calculate transaction value.
- Compare product-segment combinations.
