## MCQs

### 1. Which sequence represents the basic management cycle?

A. Sell → Buy → Deliver → Review  
B. Plan → Organise → Lead → Monitor → Review → Improve  
C. Input → Output → Revenue → Cost  
D. Budget → Sales → Marketing → Profit

**Answer:** B

### 2. Which activity is mainly associated with planning?

A. Setting targets  
B. Recording customer complaints  
C. Delivering products  
D. Processing returns

**Answer:** A

### 3. Which formula calculates target achievement?

A. Target / Actual × 100  
B. Actual / Target × 100  
C. Actual − Target  
D. Target + Actual

**Answer:** B

### 4. Which formula calculates budget utilisation?

A. Budget / Actual Cost × 100  
B. Actual Cost / Budget × 100  
C. Budget − Actual Cost  
D. Actual Cost + Budget

**Answer:** B

### 5. Which measure compares completed work with planned work?

A. Customer Satisfaction  
B. Cost Variance  
C. Task Completion  
D. Revenue

**Answer:** C
