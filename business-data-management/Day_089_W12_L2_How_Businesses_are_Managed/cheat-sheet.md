## Management Cycle

**Plan → Organise → Lead → Monitor → Review → Improve**

| Stage | Main Activity |
|---|---|
| Plan | Set goals, targets, priorities, budgets |
| Organise | Allocate resources and responsibilities |
| Lead | Coordinate and guide teams |
| Monitor | Track KPIs and progress |
| Review | Compare actual results with plans |
| Improve | Take corrective or improvement actions |

## Important Terms

| Term | Meaning |
|---|---|
| Target | Planned level of performance |
| Actual | Result achieved |
| Budget | Planned financial allocation |
| Actual Cost | Cost actually incurred |
| KPI | Key Performance Indicator |
| Cost Variance | Difference between actual cost and budget |
| Task Completion | Completed tasks compared with planned tasks |
| Customer Satisfaction | Measure of customer-facing performance |
| Resource Allocation | Assignment of resources to activities |

## Key Formulae

**Target Achievement (%) = Actual / Target × 100**

**Budget Utilisation (%) = Actual Cost / Budget × 100**

**Task Completion (%) = Tasks Completed / Tasks Planned × 100**

**Cost Variance = Actual Cost − Budget**

## Management Functions

- Planning → goals and targets
- Organising → resources and responsibilities
- Leading → team coordination
- Monitoring → performance tracking
- Reviewing → plan vs actual comparison
- Improving → corrective and improvement actions

## Key Management KPIs

| Category | Examples |
|---|---|
| Performance | Target, Actual |
| Financial | Budget, Actual Cost, Cost Variance |
| Execution | Tasks Planned, Tasks Completed |
| Customer | Customer Satisfaction |
| Resource | Team Size, Budget |
| Management | Target Achievement, Budget Utilisation |

## Data Analysis Questions

1. Did actual performance meet the target?
2. How much of the budget was used?
3. What percentage of planned tasks were completed?
4. Which business function has the highest actual performance?
5. Which function has the highest customer satisfaction?
6. Where is actual cost different from budget?
7. Which areas require further investigation?

## Remember

- Management connects goals with execution.
- Compare **Target vs Actual**.
- Compare **Budget vs Actual Cost**.
- Track both performance and resource utilisation.
- Use multiple KPIs together.
- A KPI shows a performance pattern but does not automatically explain its cause.
- Business decisions should consider data and business context.
