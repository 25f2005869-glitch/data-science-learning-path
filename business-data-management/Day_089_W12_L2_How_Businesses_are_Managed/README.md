## Management Cycle

**Plan → Organise → Lead → Monitor → Review → Improve**

### Plan

Managers define:

- Goals
- Targets
- Priorities
- Budgets
- Timelines

### Organise

Resources and responsibilities are allocated to the appropriate teams and people.

### Lead

Managers coordinate teams, communicate expectations, and support execution.

### Monitor

Managers track KPIs and compare current performance with planned targets.

### Review

Actual results are compared with plans to identify gaps and changes.

### Improve

Managers use the findings to make corrective or improvement actions.

## Key Management Measures

| Measure | Purpose |
|---|---|
| Target | Planned level of performance |
| Actual | Result achieved |
| Budget | Planned financial allocation |
| Actual Cost | Cost incurred |
| Target Achievement | Actual performance compared with target |
| Budget Utilisation | Actual cost compared with budget |
| Task Completion | Completed work compared with planned work |
| Customer Satisfaction | Customer-facing performance indicator |

## Basic Formulae

**Target Achievement (%) = Actual / Target × 100**

**Budget Utilisation (%) = Actual Cost / Budget × 100**

**Task Completion (%) = Tasks Completed / Tasks Planned × 100**

**Cost Variance = Actual Cost − Budget**

## Management Questions

A manager can use the data to ask:

- Are actual results meeting targets?
- How much of the budget has been used?
- Are planned tasks being completed?
- Which business function needs further investigation?
- How is customer satisfaction changing?
- Where are actual costs different from planned budgets?
- What additional information is required before taking action?

## Important Data Practice

The workbook contains **synthetic educational data** created for learning business management and analytics concepts.

The data should not be interpreted as actual performance of a real business.

A KPI describes a performance pattern, but the KPI alone does not necessarily explain the reason behind that pattern.

## Key Takeaways

- Management connects goals, people, resources, and performance.
- Planning establishes targets and priorities.
- Organising assigns resources and responsibilities.
- Monitoring compares actual performance with expectations.
- Reviewing results helps identify performance gaps.
- Improvement uses evidence to support future actions.
- Managers should consider multiple KPIs together.
- Data supports management decisions but should be interpreted in business context.
