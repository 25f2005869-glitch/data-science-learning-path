## 📐 Formulas

Good Units = Production Units - Scrap Units.
Scrap Rate = Scrap Units / Production Units.

## 📊 Analysis

Product analysis compares products.
Monthly analysis tracks scrap over time.
Regional analysis compares regions.
Product-region analysis provides detailed comparison.

## 🛠️ Workflow

1. Open raw data.
2. Understand fields.
3. Calculate total production.
4. Calculate total scrap.
5. Calculate scrap rate.
6. Review product summary.
7. Review monthly summary.
8. Review regional summary.
9. Review product-region summary.
10. Review dashboard.

## 📈 Dashboard

The dashboard contains four charts.
Production versus scrap is shown by product.
Monthly scrap rate is shown over time.
Scrap units are shown by product.
Scrap rate is shown by region.

## 🧠 Interpretation

A higher scrap rate means a larger share of production is classified as scrap.
Scrap units measure volume.
Scrap rate normalizes scrap against production.
Scrap cost provides an illustrative monetary view.

## ⚠️ Limitation

Scrap analysis identifies patterns.
It does not automatically identify root causes.
Root-cause analysis requires additional operational information.

## 🐍 Python

The Python script uses pandas.
It uses groupby aggregation.
It calculates product, monthly and regional summaries.
It exports CSV files.
It creates four charts.
