## 📌 Rural Spending Analysis

Rural spending analysis means studying how people in rural areas spend their income across different categories.

Important categories:

- Food
- Clothing
- Transport
- Healthcare
- Education

---

## 📊 Important Variables

| Variable | Meaning |
|---|---|
| Age_Group | Age category |
| Gender | Male/Female |
| Location | Rural/Urban |
| Household_Size | Number of household members |
| Monthly_Income | Monthly income |
| Food_Spend | Food expenditure |
| Clothing_Spend | Clothing expenditure |
| Transport_Spend | Transport expenditure |
| Healthcare_Spend | Healthcare expenditure |
| Education_Spend | Education expenditure |
| Total_Spending | Total spending |

---

## 🧮 Important Excel Functions

`AVERAGEIF()` → Average for one condition

`AVERAGEIFS()` → Average using multiple conditions

`COUNTIF()` → Count using one condition

`COUNTIFS()` → Count using multiple conditions

`SUM()` → Total value
