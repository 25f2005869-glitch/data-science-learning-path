## 🎯 Objective

Day 025 reviews the underlying e-commerce data used in the case study.

The focus is on understanding data structure and quality before further analysis.

The learner reviews fields, data types, missing values, duplicates, categories, and numerical measures.

The goal is to understand whether the dataset is ready for analysis.

The review should happen before drawing business conclusions.

## 🧠 Main Learning

Data should be reviewed before analysis.

The raw dataset should be understood first.

Every important field should have a clear meaning.

Missing values should be identified.

Duplicate records should be checked.

Identifiers should be checked separately.

Categorical values should be reviewed.

Numerical fields should be summarised.

Time fields should be checked.

Business measures should be interpreted correctly.

## 🔎 Data Quality

A data-quality review helps identify possible problems.

Missing data can affect calculations.

Duplicate rows can affect totals.

Duplicate identifiers can create ambiguity.

Unexpected categories can affect grouping.

Incorrect numerical values can distort analysis.

Incorrect time values can distort trends.

Quality checks should be documented.

## 📊 Business Analysis

Revenue is a sales-value measure.

Orders measure transaction activity.

Units measure product volume.

Discount provides pricing context.

Revenue should not be interpreted as profit.

Profit analysis requires cost information.

Business conclusions should be based on available evidence.
