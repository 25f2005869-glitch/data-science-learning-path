# 📝 Day 075 Notes — Nudge Economics & Consumer Behavior

## 1. Nudge Economics

- A nudge changes how choices are presented.
- It does not require removing every alternative.
- E-commerce interfaces contain many behavioural cues.
- Business data can measure outcomes associated with those cues.

## 2. Choice Architecture

- Defaults can reduce decision effort.
- Messages can make benefits visible.
- Social proof can provide popularity information.
- Time framing can emphasise urgency.

## 3. Control Condition

- No Nudge is the baseline in this synthetic case.
- A baseline provides a reference conversion rate.
- Comparisons should use the same outcome definition.
- Baseline interpretation depends on study design.

## 4. Default Recommendation

- A suggested option changes presentation.
- It can reduce search effort.
- It can change product prominence.
- The dataset records clicks and purchases.

## 5. Free Shipping Message

- The message highlights a delivery benefit.
- Exposure is represented as a categorical condition.
- Clicks are an intermediate measure.
- Purchases are the final binary outcome.

## 6. Social Proof

- Social proof communicates popularity information.
- It can be represented as a message.
- Click and purchase behaviour can be measured.
- The dataset does not establish a psychological mechanism.

## 7. Limited Time Message

- The message highlights a time constraint.
- It represents scarcity-style framing.
- Purchase is the measured business outcome.
- Association must not automatically be called causation.

## 8. Conversion Rate

- Conversion rate measures purchases relative to observations.
- Formula: purchases / observations × 100.
- It supports group comparisons.
- The denominator must remain consistent.

## 9. Click Rate

- Click rate measures clicks relative to exposures.
- It is an intermediate engagement metric.
- A click is not necessarily a purchase.
- Both metrics can be tracked together.

## 10. Percentage-Point Lift

- Lift in percentage points subtracts two percentages.
- 20% minus 15% equals 5 percentage points.
- This differs from relative percentage growth.
- Always state the unit.

## 11. Order Value

- Order value is recorded in rupees.
- It provides a monetary dimension.
- Total and average order value answer different questions.
- Revenue analysis should consider purchase status.

## 12. Segmentation

- Region can reveal geographic variation.
- Category can reveal product-context variation.
- Device can reveal interface-context variation.
- Segment results should not automatically be generalised.

## 13. Experiment Thinking

- Define intervention.
- Define control.
- Define outcome.
- Keep measurement rules consistent.
- Compare groups carefully.

## 14. Data Quality

- Check experiment IDs.
- Check binary fields.
- Check missing values.
- Check order-value units.
- Check nudge labels.
- Check the baseline category.

## 15. Dashboard Reading

- Start with exposure composition.
- Review conversion by nudge.
- Review regional conversion.
- Inspect the scatter plot.
- Return to raw data for validation.

## 16. Business Interpretation

- Nudges can be evaluated using measurable outcomes.
- Multiple KPIs provide more context.
- Segment analysis can reveal heterogeneous patterns.
- Synthetic data remains a learning device.

## 17. Limitations

- The dataset is small.
- The records are synthetic.
- No randomisation process is established by the dataset alone.
- No external consumer population is represented.
- No real company conclusion should be drawn.

## 18. Learning Outcome

- Explain nudges.
- Define a baseline.
- Calculate conversion.
- Calculate lift.
- Compare segments.
- Build dashboard metrics.
- State limitations.
