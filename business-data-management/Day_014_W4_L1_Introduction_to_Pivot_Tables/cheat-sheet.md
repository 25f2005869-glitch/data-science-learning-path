---

## 🧩 Pivot Table Areas

| Area | Purpose |
|---|---|
| Rows | Group data |
| Columns | Compare groups |
| Values | Calculate metrics |
| Filters | Restrict data |

---

## 📊 Common Calculations

### Sum

Total sales, revenue, quantity, etc.

### Count

Number of orders, customers, products, etc.

### Average

Average sales, price, score, etc.

---

## 🔑 Common Examples

**Category → Sum of Sales**

**Region → Sum of Sales**

**Product → Sum of Quantity**

**Category → Region → Sum of Sales**

---

## 🔄 Basic Process

**Select Data**

→ **Insert**

→ **Pivot Table**

→ **Choose Rows**

→ **Choose Values**

→ **Add Filters**

→ **Analyse**

---

## ⚠️ Remember

- Keep the source data structured.
- Column headers should be clear.
- Refresh the Pivot Table after changing source data.
- Do not confuse a Pivot Table with a normal data table.

---

## 🎯 Key Formula

Pivot Table =

**Group + Aggregate + Filter**
