## 📌 Overview

Day 097 focuses on **A/B Testing Practice**.

A/B testing is an experimental approach used to compare two versions of a business experience.

In this project:

- **Control Group (A)** represents the existing version.
- **Treatment Group (B)** represents the changed version.

The analysis compares both groups using business and customer metrics such as conversion, revenue, average order value, customer segments, and daily trends.

The dataset used in this project is **synthetic and created for educational practice**.

## 🧮 Important Formulas

### Conversion Rate

Conversion Rate measures the percentage of visitors who converted.

**Formula:**

Conversion Rate = (Conversions / Visitors) × 100

### Average Order Value

Average Order Value measures the average revenue generated per conversion.

**Formula:**

Average Order Value = Revenue / Conversions
