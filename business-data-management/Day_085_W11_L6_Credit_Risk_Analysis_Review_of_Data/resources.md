# 📚 Day 085 — Resources and Study Path

**Author:** Saloni Tiwari  
**Programme:** IIT Madras BS Degree — Diploma Level  
**Day:** 085  
**Topic:** Credit Risk Analysis — Review of Data

## 🎯 Study Goal

Day 085 focuses on reviewing a credit-risk dataset before deeper analysis.

The main focus is:

- Dataset structure
- Data quality
- Numeric review
- Category review
- Outcome review
- Business interpretation

## 2. Excel Skills

Review:

- Filters
- Sorting
- Tables
- Conditional formatting
- Pivot tables
- Basic formulas
- Charts

## 3. Data Quality Skills

Practise:

- Missing-value checks.
- Duplicate checks.
- Category frequency checks.
- Numeric summaries.
- Minimum and maximum checks.
- Binary flag validation.

## 4. Python Skills

- `read_excel`

- `nunique`

## 5. Credit Concepts

Review:

- Credit score.
- Debt-to-income.
- Loan exposure.
- Income capacity.
- Delinquency.
- Default.
- High-risk indicator.

## 6. Data Quality Concepts

Study:

- Completeness.
- Accuracy.
- Consistency.
- Uniqueness.
- Validity.
- Timeliness.
- Relevance.

## 7. Business Definition Questions

For every important field ask:

- What exactly does it mean?
- What unit is used?
- Who creates it?
- When is it available?
- Is it raw or derived?
- Could it be wrong?
- Could it leak the target?

## 8. Portfolio Extension

Create:

- A data-quality checklist.
- A KPI table.
- A credit-risk dashboard.
- A data dictionary.
- A Python review script.

## 9. Reproducibility

Keep the workbook and Python script in the same project structure.

The Python script should:

1. Read the workbook.
2. Review the data.
3. Generate summaries.
4. Export CSV files.
5. Generate charts.

## 10. Comparison Exercise

Calculate default rate in Excel.

Calculate default rate in Python.

Calculate total exposure in Excel.

Calculate total exposure in Python.

Compare the results.

Investigate any mismatch.

## 11. Modelling Preparation

Before modelling, confirm:

- Target definition.
- Target timing.
- Feature timing.
- Missing-value treatment.
- Category treatment.
- Outlier policy.
- Class balance.
- Leakage.
- Sampling context.

## 12. Important Limitation

The workbook contains only 30 synthetic observations.

The data is intended for educational practice.

The risk indicators are not validated underwriting rules.

## 13. Next Learning Direction

After review, deeper analysis can include:

- Univariate analysis.
- Bivariate analysis.
- Correlation.
- Segment analysis.
- Risk-factor analysis.
- Classification preparation.

## 14. Study Sequence

**Understand → Validate → Summarise → Visualise → Interpret → Document → Model**
