## 🎯 Learning Objectives

By the end of Day 006, you should be able to:

- Apply Excel to basic economic data.

- Analyse the relationship between Price and Demand.
- Calculate basic economic summaries using Excel.
- Compare Demand and Supply using spreadsheet calculations.

## 💼 Business Data Management Connection

Excel can be used to convert economic data into useful information.

**Economic Data → Excel Functions → Analysis → Business Insight**

For example:

- Total Demand
- Total Supply
- Average Price
- Highest Demand
- Lowest Demand
- Demand–Supply Gap
