## 🎯 Day Objective

Day 023 focuses on e-commerce data and post-COVID sales analysis.

The goal is to understand sales performance through business data.

Monthly, category, channel, region, and customer dimensions are used.

Revenue, orders, units, and discount are the main measures.

The analysis should remain connected to the case-study context.

## 📊 Workbook

Ecommerce_Data contains the raw practice dataset.

Monthly_Summary provides time-based performance.

Category_Summary provides product-category performance.

Channel_Summary provides sales-platform performance.

Region_Summary provides geographic performance.

Customer_Summary compares customer types.

Dashboard presents selected visualisations.

Business_Insights records major descriptive findings.

## 📈 Analysis

Start with data understanding.

Check data quality.

Calculate business measures.

Compare performance across dimensions.

Use visualisation to communicate important patterns.

Interpret findings carefully.

Do not treat descriptive results as causal proof.
