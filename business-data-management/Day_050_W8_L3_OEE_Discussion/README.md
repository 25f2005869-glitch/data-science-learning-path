## 🔢 OEE Components

Availability measures production time availability.
Performance measures output relative to ideal output.
Quality measures good output relative to total output.

## 📐 Main Formula

OEE = Availability × Performance × Quality.

## 🧮 Component Formulas

Availability = Run Time / Planned Time.
Performance = Actual Output / Ideal Output.
Quality = Good Count / Total Count.

## 🧠 Discussion Focus

OEE should be decomposed into its three components.
The component view helps explain which part of the metric differs.

## ⚠️ Interpretation

OEE is a composite metric.
A lower OEE can result from different component values.
The component-level data should therefore be inspected.
