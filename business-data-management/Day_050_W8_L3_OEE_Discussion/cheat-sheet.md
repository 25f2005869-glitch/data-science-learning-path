# ⚡ Day 050 Cheat Sheet — OEE Discussion

## 🔢 Core Formula

OEE = Availability × Performance × Quality.

## 📐 Component Formulas

Availability = Run Time / Planned Time.

Performance = Actual Output / Ideal Output.

Quality = Good Count / Total Count.

## ⏱️ Time Formula

Run Time = Planned Time - Downtime.

## 🏭 Ideal Output

Ideal Output = Run Time × 60 / Ideal Cycle Time.

## 📌 Excel Functions

SUMIF → one-condition aggregation.
SUMIFS → multiple-condition aggregation.

## 🧠 Interpretation

Availability relates to time.
Performance relates to speed/output.
Quality relates to good output.
OEE combines all three.

## ⚠️ Important

Do not explain OEE from the final percentage alone.
Inspect its three components.
Do not infer operational causes without evidence.
