# ⚡ Day 063 Cheat Sheet — Job Description

## Core Structure

Job Title → What is the role called?

Department → Where does it belong?

Function → What area of work?

Level → What seniority?

Qualification → What education?

Skills → What capabilities?

Experience → What prior exposure?

Role Summary → Why does the role exist?

KPIs → What outcomes matter?

Reports To → Who manages the role?

## Role vs Skill

Role = position and responsibility.

Skill = capability needed to perform the role.

Experience = prior exposure to relevant work.

Qualification = educational requirement.

KPI = measurable outcome.

## Excel

COUNTA → count populated fields.

COUNTIF → count records matching a condition.

AVERAGEIF → average a numeric field by category.

SUMPRODUCT → useful for weighted analysis.

FILTER → isolate role records.

SORT → order records for review.

## Python

pd.read_excel() → read workbook.

str.split() → separate skills.

str.extract() → extract experience numbers.

groupby() → summarize roles.

agg() → calculate multiple metrics.

to_csv() → export analysis.

## Quality Checks

Check title.

Check department.

Check level.

Check qualification.

Check required skills.

Check experience.

Check responsibilities.

Check KPIs.

Check reporting relationship.

## Business Questions

Which departments have more roles?

Which skills occur frequently?

How does experience vary by level?

Which roles require Power BI?

Which roles require Python?

Are KPIs defined?

Is the reporting relationship clear?

## Key Principle

Job requirements should be role-relevant.

Generic requirements can reduce matching quality.

Document assumptions.

Review descriptions periodically.
