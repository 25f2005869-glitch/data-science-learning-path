# 🧪 Day 063 Practice — Caselet 2: Job Description

## Practice Setup

Open the Excel workbook.

Start with Job_Descriptions.

Read several role records before analyzing the summaries.

## Task 1 — Identify Components

Identify the job title.

Identify the department.

Identify the function.

Identify the level.

Identify qualification.

Identify required skills.

Identify experience.

Identify KPIs.

Identify reporting relationship.

## Task 2 — Role Summary

Choose three job descriptions.

Write the purpose of each role in one sentence.

Separate purpose from individual tasks.

## Task 3 — Skills

Count the required skills for each role.

Identify roles requiring Excel.

Identify roles requiring SQL.

Identify roles requiring Python.

Identify roles requiring Power BI.

## Task 4 — Experience

Extract minimum experience requirements.

Compare Entry and Intermediate roles.

Explain why experience should relate to responsibility.

## Task 5 — Department

Count job descriptions by department.

Calculate average required skills.

Calculate average experience.

Compare the department summaries.

## Task 6 — Function

Count roles by function.

Identify functions with analytics-related responsibilities.

Review whether the role summary matches the function.

## Task 7 — KPI Review

Read the KPI field for five roles.

Explain how each KPI connects to the role.

Identify one KPI that could be made more measurable.

## Task 8 — Internal Sourcing

Choose one role.

Create a short internal candidate profile.

List five matching criteria.

List two pieces of evidence you would review.

## Task 9 — Completeness

Check whether all major fields are populated.

Calculate the completeness percentage.

Explain why missing role information can affect sourcing.

## Task 10 — Excel Practice

Use COUNTIF for department counts.

Use AVERAGEIF for experience analysis.

Use filtering for role-specific review.

Create a PivotTable by department.

## Task 11 — Python

Run the supplied Python script.

Open department_job_description_summary.csv.

Open job_level_summary.csv.

Open required_skill_summary.csv.

Review the generated PNG charts.

## Mini Case

A department wants to fill an internal vacancy.

Write a structured job description for the vacancy.

Include the role purpose, five skills, experience, three KPIs and reporting relationship.
