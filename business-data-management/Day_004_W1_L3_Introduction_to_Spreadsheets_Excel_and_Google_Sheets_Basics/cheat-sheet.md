## 📊 1. Spreadsheet

**Spreadsheet = Tool for storing, organizing, calculating, and analyzing data**

Main structure:

**Rows + Columns + Cells**

---

## 💻 2. Microsoft Excel

Excel is a spreadsheet application used for:

- Data Entry
- Data Organization
- Calculations
- Data Analysis
- Reporting

---

## 🌐 3. Google Sheets

Google Sheets is a web-based spreadsheet application used for:

- Creating spreadsheets
- Entering data
- Editing data
- Organizing data
- Calculations
- Collaboration

---

## 📁 4. Workbook vs Worksheet

| Term | Meaning |
|---|---|
| **Workbook** | Spreadsheet file |
| **Worksheet** | Individual sheet inside a workbook |

**Workbook → Multiple Worksheets**

---

## 📐 5. Rows & Columns

### Row

- Horizontal
- Identified by numbers

**1, 2, 3, 4...**

### Column

- Vertical
- Identified by letters

**A, B, C, D...**

---

## 🔲 6. Cell

A **Cell** is the intersection of a row and a column.

Example:

**A1**

- `A` → Column
- `1` → Row

Examples:

`A1`  
`B5`  
`C10`  
`D20`

---

## 📌 7. Cell Reference

**Cell Reference = Address of a cell**

Examples:

- `A1`
- `B2`
- `C5`
- `D10`

Cell references are important when working with spreadsheet data and formulas.

## 🧠 11. Must Remember

**Spreadsheet → Rows + Columns + Cells**

**Workbook → Spreadsheet File**

**Worksheet → Sheet inside Workbook**

**Row → Number**

**Column → Letter**

**Cell → Row + Column Intersection**

**A1 → Column A + Row 1**
