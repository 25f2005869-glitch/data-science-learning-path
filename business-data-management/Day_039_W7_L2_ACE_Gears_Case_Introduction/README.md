## 🚀 Day Overview

This day introduces the ACE Gears manufacturing case and prepares the dataset for detailed business analysis.

The case connects products, regions, customer types, production, sales, scrap, revenue and production cost.

## 🎯 Learning Objectives

- Understand the ACE Gears case context.
- Understand the dataset structure.
- Identify key business dimensions.
- Review manufacturing KPIs.
- Compare product performance.
- Compare regional performance.
- Compare customer types.
- Prepare questions for deeper case analysis.

## 🏭 Case Context

ACE Gears is used here as a manufacturing-sector case for BDM analytical practice.

The workbook provides a structured sample dataset for learning the case-analysis workflow.

## 📊 Core Metrics

- Production Units
- Sales Units
- Scrap Units
- Revenue
- Production Cost
- Gross Margin
- Scrap Rate

## 🧮 Formulas

Gross Margin = Revenue − Production Cost

Scrap Rate = Scrap Units / Production Units
