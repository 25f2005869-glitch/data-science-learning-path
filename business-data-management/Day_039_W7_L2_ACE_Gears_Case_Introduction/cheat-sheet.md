## 🏭 Case Dimensions

Product

Region

Customer Type

## 📊 Measures

Production Units

Sales Units

Scrap Units

Revenue

Production Cost

Gross Margin

## 🧮 Formulas

Gross Margin = Revenue − Production Cost

Scrap Rate = Scrap Units ÷ Production Units

## 🔎 Product Questions

Which product has the highest revenue?

Which product has the highest sales volume?

Which product has the highest scrap rate?

## 🌍 Regional Questions

Which region has the highest revenue?

Which region has the highest sales volume?

How does scrap rate differ by region?

## 👥 Customer Questions

How do OEM and Distributor groups compare?

Which customer type contributes more revenue?

How do sales units differ?

## 📈 Chart Selection

Bar → product or region comparison

Line → time trend when dates exist

Scatter → relationship between numerical variables

Table → exact values

## 🧭 Workflow

1. Understand case context.
2. Read data dictionary.
3. Inspect raw data.
4. Calculate KPIs.
5. Group by product.
6. Group by region.
7. Group by customer type.
8. Visualize.
9. Write insights.

## 🛠️ Excel

SUMIF can create grouped summaries.

Pivot Tables can create interactive summaries.

Charts communicate comparisons.

## 🐍 Python

groupby() creates grouped summaries.

agg() calculates multiple metrics.

matplotlib creates charts.

## ⚠️ Remember

Production is not the same as sales.

Scrap is not sales.

Revenue is not profit.

Gross margin here is a simple revenue-minus-production-cost measure.
