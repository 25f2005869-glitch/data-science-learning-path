# ⚡ Day 083 Cheat Sheet — Credit Risk Analysis

## Core Terms

- Credit Risk → risk of borrower non-repayment.
- Default → observed failure to meet the defined obligation.
- Credit Score → credit-behaviour indicator.
- DTI → debt burden relative to income.
- Delinquency → previous payment problem.
- Exposure → amount financially at risk.

## Core Formulas

- Default Rate = Defaults / Customers × 100.
- Annual Income = Monthly Income × 12.
- Loan-to-Annual-Income % = Loan Amount / Annual Income × 100.
- Simple Monthly Installment = Loan Amount / Tenure.

## Excel Functions

- COUNTIF → count by one condition.
- COUNTIFS → count by multiple conditions.
- SUMIF → sum by category.
- SUMIFS → conditional sum.
- AVERAGEIF → subgroup average.
- AVERAGEIFS → multi-condition average.
- PivotTable → multi-dimensional analysis.

## Python

- read_excel() → read workbook.
- groupby() → create segments.
- agg() → calculate summary metrics.
- cut() → create bands.
- to_csv() → export results.
- matplotlib → create charts.

## Quality Checks
