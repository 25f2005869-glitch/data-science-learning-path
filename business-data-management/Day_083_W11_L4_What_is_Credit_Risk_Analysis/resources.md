# 📚 Day 083 Resources — Credit Risk Analysis

## 1. Learning Sequence

- Start with the definition of credit risk.
- Understand the default outcome.
- Study credit score.
- Study DTI.
- Study delinquency.
- Study loan exposure.
- Practise segmentation.

## 2. Excel Practice

- COUNTIFS for default counts.
- SUMIFS for exposure totals.
- AVERAGEIFS for risk averages.
- PivotTables for subgroup analysis.
- Column charts for rate comparisons.
- Scatter charts for variable relationships.

## 3. Python Practice

- pandas DataFrame inspection.
- groupby and aggregation.
- pd.cut for risk bands.
- CSV export.
- Matplotlib chart generation.

## 4. Statistical Extension

- Probability of default.
- Logistic regression.
- Train/test split.
- Confusion matrix.
- ROC-AUC.
- Precision and recall.
- Calibration.

## 5. Governance

## 6. Portfolio Extension
