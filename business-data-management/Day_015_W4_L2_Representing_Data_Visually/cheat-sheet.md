# ⚡ Cheat Sheet — Data Visualization

**Author:** Saloni Tiwari  
**Programme:** IIT Madras BS Degree — Diploma Level  
**Day:** 015  
**Topic:** W4_L2 — Representing Data Visually

## 📊 Bar Chart

**Use:** Category comparison

Example:

**Region → Sales**

## 📈 Line Chart

**Use:** Trend / ordered data

Example:

**Month → Sales**

## 🥧 Pie Chart

**Use:** Part-to-whole composition

Example:

**Product → Sales Share**

## 🐍 Python Libraries

- `pandas`
- `matplotlib`
- `seaborn`

## 📗 Excel

**Select → Insert → Chart → Format → Interpret**

## 🧠 Remember

| Question | Suitable Chart |
|---|---|
| Compare categories | Bar |
| Show trend | Line |
| Show share | Pie |

## 🎯 Visualization Formula

**Question → Data → Chart → Insight**
