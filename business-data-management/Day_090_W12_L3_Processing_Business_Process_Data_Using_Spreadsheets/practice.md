# 🧮 Part 4 — Calculation Practice

Create calculated columns for the following metrics.

### Task 15 — Profit

Calculate:

**Profit = Revenue − Cost**

### Task 16 — Average Order Value

Calculate:

**AOV = Revenue / Orders**

### Task 17 — Cost per Order

Calculate:

**Cost per Order = Cost / Orders**

### Task 18 — On-Time Delivery Rate

Calculate:

**On-Time Delivery Rate = On-Time Deliveries / Deliveries × 100**

### Task 19 — Return Rate

Calculate:

**Return Rate = Returned Orders / Orders × 100**

### Task 20 — Profit Margin

Calculate:

**Profit Margin = Profit / Revenue × 100**
