## Overview

Day 090 focuses on processing business process data using spreadsheets.

The main workflow is:

**Raw Data → Clean/Organise → Calculate → Summarise → Visualise → Interpret**

Spreadsheets can be used to organise business records, perform calculations, filter data, create summaries, and build charts.

## Learning Objectives

By the end of this day, you should be able to:

- Understand business process data.
- Organise raw business data in a spreadsheet.
- Sort and filter business records.
- Perform basic calculations.
- Calculate business KPIs.
- Summarise data by business function and process.
- Use Pivot Tables for analysis.
- Create charts from business data.
- Interpret spreadsheet-based results.

## Spreadsheet Processing Workflow

### Step 1 — Understand the Data

First identify:

- Rows
- Columns
- Variables
- Business functions
- Processes
- Measures

### Step 2 — Organise the Data

Keep the dataset structured so that each row represents a business record and each column represents a variable.

### Step 3 — Calculate

Use spreadsheet formulas to calculate:

- Revenue
- Cost
- Profit
- Average Order Value
- Cost per Order
- On-Time Delivery Rate
- Return Rate
- Profit Margin

### Step 4 — Summarise

Group the data by:

- Business Function
- Process
- Other relevant categories

### Step 5 — Visualise

Use charts to make patterns easier to understand.

Examples:

- Revenue by Process
- Profit by Process
- Orders by Function
- Delivery Performance

### Step 6 — Interpret

Use the processed data to identify patterns and areas that may require further investigation.

## Important Spreadsheet Functions

| Function | Purpose |
|---|---|
| SUM | Calculate totals |
| COUNT | Count values |
| AVERAGE | Calculate mean |
| SUMIF | Conditional total |
| SUMIFS | Multiple-condition total |
| COUNTIF | Conditional count |
| COUNTIFS | Multiple-condition count |
| AVERAGEIF | Conditional average |

## Key Formulae

**Profit = Revenue − Cost**

**Average Order Value = Revenue / Orders**

**Cost Per Order = Cost / Orders**

**On-Time Delivery Rate (%) = On-Time Deliveries / Deliveries × 100**

**Return Rate (%) = Returned Orders / Orders × 100**

**Profit Margin (%) = Profit / Revenue × 100**
