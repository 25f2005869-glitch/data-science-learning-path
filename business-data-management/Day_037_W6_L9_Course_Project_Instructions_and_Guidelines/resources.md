# 📚 Day 037 Resources — Course Project Instructions & Guidelines

**Author:** Saloni Tiwari  
**Programme:** IIT Madras BS Degree — Diploma Level  
**Day:** 037  
**Topic:** Course Project Instructions & Guidelines

## 🎓 Learning Context

This day prepares the learner for the BDM course project workflow.

The emphasis is project planning, data understanding, analysis and communication.

## 📖 Core Resources in Workbook

Project_Brief explains the overall workflow.

Project_Checklist tracks project stages.

Business_Questions provides question examples.

Data_Quality provides a quality-control checklist.

KPI_Framework provides KPI definitions.

Analysis_Plan maps analysis types to tools.

Presentation_Plan provides a communication structure.

Self_Review supports final validation.

Project_Dashboard provides a visual planning view.

## 🧰 Excel Tools

Excel can be used for filtering, formulas, Pivot Tables, charts and dashboard construction.

## 🐍 Python Tools

pandas can be used for data loading, cleaning, grouping and analysis.

matplotlib can be used for programmatic visualization.

## 🧭 Recommended Study Sequence

1. Read the project instructions.
2. Understand the business problem.
3. Inspect the dataset.
4. Perform quality checks.
5. Define questions.
6. Select KPIs.
7. Analyze the data.
8. Build visualizations.
9. Write insights.
10. Prepare the presentation.
11. Perform final validation.

## 🔎 Questions for Revision

What is the business problem?

What evidence is needed?

What data fields are required?

Which KPI measures the objective?

Which chart answers the question?

What limitation affects interpretation?

## 💼 Business Communication

A business audience needs clear evidence and meaning.

Avoid unexplained technical terminology.

Use concise charts and tables.

Keep conclusions connected to the analysis.

## ⚠️ Official Instructions

The official course/project instructions supplied by IIT Madras should be checked before final submission.

This learning package is not a replacement for those instructions.
