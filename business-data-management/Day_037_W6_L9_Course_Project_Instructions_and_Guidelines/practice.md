# 🧪 Day 037 Practice — Course Project Planning

**Author:** Saloni Tiwari  
**Programme:** IIT Madras BS Degree — Diploma Level  
**Day:** 037  
**Topic:** Course Project Instructions & Guidelines

## 🎯 Practice Goal

Use the workbook to create a project plan before beginning the final analysis.

## Level 1 — Project Understanding

1. Read Project_Brief.
2. Write the purpose of your project in one sentence.
3. Identify the business context.
4. Write the main problem statement.
5. List the expected project outputs.

## Level 2 — Data Understanding

6. Identify the dataset source.
7. List the important fields.
8. Identify unique identifiers.
9. Separate dimensions and measures.
10. Create a data dictionary.

## Level 3 — Data Quality

11. Check missing values.
12. Check duplicates.
13. Check data types.
14. Check category consistency.
15. Check unusual values.
16. Document every important cleaning decision.

## Level 4 — Business Questions

17. Write three sales questions.
18. Write two trend questions.
19. Write one regional question.
20. Write one channel question.
21. Write one KPI question.

## Level 5 — Analysis

22. Create a descriptive summary.
23. Create a grouped product summary.
24. Create a regional summary.
25. Create a channel summary.
26. Create a time-based summary if dates exist.

## Level 6 — Visualization

27. Select a chart for product comparison.
28. Select a chart for trend analysis.
29. Select a chart for regional comparison.
30. Create a dashboard layout.
31. Add meaningful titles.

## Level 7 — Insights

32. Write three evidence-based observations.
33. Add business meaning to each observation.
34. Identify one important limitation.
35. Identify one question requiring further analysis.

## Level 8 — Presentation

36. Prepare the project title.
37. Prepare the business context.
38. Prepare the problem statement.
39. Prepare the methodology.
40. Prepare the findings.
41. Prepare the conclusion.

## 🧠 Challenge

Create a complete one-page project plan.

Include the business problem, five questions, data requirements, KPIs, charts and expected insights.

## 🏁 Completion Checklist

- [ ] Problem defined
- [ ] Data understood
- [ ] Data quality checked
- [ ] Questions written
- [ ] KPIs selected
- [ ] Analysis planned
- [ ] Visualizations planned
- [ ] Insights planned
- [ ] Presentation structure prepared
- [ ] Official project instructions checked

## 💡 Extra Practice

Create a project timeline.

List every major analysis task.

Identify dependencies between tasks.

Record expected outputs.

Add a validation step after each major calculation.
