# ⚡ Day 037 Cheat Sheet — Course Project

**Author:** Saloni Tiwari  
**Programme:** IIT Madras BS Degree — Diploma Level  
**Day:** 037  
**Topic:** Course Project Instructions & Guidelines

## 🎯 Project Formula

Business Problem → Questions → Data → Cleaning → Analysis → Visualization → Insights → Presentation

## 🧩 Problem Statement

State the business context.

State what needs to be understood.

State the decision or analysis objective.

## 🔍 Data Checklist

- Identify rows.
- Identify columns.
- Identify keys.
- Identify measures.
- Identify categories.
- Understand dates.

## 🧹 Quality Checklist

- Missing values
- Duplicates
- Data types
- Category consistency
- Outliers
- Invalid values
- Identifier consistency

## 📊 Common KPIs

Total Revenue = SUM(Revenue)

Total Units = SUM(Units)

Average Revenue per Unit = Revenue / Units

Order Count = COUNT(Order_ID)

Average Order Value = Revenue / Order Count

## 📈 Chart Selection

Bar → category comparison

Line → time trend

Pie → simple composition

Scatter → relationship

Table → exact values

## 🧠 Insight Structure

Observation + Evidence + Business Meaning

## 💼 Question Structure

What happened?

Where did it happen?

When did it happen?

Which segment differs?

Why might it matter?

## 📝 Presentation Structure

1. Title
2. Business Context
3. Problem
4. Data
5. Data Quality
6. Method
7. Findings
8. Insights
9. Recommendations
10. Limitations
11. Conclusion

## ⚠️ Final Checks

Validate important numbers.

Check chart labels.

Check units and currency.

Check assumptions.

Check official submission requirements.

## 🏅 Quick Rule

Do not start with the chart.

Start with the business question.

## 🔄 Revision Notes

Review the project instructions.

Keep the objective visible.

Validate calculations.

Document assumptions.

Use evidence for insights.

Review visual clarity.

Check final presentation.

Record limitations.

Complete the self-review.
