# 🧹 Data Preparation

The project follows a structured data preparation process.

### Step 1 — Understand

Identify:

- Rows
- Columns
- Business fields
- Dimensions
- Measures
- Data types

### Step 2 — Check

Review:

- Missing values
- Duplicate records
- Incorrect data types
- Invalid values
- Inconsistent fields

### Step 3 — Clean

Prepare the dataset for analysis.

### Step 4 — Validate

Confirm that the cleaned data is suitable for analysis.
