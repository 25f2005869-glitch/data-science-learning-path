## 📖 Overview

Day 091 is a practical revision of Excel skills used in business data analysis.

This revision goes beyond basic formulas and covers the complete workflow:

**Business Data → Processing → Summary → Pivot → KPI → Charts → Dashboard → Final Project**

The workbook provides hands-on practice with Excel fundamentals, formulas, functions, logical operations, conditional analysis, sorting, filtering, data cleaning, text and date functions, lookup functions, business KPIs, charts and dashboard creation.

---

## 🎯 Learning Objectives

By the end of Day 091, the learner should be able to:

- Understand the basic structure of an Excel workbook.
- Work with worksheets, cells, rows, columns and ranges.
- Create and use formulas.
- Use common Excel functions.
- Apply logical and conditional functions.
- Sort and filter business data.
- Perform basic data-cleaning operations.
- Use text and date functions.
- Understand lookup functions.
- Work with Excel Tables.
- Summarise business data.
- Create Pivot-style summaries.
- Create and interpret different chart types.
- Calculate important business KPIs.

- Complete a business-oriented Excel project.

## 🧮 Business KPI Calculations

### Profit

**Profit = Revenue − Cost**

### Average Order Value

**AOV = Revenue / Orders**

### Cost per Order

**Cost per Order = Cost / Orders**

### Profit Margin

**Profit Margin = Profit / Revenue × 100**

### Return Rate

**Return Rate = Returned Orders / Orders × 100**

### On-Time Delivery Rate

**On-Time Delivery Rate = On-Time Deliveries / Deliveries × 100**
