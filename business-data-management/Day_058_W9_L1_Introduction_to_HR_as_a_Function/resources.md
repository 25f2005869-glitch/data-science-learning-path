## Data Quality Checklist

Check employee IDs.

Check missing values.

Check duplicate IDs.

Check numeric fields.

Check percentage ranges.

Check category spelling.

Confirm the time period.

Document assumptions.

## Responsible HR Data Use

Use only necessary employee data.

Avoid exposing personally identifying information in public dashboards.

Aggregate data when individual-level detail is unnecessary.

Control access to sensitive workforce information.

Document definitions for HR metrics.
