## 🔹 Basic Functions

| Function | Purpose | Example |
|---|---|---|
| `SUM` | Total | `=SUM(B2:B10)` |
| `AVERAGE` | Average | `=AVERAGE(B2:B10)` |
| `COUNT` | Count numbers | `=COUNT(B2:B10)` |
| `COUNTA` | Count non-empty cells | `=COUNTA(B2:B10)` |
| `MIN` | Smallest value | `=MIN(B2:B10)` |
| `MAX` | Largest value | `=MAX(B2:B10)` |

---

## 🔹 Cell References

**Single Cell:** `A1`

**Range:** `A1:A10`

**Multiple Cells:** `A1, B1, C1`

---

## 🔹 Function Structure

`=FUNCTION(range)`

Example:

`=SUM(C2:C10)`

---

## 💼 Business Use

- `SUM` → Total Sales
- `AVERAGE` → Average Sales
- `COUNT` → Number of numerical records
- `COUNTA` → Number of filled records
- `MAX` → Highest Sales
- `MIN` → Lowest Sales
