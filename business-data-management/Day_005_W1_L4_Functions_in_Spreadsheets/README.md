## 📚 Topics Covered

### 🔹 1. Spreadsheet Functions
Functions are predefined formulas used to perform calculations on data.

### 🔹 2. Basic Functions

- `SUM`
- `AVERAGE`
- `COUNT`
- `COUNTA`
- `MIN`
- `MAX`

### 🔹 3. Cell References

Examples:

- `A1`
- `B5`
- `A1:A10`

### 🔹 4. Using Functions with Data

Functions can be applied to:

- Sales data
- Quantity
- Prices
- Customer data
- Business records

---

## 💼 BDM Connection

Spreadsheet functions are important in Business Data Management because they help convert raw business data into useful numerical information.

Examples:

**Total Sales** → SUM  
**Average Sales** → AVERAGE  
**Number of Orders** → COUNT/COUNTA  
**Highest Sales** → MAX  
**Lowest Sales** → MIN

---

## 🧠 Key Concepts

| Function | Purpose |
|---|---|
| `SUM` | Adds values |
| `AVERAGE` | Calculates average |
| `COUNT` | Counts numerical values |
| `COUNTA` | Counts non-empty cells |
| `MIN` | Finds minimum value |
| `MAX` | Finds maximum value |
