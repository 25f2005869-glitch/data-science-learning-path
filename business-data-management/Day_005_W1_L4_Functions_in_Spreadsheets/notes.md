## 🔹 What is a Spreadsheet Function?

A function is a predefined formula used to perform calculations on data.

Basic structure:

Function + Range → Result

Example:

`SUM(A1:A10)` → Adds values from A1 to A10.

---

## 🔹 Common Functions

| Function | Use |
|---|---|
| `SUM` | Total |
| `AVERAGE` | Average |
| `COUNT` | Counts numbers |
| `COUNTA` | Counts non-empty cells |
| `MIN` | Smallest value |
| `MAX` | Largest value |

---

## 🔹 Cell Reference

A cell is identified using its column and row.

Examples:

- `A1`
- `B5`
- `C10`

A range contains multiple cells.

Example:

`A1:A10`

---

## 🔹 Business Example

Suppose `B2:B6` contains sales:

- `SUM(B2:B6)` → Total Sales
- `AVERAGE(B2:B6)` → Average Sales
- `MAX(B2:B6)` → Highest Sales
- `MIN(B2:B6)` → Lowest Sales
- `COUNT(B2:B6)` → Number of numerical values

## 📌 Key Takeaways

- Functions make spreadsheet calculations easier.
- Functions can work with individual cells or ranges.
- `SUM`, `AVERAGE`, `COUNT`, `COUNTA`, `MIN`, and `MAX` are important basic functions.
- Functions are widely used in business data analysis.
