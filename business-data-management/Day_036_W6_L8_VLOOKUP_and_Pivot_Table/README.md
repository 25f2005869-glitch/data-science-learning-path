## 🔎 VLOOKUP

VLOOKUP searches for a value in the first column of a lookup table.

It returns information from another column in the same row.

The practical exercise uses Product as the lookup key.

Product_Master contains the reference attributes.

## 📊 Pivot Table

A Pivot Table summarizes records by selected dimensions.

Typical dimensions include Product, Region and Channel.

Typical measures include Total Units and Total Revenue.

## 💼 Business Thinking

VLOOKUP answers a data retrieval question.

Pivot analysis answers a summarization question.

Together they support spreadsheet-based business analysis.

## 📈 Dashboard

## 📌 Key Takeaways

- A lookup key should be consistent.
- Exact matching is useful for controlled reference data.
- Lookup tables should have a clear key column.
- Pivot summaries turn rows into grouped information.
- Revenue and units answer different business questions.
