# 📊 Day 062 — Internal Sourcing: Ranking of Internal Candidates

## 📌 Day Overview

Day 062 focuses on ranking internal candidates using a structured composite score.

This package uses an illustrative internal sourcing dataset for learning.

The data is not official IIT Madras or company data.

## 🎯 Learning Objectives

1. Understand internal candidate ranking.
2. Separate candidate attributes from ranking outputs.
3. Combine multiple evaluation dimensions.
4. Build a weighted composite score.
5. Assign candidate ranks.
6. Compare candidates across departments.
7. Compare internal sourcing types.
8. Interpret ranking results responsibly.

## 🧩 Candidate Evaluation Dimensions

- Performance score
- Skill match score
- Leadership score
- Experience
- Assessment score

## 📐 Composite Score

Performance contributes 30%.

Skill match contributes 30%.

Leadership contributes 20%.

Experience contributes 10%.

Assessment contributes 10%.

The composite score is a screening aid.

## 🏆 Ranking

Rank 1 represents the highest composite score in this illustrative dataset.

Lower numeric rank means a higher position.

Ranking should be reviewed alongside role requirements and evidence.

## 🧪 Analysis Flow

1. Review candidate records.
2. Check evaluation fields.
3. Calculate the composite score.
4. Rank candidates.
5. Segment by department.
6. Segment by sourcing type.
7. Review selection status.
8. Document assumptions.

## ⚠️ Interpretation

A composite score depends on the chosen weights.

Changing weights can change ranks.

A ranking is not proof that one employee is universally better.

Final internal staffing decisions require appropriate human review.

## 🐍 Python

The Python script reproduces the composite-score and ranking workflow.

It exports CSV summaries and PNG charts.

## 🧠 Key Takeaway

Structured ranking makes candidate comparison more transparent.

The method is useful when the evaluation criteria are defined clearly.

The score should support, not replace, appropriate review.
