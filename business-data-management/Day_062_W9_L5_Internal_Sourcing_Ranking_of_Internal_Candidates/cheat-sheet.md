# ⚡ Day 062 Cheat Sheet — Internal Candidate Ranking

## Core Idea

Rank internal candidates using a defined composite score.

## Candidate Dimensions

Performance → 30%

Skill Match → 30%

Leadership → 20%

Experience → 10%

Assessment → 10%

## Composite Formula

Composite = Performance×0.30 + Skill Match×0.30 + Leadership×0.20 + Normalized Experience×0.10 + Normalized Assessment×0.10

## Ranking

Higher composite score → better numeric rank.

Rank 1 = highest score.

## Excel Concepts

SUMPRODUCT can implement weighted scoring.

RANK.EQ can create ranking positions.

COUNTIF can count selected candidates.

AVERAGEIF can compare group averages.

PivotTables can summarize departments and regions.

## Python Concepts

pandas read_excel() reads workbook data.

rank() creates ranking values.

groupby() creates segment summaries.

to_csv() exports results.

matplotlib creates charts.

## Useful Checks

Check missing scores.

Check score ranges.

Check experience units.

Check assessment denominator.

Check weights sum to 100%.

## Business Questions

Who has the highest composite score?

Which departments have stronger average scores?

How many candidates are selected?

What is the selection rate?

How do sourcing types compare?

## Interpretation Rules

Weight choice affects rank.

Average score is descriptive.

Rank does not prove overall employee quality.

Context matters.

## Dashboard

Top 10 candidate scores.

Department average scores.

Sourcing-type average scores.

Selection-status counts.
