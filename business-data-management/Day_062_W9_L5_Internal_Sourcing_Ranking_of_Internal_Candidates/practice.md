# 🧪 Day 062 Practice — Ranking of Internal Candidates

## Practice Setup

Open the workbook.

Start with Candidate_Data.

Review every evaluation field before ranking.

## Task 1 — Data Review

Count candidates.

Check candidate IDs for duplicates.

Check missing values.

Inspect department and region categories.

## Task 2 — Score Ranges

Check performance scores.

Check skill match scores.

Check leadership scores.

Check assessment scores.

Check experience years.

## Task 3 — Composite Score

Calculate each weighted component.

Normalize experience.

Normalize assessment.

Add the weighted components.

Compare your result with Candidate_Data.

## Task 4 — Ranking

Rank candidates from highest to lowest composite score.

Identify the top five.

Identify the bottom five.

## Task 5 — Department

Count candidates by department.

Calculate average composite score by department.

Compare average performance.

Compare average skill match.

## Task 6 — Sourcing Type

Count transfers.

Count promotions.

Calculate average composite score by sourcing type.

Compare average assessment scores.

## Task 7 — Region

Count candidates by region.

Calculate average composite score by region.

Count selected candidates by region.

## Task 8 — Selection

Count selected candidates.

Calculate selection rate.

Compare selected and non-selected average scores.

## Task 9 — Sensitivity

Increase skill-match weight.

Reduce another weight so the total remains 100%.

Recalculate the ranking.

Record candidates whose ranks change.

## Task 10 — Excel

Use SUMPRODUCT for weighted scoring.

Use RANK.EQ for rank.

Use COUNTIF for selection counts.

Use AVERAGEIF for group averages.

Build a PivotTable.

## Task 11 — Python

Open region_candidate_ranking.csv.
