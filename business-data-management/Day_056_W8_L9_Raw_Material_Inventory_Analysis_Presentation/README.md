## 🧮 Inventory Flow

A simplified inventory relationship is:

Opening Inventory + Purchases − Material Usage = Closing Inventory

## 💰 Inventory Value

Inventory value can be calculated as:

Closing Inventory × Unit Cost

## ⏱️ Lead-Time Demand

Lead-time demand estimates the expected material requirement during replenishment.

Formula:

Average Daily Usage × Lead Time

## 📌 Reorder Point

Reorder point represents the inventory level used as a replenishment reference.

Formula:

Lead-Time Demand + Safety Stock

## 📉 Inventory Gap

Inventory gap compares closing inventory with reorder point.

Formula:

Closing Inventory − Reorder Point

## 🚦 Stock Status

If inventory gap is negative:

**Below Reorder Point**

If inventory gap is zero or positive:

**At/Above Reorder Point**
